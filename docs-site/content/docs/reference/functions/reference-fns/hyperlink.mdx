Returns the friendly name of a hyperlink, or its link location when no name is given.

The returned value is `friendly_name` when the second argument is present,
 otherwise `link_location`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HYPERLINK(link_location, [friendly_name])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `link_location` | any | Required | — |
| `friendly_name` | any | Optional | — |

## Differences from Excel
 Formualizer returns the friendly name as text. Excel passes numbers and booleans through
 with their original type, so `=ISNUMBER(HYPERLINK("x",1))` is FALSE in Formualizer and TRUE in Excel.

## Examples

<FunctionExample
  title={"Use the destination itself as the displayed text."}
  formula={"=HYPERLINK(\"https://example.com\")"}
  grid={{}}
  expected={"https://example.com"}
/>

<FunctionExample
  title={"Supply independent display text for the same destination."}
  formula={"=HYPERLINK(\"https://example.com\",\"Open example\")"}
  grid={{}}
  expected={"Open example"}
/>

<FunctionExample
  title={"Use an empty display string."}
  formula={"=HYPERLINK(\"https://example.com\",\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An error in the destination expression propagates."}
  formula={"=HYPERLINK(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Hyperlink with a friendly name"}
  formula={"=HYPERLINK(\"https://example.com\",\"Example\")"}
  grid={{}}
  expected={"Example"}
/>

## FAQ

### What does HYPERLINK return?
The friendly name when provided, otherwise the link location, always as text.
