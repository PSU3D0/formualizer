Converts text into a reference and returns the referenced value or range.

`INDIRECT` lets formulas build references dynamically from strings such as `"A1"` or
 `"Sheet2!B3:C5"`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=INDIRECT(ref_text, [a1])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `ref_text` | text | Required | — |
| `a1` | logical or number | Optional | `true` |

## Return type

Can return a reference when evaluated in a reference context.

## Remarks
 - `a1_style` defaults to `TRUE` (A1 style parsing).
 - The function is volatile because target references can change without direct dependency links.

## Differences from Excel
 R1C1 cell and range references selected with `a1_style=FALSE` return `#N/IMPL!` in Formualizer.

## Error cases

 - Invalid or unresolved references return `#REF!`.

## Examples

<FunctionExample
  title={"Resolve an A1-style address provided as text."}
  formula={"=INDIRECT(\"A1\")"}
  grid={{"A1":"99"}}
  expected={"99"}
/>

<FunctionExample
  title={"Resolve an absolute A1-style reference and explicitly select A1 notation."}
  formula={"=INDIRECT(\"$B$2\",TRUE)"}
  grid={{"B2":"42"}}
  expected={"42"}
/>

<FunctionExample
  title={"Resolve the reference to an empty cell."}
  formula={"=INDIRECT(\"B1\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A string that cannot be resolved to a reference returns an error."}
  formula={"=INDIRECT(\"not a reference\")"}
  grid={{}}
  expected={"#REF!"}
/>

<FunctionExample
  title={"Resolve a range and aggregate it"}
  formula={"=SUM(INDIRECT(\"A1:A3\"))"}
  grid={{"A1":"5","A2":"7","A3":"9"}}
  expected={"21"}
/>

## FAQ

### What happens if a1_style is FALSE?
R1C1 cell and range references are unsupported. Defined names and table references can still resolve with either flag.

### How are bad reference strings reported?
If the text cannot be parsed or resolved to a valid reference, INDIRECT returns #REF!.
