Converts a value to text representation.

`VALUETOTEXT(value, [format])` supports concise (`0`) and strict (`1`) modes.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VALUETOTEXT(value, [format])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |
| `format` | number | Optional | `0` |

## Return type

Can return text.

## Remarks
 - Concise mode (`0`) returns natural text for scalars.
 - Strict mode (`1`) adds explicit quoting for text and serializes arrays with braces.
 - In concise mode, error values are propagated as errors.
 - In strict mode, error values are rendered as their error text.

## Examples

<FunctionExample
  title={"Convert a number to its concise text form."}
  formula={"=VALUETOTEXT(42)"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"Request strict output to see how a text value is represented."}
  formula={"=VALUETOTEXT(\"Visit\",1)"}
  grid={{}}
  expected={"\"Visit\""}
/>

<FunctionExample
  title={"Request the strict representation of empty text."}
  formula={"=VALUETOTEXT(\"\",1)"}
  grid={{}}
  expected={"\"\""}
/>

<FunctionExample
  title={"In concise mode an input error propagates as an error value."}
  formula={"=VALUETOTEXT(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Concise text conversion"}
  formula={"=VALUETOTEXT(123)"}
  grid={{}}
  expected={"123"}
/>

<FunctionExample
  title={"Strict quoting for text"}
  formula={"=VALUETOTEXT(\"hello\", 1)"}
  grid={{}}
  expected={"\"hello\""}
/>

## FAQ

### How are errors handled in concise vs strict mode?
Concise mode returns the error, while strict mode converts the error to its text form.
