Returns the Unicode character for a given code point.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=UNICHAR(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |

## Remarks
 - Input is truncated to an integer code point.
 - Errors are propagated unchanged.
 - Non-numeric inputs are coerced with numeric coercion rules.

## Error cases

 - Code point `0`, surrogate range, and values above `0x10FFFF` return `#VALUE!`.
