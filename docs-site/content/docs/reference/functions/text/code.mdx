Returns a numeric code for the first character in a text string.

Returns the numeric code of the first character in text.

 `CODE` mirrors Excel behavior with Windows-1252 compatibility mappings.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CODE(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Remarks
 - Only the first character is inspected.
 - Text-like coercion is applied to non-text scalar inputs.
 - Known Unicode characters in the Windows-1252 extension map back to their Excel codes.

## Error cases

 - Empty text returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Return the numeric character code for the first character in a string."}
  formula={"=CODE(\"ABC\")"}
  grid={{}}
  expected={"65"}
/>

<FunctionExample
  title={"Change the leading character while keeping the rest of the string."}
  formula={"=CODE(\"aBC\")"}
  grid={{}}
  expected={"97"}
/>

<FunctionExample
  title={"Read the numeric code of a single space."}
  formula={"=CODE(\" \")"}
  grid={{}}
  expected={"32"}
/>

<FunctionExample
  title={"An empty string has no first character to encode."}
  formula={"=CODE(\"\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"ASCII code"}
  formula={"=CODE(\"A\")"}
  grid={{}}
  expected={"65"}
/>

<FunctionExample
  title={"Extended mapping"}
  formula={"=CODE(CHAR(128))"}
  grid={{}}
  expected={"128"}
/>

## FAQ

### What if the input text is empty?
CODE returns #VALUE! because there is no first character to evaluate.
