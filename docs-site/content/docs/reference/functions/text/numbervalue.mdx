Converts locale-delimited text to a number.

Parses text using explicit decimal and group separators, independent of the
 workbook's invariant locale.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NUMBERVALUE(text, [decimal_separator], [group_separator])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `decimal_separator` | any | Optional | — |
| `group_separator` | any | Optional | — |

## Remarks
 - The decimal separator defaults to `.`.
 - The group separator defaults to `,`.
 - Percent suffixes are supported and scale the result by 100 per suffix.

## Examples

<FunctionExample
  title={"Convert a decimal string using the default separators."}
  formula={"=NUMBERVALUE(\"1234.56\")"}
  grid={{}}
  expected={"1234.56"}
/>

<FunctionExample
  title={"Supply a comma decimal separator and a dot group separator."}
  formula={"=NUMBERVALUE(\"1.234,56\",\",\",\".\")"}
  grid={{}}
  expected={"1234.56"}
/>

<FunctionExample
  title={"Convert the single digit zero."}
  formula={"=NUMBERVALUE(\"0\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Nonnumeric text cannot be parsed as a number."}
  formula={"=NUMBERVALUE(\"unknown\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Parse percent suffix"}
  formula={"=NUMBERVALUE(\"12.5%\")"}
  grid={{}}
  expected={"0.125"}
/>

## FAQ

### Does NUMBERVALUE use the global locale?
No. Decimal and group separators are passed explicitly as arguments.
