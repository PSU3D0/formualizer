Searches text using non-DBCS byte-compatible semantics.

In Formualizer's invariant locale, SEARCHB delegates to SEARCH and supports
 the same wildcard behavior.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SEARCHB(find_text, within_text, [start_num])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `find_text` | any | Required | — |
| `within_text` | any | Required | — |
| `start_num` | any | Optional | — |

## How it works

Delegates to SEARCH. Returns the one-based character position of a case-insensitive match, with Excel-style wildcards, in Formualizer’s invariant locale. It returns an error if there is no match at or after the start.

### Is SEARCHB case-sensitive?
No. It follows SEARCH behavior in the invariant locale.
