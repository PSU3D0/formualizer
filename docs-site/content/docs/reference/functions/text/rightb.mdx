Returns the rightmost characters using non-DBCS byte-compatible semantics.

In Formualizer's invariant locale, RIGHTB delegates to RIGHT.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=RIGHTB(text, [num_bytes])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `num_bytes` | any | Optional | — |

## How it works

Delegates to RIGHT. Takes up to the final n Unicode scalar characters in Formualizer’s invariant locale. At zero it returns empty text, and a negative count is invalid.

<FunctionExample

  formula={"=RIGHTB(\"xyzé界\",0)"}

<FunctionExample
  title={"A negative count cannot select a suffix."}
  formula={"=RIGHTB(\"xyzé界\",-1)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Right byte-compatible characters"}
  formula={"=RIGHTB(\"hello\",2)"}
  grid={{}}
  expected={"lo"}
/>

## FAQ

### Does RIGHTB count DBCS bytes?
Not currently. In the invariant locale it matches RIGHT.
