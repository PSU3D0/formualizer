Converts text to uppercase.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=UPPER(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Uses ASCII uppercasing semantics in this implementation.
 - Numbers and booleans are first converted to text.
 - Errors are propagated unchanged.

## Examples

<FunctionExample
  title={"Apply the case conversion to two words with mixed capitalization."}
  formula={"=UPPER(\"eAST team\")"}
  grid={{}}
  expected={"EAST TEAM"}
/>

<FunctionExample
  title={"Convert text that also includes digits and punctuation."}
  formula={"=UPPER(\"Q2-sales\")"}
  grid={{}}
  expected={"Q2-SALES"}
/>

<FunctionExample
  title={"Case conversion of an empty string yields empty text."}
  formula={"=UPPER(\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An input error propagates before any text conversion."}
  formula={"=UPPER(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Uppercase letters"}
  formula={"=UPPER(\"Quarterly report\")"}
  grid={{}}
  expected={"QUARTERLY REPORT"}
/>

<FunctionExample
  title={"Number coerced to text"}
  formula={"=UPPER(123)"}
  grid={{}}
  expected={"123"}
/>

## FAQ

### Is uppercasing fully Unicode-aware?
This implementation uses ASCII uppercasing semantics, so non-ASCII case rules are limited.
