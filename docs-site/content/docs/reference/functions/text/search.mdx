Returns the 1-based position of one text string inside another.

`SEARCH` is case-insensitive and supports `*` and `?` wildcards.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SEARCH(find_text, within_text, [start_num])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `find_text` | any | Required | — |
| `within_text` | any | Required | — |
| `start_num` | any | Optional | — |

## Remarks
 - Search is case-insensitive.
 - `*` matches any sequence and `?` matches a single character.
 - `start_num` is 1-based and must be greater than `0`.

## Error cases

 - If no match is found, returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Find a substring without matching letter case."}
  formula={"=SEARCH(\"BO\",\"Ana and bo\")"}
  grid={{}}
  expected={"9"}
/>

<FunctionExample
  title={"Start at the second position and find the later occurrence."}
  formula={"=SEARCH(\"A\",\"A-B-a\",2)"}
  grid={{}}
  expected={"5"}
/>

<FunctionExample
  title={"A one-character text has its match at the first position."}
  formula={"=SEARCH(\"A\",\"A\")"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"The requested letters do not occur together in the source."}
  formula={"=SEARCH(\"Cy\",\"Ana and bo\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Case-insensitive search"}
  formula={"=SEARCH(\"world\", \"Hello World\")"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"Wildcard pattern"}
  formula={"=SEARCH(\"d?ta*\", \"Meta Data Lake\")"}
  grid={{}}
  expected={"6"}
/>

## FAQ

### How are case and wildcards handled?
SEARCH is case-insensitive and supports * for any sequence plus ? for one character.
