Returns a numeric value for the character count in a non-DBCS locale.

In Formualizer's invariant locale, LENB delegates to LEN.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LENB(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Number

## How it works

Delegates to LEN. Sums one for each Unicode scalar character in Formualizer’s invariant locale. The result can differ from a byte count in a double-byte Excel locale.

## Examples

<FunctionExample
  title={"Count the four letters, one space and four digits in the label."}
  formula={"=LENB(\"East 2024\")"}
  grid={{}}
  expected={"9"}
/>

<FunctionExample
  title={"The two Unicode characters contribute one each in Formualizer."}
  formula={"=LENB(\"é界\")"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"Empty text has zero character positions."}
  formula={"=LENB(\"\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The input error propagates before any characters can be counted."}
  formula={"=LENB(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Length of text"}
  formula={"=LENB(\"abc\")"}
  grid={{}}
  expected={"3"}
/>

## FAQ

### Does LENB count UTF-8 bytes?
No. In the invariant locale it matches LEN.
