Replaces matching text within a string.

`SUBSTITUTE` can replace all occurrences or only a specific instance.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUBSTITUTE(text, old_text, new_text, [instance_num])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `old_text` | any | Required | — |
| `new_text` | any | Required | — |
| `instance_num` | any | Optional | — |

## Remarks
 - Matching is case-sensitive.
 - If `old_text` is empty, the original text is returned unchanged.
 - With `instance_num`, only that 1-based occurrence is replaced.

## Error cases

 - Non-positive `instance_num` returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Replace every occurrence of the target text."}
  formula={"=SUBSTITUTE(\"A-B-A\",\"A\",\"X\")"}
  grid={{}}
  expected={"X-B-X"}
/>

<FunctionExample
  title={"Replace only the second occurrence."}
  formula={"=SUBSTITUTE(\"A-B-A\",\"A\",\"X\",2)"}
  grid={{}}
  expected={"A-B-X"}
/>

<FunctionExample
  title={"Remove the target occurrences by replacing them with an empty string."}
  formula={"=SUBSTITUTE(\"A-B-A\",\"A\",\"\")"}
  grid={{}}
  expected={"-B-"}
/>

<FunctionExample
  title={"The occurrence index must start at one."}
  formula={"=SUBSTITUTE(\"A-B-A\",\"A\",\"X\",0)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Replace all matches"}
  formula={"=SUBSTITUTE(\"a-b-a\", \"a\", \"x\")"}
  grid={{}}
  expected={"x-b-x"}
/>

<FunctionExample
  title={"Replace only second match"}
  formula={"=SUBSTITUTE(\"2024-01-2024\", \"2024\", \"FY24\", 2)"}
  grid={{}}
  expected={"2024-01-FY24"}
/>

## FAQ

### Is SUBSTITUTE case-sensitive?
Yes. It matches old_text with exact case and replaces either all or the requested instance.
