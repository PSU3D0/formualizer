Compares two text values for exact equality.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=EXACT(text1, text2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text1` | any | Required | — |
| `text2` | any | Required | — |

## Return type

Can return a logical value (TRUE or FALSE).

## Remarks
 - Comparison is case-sensitive.
 - No wildcard semantics are applied.
 - Non-text values are converted to text before comparison.
 - Errors in either argument are propagated.

## Examples

<FunctionExample
  title={"Compare two identical text values."}
  formula={"=EXACT(\"Team\",\"Team\")"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Change letter case while leaving the characters otherwise equal."}
  formula={"=EXACT(\"Team\",\"team\")"}
  grid={{}}
  expected={"FALSE"}
/>

<FunctionExample
  title={"Two zero-length strings compare equal."}
  formula={"=EXACT(\"\",\"\")"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"An error in a comparison input propagates."}
  formula={"=EXACT(\"Team\",1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Exact same text"}
  formula={"=EXACT(\"Form\", \"Form\")"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Case difference is not equal"}
  formula={"=EXACT(\"Form\", \"form\")"}
  grid={{}}
  expected={"FALSE"}
/>

## FAQ

### Does EXACT perform case-sensitive comparison?
Yes. EXACT compares the resulting text values with exact case and character equality.
