Formats a number as currency text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DOLLAR(number, [decimals])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `decimals` | number | Optional | `2` |

## Return type

Can return text.

## Remarks
 - Default decimal places is `2` when omitted.
 - Negative values are rendered in parentheses, such as `($1,234.00)`.
 - Uses comma group separators and dollar symbol.
 - Input coercion failures or propagated errors return an error.

## Examples

<FunctionExample
  title={"Format a positive amount using the default number of decimal places."}
  formula={"=DOLLAR(1234.567)"}
  grid={{}}
  expected={"$1,234.57"}
/>

<FunctionExample
  title={"Format a negative amount with one decimal digit."}
  formula={"=DOLLAR(-1234.567,1)"}
  grid={{}}
  expected={"($1,234.6)"}
/>

<FunctionExample
  title={"Format zero with no decimal digits."}
  formula={"=DOLLAR(0,0)"}
  grid={{}}
  expected={"$0"}
/>

<FunctionExample
  title={"The amount cannot be read from nonnumeric text."}
  formula={"=DOLLAR(\"amount\",2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Default currency formatting"}
  formula={"=DOLLAR(1234.5)"}
  grid={{}}
  expected={"$1,234.50"}
/>

<FunctionExample
  title={"Negative value with zero decimals"}
  formula={"=DOLLAR(-999.4, 0)"}
  grid={{}}
  expected={"($999)"}
/>
