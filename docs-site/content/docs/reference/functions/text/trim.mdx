Removes leading/trailing whitespace and collapses internal runs to single spaces.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TRIM(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Leading and trailing whitespace is removed.
 - Consecutive whitespace inside the text is collapsed to one ASCII space.
 - Non-text inputs are coerced to text before trimming.
 - Errors are propagated unchanged.

## Examples

<FunctionExample
  title={"Remove leading and trailing spaces and collapse interior space runs."}
  formula={"=TRIM(\"  East   Team  \")"}
  grid={{}}
  expected={"East Team"}
/>

<FunctionExample
  title={"Trim padding around a single word."}
  formula={"=TRIM(\" East \")"}
  grid={{}}
  expected={"East"}
/>

<FunctionExample
  title={"A string consisting entirely of spaces becomes empty."}
  formula={"=TRIM(\"   \")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An input error propagates before trimming."}
  formula={"=TRIM(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Normalize spacing"}
  formula={"=TRIM(\"  alpha   beta  \")"}
  grid={{}}
  expected={"alpha beta"}
/>

<FunctionExample
  title={"Already clean text"}
  formula={"=TRIM(\"report\")"}
  grid={{}}
  expected={"report"}
/>

### What whitespace does TRIM normalize?
It trims edges and collapses internal whitespace runs to single spaces.
