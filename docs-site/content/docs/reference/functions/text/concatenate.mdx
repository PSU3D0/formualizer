Legacy function that joins multiple scalar values as text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CONCATENATE(text1, [text2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text1` | any | Required | — |
| `text2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Can return text.

## Remarks
 - Range and array arguments use only their top-left value.
 - Blank values contribute an empty string.
 - Numbers and booleans are coerced to text.
 - Errors are propagated as soon as encountered.

## Examples

<FunctionExample
  title={"Join region and year labels with an explicit separator."}

<FunctionExample
  title={"A single argument is already the entire concatenated result."}

<FunctionExample

<FunctionExample
  title={"Legacy concatenate behavior"}

## FAQ

### Is CONCATENATE behavior different from CONCAT here?
Yes. CONCAT expands ranges and arrays, while legacy CONCATENATE uses only the top-left value.
