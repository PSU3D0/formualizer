Splits text into a dynamic 2D array by column and optional row delimiters.

`TEXTSPLIT` supports multiple delimiters, optional case-insensitive matching, and output padding.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TEXTSPLIT(text, col_delimiter, [row_delimiter], [ignore_empty], [match_mode], [pad_with])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `col_delimiter` | any | Required | — |
| `row_delimiter` | any | Optional | — |
| `ignore_empty` | logical | Optional | `false` |
| `match_mode` | number | Optional | `0` |
| `pad_with` | any | Optional | `#N/A` |

## Remarks
 - Column delimiter is required; row delimiter is optional.
 - `match_mode=0` is case-sensitive, `match_mode=1` is case-insensitive.
 - `ignore_empty=TRUE` drops empty segments created by adjacent delimiters.
 - Rows are padded to equal width using `pad_with` (default `#N/A`).

## Examples

<FunctionExample
  title={"Split one comma-separated row into columns."}
  formula={"=TEXTSPLIT(\"East,West\",\",\")"}
  grid={{}}
  expected={"{\"East\", \"West\"}"}
/>

<FunctionExample
  title={"Split on either case of X, skip empty pieces, and pad the shorter final row with text."}
  formula={"=TEXTSPLIT(\"EastX10;WestXX20;North\",\"x\",\";\",TRUE,1,\"missing\")"}
  grid={{}}
  expected={"{\"East\", \"10\"; \"West\", \"20\"; \"North\", \"missing\"}"}
/>

<FunctionExample
  title={"With no delimiter occurrence the result contains a single piece of text."}
  formula={"=TEXTSPLIT(\"East\",\",\")"}
  grid={{}}
  expected={"East"}
/>

<FunctionExample
  title={"An error in the delimiter argument prevents splitting."}
  formula={"=TEXTSPLIT(\"East,West\",1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Split CSV row"}
  formula={"=TEXTSPLIT(\"A,B,C\", \",\")"}
  grid={{}}
  expected={"{\"A\", \"B\", \"C\"}"}
/>

<FunctionExample
  title={"Row and column split with padding"}
  formula={"=TEXTSPLIT(\"A,B;C\", \",\", \";\")"}
  grid={{}}
  expected={"{\"A\", \"B\"; \"C\", #N/A}"}
/>

## FAQ

### Is delimiter matching case-sensitive?
Yes by default; set match_mode to 1 for case-insensitive delimiter matching.
