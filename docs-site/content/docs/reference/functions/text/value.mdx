Converts text that represents a number into a numeric value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VALUE(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Remarks
 - Parsing uses locale-aware invariant number parsing from the function context.
 - Date and time text becomes its serial (`VALUE("12/31/00")` is 36891; two-digit years 00-29 are 2000-2029, 30-99 are 1930-1999).
 - Booleans and numbers are first coerced to text, then parsed.
 - Errors are propagated unchanged.

## Error cases

 - Other non-numeric text, and `NaN`/`inf` spellings, return `#VALUE!`.

## FAQ

### Does VALUE coerce arbitrary text like TRUE/FALSE?
VALUE parses numeric, date and time text only; other strings return #VALUE!.
