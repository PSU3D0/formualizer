Returns the Unicode code point of the first character in text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=UNICODE(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Remarks
 - Only the first character is evaluated.
 - Non-text inputs are coerced to text before inspection.
 - Errors are propagated unchanged.

## Error cases

 - Empty text returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Return the numeric character code for the first character in a string."}
  formula={"=UNICODE(\"ABC\")"}
  grid={{}}
  expected={"65"}
/>

<FunctionExample
  title={"Change the leading character while keeping the rest of the string."}
  formula={"=UNICODE(\"aBC\")"}
  grid={{}}
  expected={"97"}
/>

<FunctionExample
  title={"Read the numeric code of a single space."}
  formula={"=UNICODE(\" \")"}
  grid={{}}
  expected={"32"}
/>

<FunctionExample
  title={"An empty string has no first character to encode."}
  formula={"=UNICODE(\"\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Code point for letter A"}
  formula={"=UNICODE(\"A\")"}
  grid={{}}
  expected={"65"}
/>

<FunctionExample
  title={"Code point for emoji"}
  formula={"=UNICODE(\"😀\")"}
  grid={{}}
  expected={"128512"}
/>

## FAQ

### If text has multiple characters, which one is used?
UNICODE inspects only the first character and ignores the rest.
