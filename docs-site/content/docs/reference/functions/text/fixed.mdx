Formats a number as text with fixed decimal places.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FIXED(number, [decimals], [no_commas])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `decimals` | number | Optional | `2` |
| `no_commas` | logical | Optional | `false` |

## Return type

Can return text.

## Remarks
 - Default decimal places is `2` when omitted.
 - Third argument controls comma grouping (`TRUE` disables commas).
 - Values are rounded to the requested decimal precision.

## Error cases

 - Numeric coercion failures return `#VALUE!`.

## Examples

<FunctionExample
  title={"Format a number with the default precision and digit grouping."}
  formula={"=FIXED(1234.567)"}
  grid={{}}
  expected={"1,234.57"}
/>

<FunctionExample
  title={"Use one decimal place and suppress the grouping separator."}
  formula={"=FIXED(1234.567,1,TRUE)"}
  grid={{}}
  expected={"1234.6"}
/>

<FunctionExample
  title={"Format zero without decimal digits."}
  formula={"=FIXED(0,0)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A nonnumeric amount cannot be formatted as a number."}
  formula={"=FIXED(\"amount\",2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Fixed with commas"}
  formula={"=FIXED(12345.678, 1, FALSE)"}
  grid={{}}
  expected={"12,345.7"}
/>

<FunctionExample
  title={"Fixed without commas"}
  formula={"=FIXED(12345.678, 1, TRUE)"}
  grid={{}}
  expected={"12345.7"}
/>

## FAQ

### What does the third argument control?
Set it to TRUE to suppress thousands separators; FALSE keeps comma grouping.
