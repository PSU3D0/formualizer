Removes non-printable ASCII control characters from text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CLEAN(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Characters with codes `0..31` are removed.
 - Printable whitespace like regular spaces is preserved.
 - Non-text inputs are coerced to text before cleaning.
 - Errors are propagated unchanged.

## Examples

<FunctionExample
  title={"Remove a line-feed control character embedded between letters."}
  formula={"=CLEAN(\"A\"&CHAR(10)&\"B\")"}
  grid={{}}
  expected={"AB"}
/>

<FunctionExample
  title={"Remove tab and carriage-return characters while preserving the letter."}
  formula={"=CLEAN(CHAR(9)&\"A\"&CHAR(13))"}
  grid={{}}
  expected={"A"}
/>

<FunctionExample
  title={"Cleaning an empty string gives an empty string."}
  formula={"=CLEAN(\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An input error propagates before any cleaning can occur."}
  formula={"=CLEAN(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Printable spaces remain"}
  formula={"=CLEAN(\"A B\")"}
  grid={{}}
  expected={"A B"}
/>

## FAQ

### Does CLEAN remove normal spaces or only control characters?
It removes only ASCII control characters (0-31); regular printable spaces remain.
