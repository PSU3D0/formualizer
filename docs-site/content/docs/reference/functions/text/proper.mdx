Capitalizes the first letter of each alphanumeric word.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=PROPER(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Word boundaries are reset by non-alphanumeric characters.
 - Internal letters in each word are lowercased.
 - Non-text inputs are coerced to text.
 - Errors are propagated unchanged.

## Examples

<FunctionExample
  title={"Apply the case conversion to two words with mixed capitalization."}
  formula={"=PROPER(\"eAST team\")"}
  grid={{}}
  expected={"East Team"}
/>

<FunctionExample
  title={"Convert text that also includes digits and punctuation."}
  formula={"=PROPER(\"Q2-sales\")"}
  grid={{}}
  expected={"Q2-Sales"}
/>

<FunctionExample
  title={"Case conversion of an empty string yields empty text."}
  formula={"=PROPER(\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An input error propagates before any text conversion."}
  formula={"=PROPER(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Title case simple phrase"}
  formula={"=PROPER(\"hello world\")"}
  grid={{}}
  expected={"Hello World"}
/>

<FunctionExample
  title={"Hyphen-separated words"}
  formula={"=PROPER(\"north-east REGION\")"}
  grid={{}}
  expected={"North-East Region"}
/>

## FAQ

### How are word boundaries determined?
Any non-alphanumeric character starts a new word boundary for capitalization.
