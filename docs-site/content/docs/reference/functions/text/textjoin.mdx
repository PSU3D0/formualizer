Joins text values using a delimiter, with optional empty-value filtering.

`TEXTJOIN(delimiter, ignore_empty, text1, ...)` is useful for building labels and lists.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TEXTJOIN(delimiter, ignore_empty, text1, [text2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `delimiter` | any | Required | — |
| `ignore_empty` | any | Required | — |
| `text1` | any (range) | Required | — |
| `text2` | value | Optional | — |

Accepts a variable number of arguments. Minimum: 3.

## Return type

Can return text.

## Remarks
 - `ignore_empty=TRUE` skips empty strings and empty cells.
 - `ignore_empty=FALSE` includes empty items, which can produce adjacent delimiters.
 - Text ranges and arrays are flattened in row-major order.
 - Delimiter and values are coerced to text.
 - Any error in inputs propagates immediately.

## Error cases

 - Results longer than 32,767 characters return `#VALUE!`.

## Examples

<FunctionExample
  title={"Join text while skipping empty items."}
  formula={"=TEXTJOIN(\", \",TRUE,\"East\",\"\",\"West\")"}
  grid={{}}
  expected={"East, West"}
/>

<FunctionExample
  title={"Keep the empty item so it contributes a separator position."}
  formula={"=TEXTJOIN(\", \",FALSE,\"East\",\"\",\"West\")"}
  grid={{}}
  expected={"East, , West"}
/>

<FunctionExample
  title={"A single nonempty item needs no delimiter."}
  formula={"=TEXTJOIN(\", \",TRUE,\"East\")"}
  grid={{}}
  expected={"East"}
/>

<FunctionExample
  title={"A division-by-zero error among the inputs propagates."}
  formula={"=TEXTJOIN(\", \",TRUE,\"East\",1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Ignore empty entries"}
  formula={"=TEXTJOIN(\",\", TRUE, \"a\", \"\", \"c\")"}
  grid={{}}
  expected={"a,c"}
/>

<FunctionExample
  title={"Keep empty entries"}
  formula={"=TEXTJOIN(\"-\", FALSE, \"a\", \"\", \"c\")"}
  grid={{}}
  expected={"a--c"}
/>

## FAQ

### What does ignore_empty change?
TRUE skips empty values; FALSE keeps them, which can create adjacent delimiters.
