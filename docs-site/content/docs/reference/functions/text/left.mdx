Returns the leftmost characters from a text value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LEFT(text, [num_chars])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `num_chars` | any | Optional | — |

## Return type

Can return text.

## Remarks
 - `num_chars` defaults to `1` when omitted.
 - If `num_chars` exceeds length, the full text is returned.
 - Non-text values are coerced to text before slicing.

## Error cases

 - Negative `num_chars` returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Extract four ASCII characters from the selected end of a label."}
  formula={"=LEFT(\"East-2024\",4)"}
  grid={{}}
  expected={"East"}
/>

<FunctionExample
  title={"Omit the count and use the default of one."}
  formula={"=LEFT(\"East-2024\")"}
  grid={{}}
  expected={"E"}
/>

<FunctionExample
  title={"A count of zero yields empty text."}
  formula={"=LEFT(\"East-2024\",0)"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"A negative extraction count is invalid."}
  formula={"=LEFT(\"East-2024\",-1)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Take first two characters"}
  formula={"=LEFT(\"Formualizer\", 2)"}
  grid={{}}
  expected={"Fo"}
/>

<FunctionExample
  title={"Default count is one"}
  formula={"=LEFT(\"Data\")"}
  grid={{}}
  expected={"D"}
/>

## FAQ

### What if num_chars is negative?
LEFT returns #VALUE! when num_chars is below zero.
