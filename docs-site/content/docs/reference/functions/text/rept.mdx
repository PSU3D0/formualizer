Repeats text a given number of times.

Repeats a text string a specified number of times.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=REPT(text, number_times)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `number_times` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Repeat count is truncated to an integer.
 - Non-text first argument is coerced to text.

## Error cases

 - Negative counts return `#VALUE!`, including fractions such as `-0.5`.
 - Output longer than 32,767 characters returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Repeat a two-character string three times."}
  formula={"=REPT(\"ab\",3)"}

<FunctionExample
  title={"Zero repetitions produce empty text."}
  formula={"=REPT(\"ab\",0)"}

  expected={"#VALUE!"}
/>

  formula={"=REPT(\"x\", -1)"}

## FAQ

### Can REPT return very long strings?
Only up to 32,767 characters; longer results return #VALUE! like Excel.
