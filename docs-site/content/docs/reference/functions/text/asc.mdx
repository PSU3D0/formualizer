Converts full-width Latin and ASCII characters to half-width text.

Maps full-width ASCII punctuation, digits, letters, and ideographic space to
 their half-width equivalents while leaving other characters unchanged.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ASC(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Can return text.

## Examples

<FunctionExample
  title={"Convert full-width Latin letters and digits to their narrow forms."}
  formula={"=ASC(\"ＡＢＣ１２３\")"}
  grid={{}}
  expected={"ABC123"}
/>

<FunctionExample
  title={"Convert a mixture of wide and narrow characters."}
  formula={"=ASC(\"ＡBＣ\")"}
  grid={{}}
  expected={"ABC"}
/>

<FunctionExample
  title={"An empty input produces empty text."}
  formula={"=ASC(\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An error in the text argument propagates."}
  formula={"=ASC(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Convert ideographic space"}
  formula={"=ASC(\"Ａ　Ｂ\")"}
  grid={{}}
  expected={"A B"}
/>

## FAQ

### Are non-ASCII full-width characters transliterated?
No. ASC only maps the full-width ASCII block and ideographic space.
