Returns the rightmost characters from a text value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=RIGHT(text, [num_chars])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `num_chars` | any | Optional | — |

## Return type

Can return text.

## Remarks
 - `num_chars` defaults to `1` when omitted.
 - If `num_chars` exceeds length, the full text is returned.
 - Non-text values are coerced to text before slicing.

## Error cases

 - Negative `num_chars` returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Extract four ASCII characters from the selected end of a label."}
  formula={"=RIGHT(\"East-2024\",4)"}
  grid={{}}
  expected={"2024"}
/>

<FunctionExample
  title={"Omit the count and use the default of one."}
  formula={"=RIGHT(\"East-2024\")"}
  grid={{}}
  expected={"4"}
/>

<FunctionExample
  title={"A count of zero yields empty text."}
  formula={"=RIGHT(\"East-2024\",0)"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"A negative extraction count is invalid."}
  formula={"=RIGHT(\"East-2024\",-1)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Take last three characters"}
  formula={"=RIGHT(\"engine\", 3)"}
  grid={{}}
  expected={"ine"}
/>

<FunctionExample
  title={"Default count is one"}
  formula={"=RIGHT(\"abc\")"}
  grid={{}}
  expected={"c"}
/>

## FAQ

### If num_chars is larger than the text length, what is returned?
RIGHT returns the full text when the requested count exceeds available characters.
