Converts text to lowercase.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LOWER(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Uses ASCII lowercasing semantics in this implementation.
 - Numbers and booleans are first converted to text.
 - Errors are propagated unchanged.

## Examples

<FunctionExample
  title={"Apply the case conversion to two words with mixed capitalization."}
  formula={"=LOWER(\"eAST team\")"}
  grid={{}}
  expected={"east team"}
/>

<FunctionExample
  title={"Convert text that also includes digits and punctuation."}
  formula={"=LOWER(\"Q2-sales\")"}
  grid={{}}
  expected={"q2-sales"}
/>

<FunctionExample
  title={"Case conversion of an empty string yields empty text."}
  formula={"=LOWER(\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"An input error propagates before any text conversion."}
  formula={"=LOWER(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Lowercase letters"}
  formula={"=LOWER(\"Data PIPELINE\")"}
  grid={{}}
  expected={"data pipeline"}
/>

<FunctionExample
  title={"Boolean coerced to text"}
  formula={"=LOWER(TRUE)"}
  grid={{}}
  expected={"true"}
/>

## FAQ

### How are booleans handled by LOWER?
Inputs are coerced to text first, so TRUE/FALSE become lowercase string values.
