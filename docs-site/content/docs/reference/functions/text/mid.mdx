Returns a substring starting at a 1-based position.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MID(text, start_num, num_chars)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `start_num` | any | Required | — |
| `num_chars` | any | Required | — |

## Return type

Can return text.

## Remarks
 - If start is beyond the end of the text, returns an empty string.
 - Non-text inputs are coerced to text.

## Error cases

 - `start_num` is 1-based; values below `1` return `#VALUE!`.
 - `num_chars` must be non-negative; negatives return `#VALUE!`.

## Examples

<FunctionExample
  title={"Extract the year from the middle of a label by position."}
  formula={"=MID(\"East-2024\",6,4)"}
  grid={{}}
  expected={"2024"}
/>

<FunctionExample
  title={"A requested count beyond the remaining text reaches only the end."}
  formula={"=MID(\"East-2024\",6,20)"}
  grid={{}}
  expected={"2024"}
/>

<FunctionExample
  title={"A zero count produces an empty substring."}
  formula={"=MID(\"East-2024\",6,0)"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"A start position of zero is invalid."}
  formula={"=MID(\"East-2024\",0,4)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Extract middle segment"}
  formula={"=MID(\"spreadsheet\", 3, 5)"}
  grid={{}}
  expected={"reads"}
/>

<FunctionExample
  title={"Start past end returns empty"}
  formula={"=MID(\"abc\", 10, 2)"}
  grid={{}}
  expected={""}
/>

## FAQ

### How does MID handle out-of-range start positions?
If start_num is beyond the text length, MID returns an empty string.
