Extracts text from the middle using non-DBCS byte-compatible semantics.

In Formualizer's invariant locale, MIDB delegates to MID.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MIDB(text, start_num, num_bytes)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `start_num` | any | Required | — |
| `num_bytes` | any | Required | — |

## How it works

Delegates to MID. Starting at a one-based character index, takes up to the requested count of Unicode scalar characters. A nonpositive starting position or negative count is invalid.

<FunctionExample

<FunctionExample
  title={"Request zero characters starting at é."}
  formula={"=MIDB(\"aé界z\",2,0)"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"The start is one-based, so zero is invalid."}
  formula={"=MIDB(\"aé界z\",0,2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Middle byte-compatible characters"}
  formula={"=MIDB(\"abcdef\",2,3)"}
  grid={{}}
  expected={"bcd"}
/>
