Concatenates multiple values into one text string.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CONCAT(text1, [text2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text1` | any (range) | Required | — |
| `text2` | any (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Can return text.

## Remarks
 - Accepts one or more arguments.
 - Ranges and arrays are flattened in row-major order.
 - Blank values contribute an empty string.
 - Numbers and booleans are coerced to text.
 - Errors are propagated as soon as encountered.

## Error cases

 - Results longer than 32,767 characters return `#VALUE!`.

## Examples

<FunctionExample
  title={"Join region and year labels with an explicit separator."}
  formula={"=CONCAT(\"East\",\" \",\"2024\")"}
  grid={{}}
  expected={"East 2024"}
/>

<FunctionExample
  title={"Combine text and numeric values in argument order."}
  formula={"=CONCAT(\"Team \",42,\" score \",8)"}
  grid={{}}
  expected={"Team 42 score 8"}
/>

<FunctionExample
  title={"A single argument is already the entire concatenated result."}
  formula={"=CONCAT(\"Only item\")"}
  grid={{}}
  expected={"Only item"}
/>

<FunctionExample
  title={"A division-by-zero error among the inputs propagates."}
  formula={"=CONCAT(\"East\",1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Join text pieces"}
  formula={"=CONCAT(\"Q\", 1, \"-\", \"2026\")"}
  grid={{}}
  expected={"Q1-2026"}
/>

<FunctionExample
  title={"Concatenate with blanks"}
  formula={"=CONCAT(\"A\", \"\", \"B\")"}
  grid={{}}
  expected={"AB"}
/>

## FAQ

### Do blank arguments add separators or characters?
No. CONCAT appends each value directly, and blanks contribute an empty string.
