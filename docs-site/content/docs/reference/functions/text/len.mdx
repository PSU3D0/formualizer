Returns the number of characters in a text value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LEN(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Remarks
 - Counts Unicode scalar characters, not bytes.
 - Empty values return `0`.
 - Non-text values are converted to their text form before counting.
 - Errors are propagated unchanged.

## Examples

<FunctionExample
  title={"Count the length of a label containing an internal space."}
  formula={"=LEN(\"East 2024\")"}
  grid={{}}
  expected={"9"}
/>

<FunctionExample
  title={"Measure text containing non-ASCII characters."}
  formula={"=LEN(\"é界\")"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"Empty text has a length of zero."}
  formula={"=LEN(\"\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A division-by-zero input propagates."}
  formula={"=LEN(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Basic text length"}
  formula={"=LEN(\"hello\")"}
  grid={{}}
  expected={"5"}
/>

<FunctionExample
  title={"Whitespace is counted"}
  formula={"=LEN(\"a b\")"}
  grid={{}}
  expected={"3"}
/>

## FAQ

### Does LEN ignore spaces?
No. LEN counts spaces and other visible characters as part of the total length.
