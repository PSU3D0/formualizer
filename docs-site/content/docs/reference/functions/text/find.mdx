Returns the 1-based position of one text string inside another.

`FIND` is case-sensitive and does not interpret wildcard characters.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FIND(find_text, within_text, [start_num])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `find_text` | any | Required | — |
| `within_text` | any | Required | — |
| `start_num` | any | Optional | — |

## Remarks
 - Search is case-sensitive (`"A"` and `"a"` are different).
 - `start_num` is 1-based and must be greater than `0`.
 - Errors in either argument are propagated.

## Error cases

 - If no match is found, returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Find the position of an exact lowercase substring."}
  formula={"=FIND(\"bo\",\"Ana and bo\")"}
  grid={{}}
  expected={"9"}
/>

<FunctionExample
  title={"Skip the first character by supplying a starting position."}
  formula={"=FIND(\"A\",\"A-B-A\",2)"}
  grid={{}}
  expected={"5"}
/>

<FunctionExample
  title={"A one-character text has its match at the first position."}
  formula={"=FIND(\"A\",\"A\")"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"The uppercase B prevents the case-sensitive search from matching."}
  formula={"=FIND(\"Bo\",\"Ana and bo\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Case-sensitive match"}
  formula={"=FIND(\"World\", \"Hello World\")"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"Case mismatch fails"}
  formula={"=FIND(\"world\", \"Hello World\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

## FAQ

### Do wildcard characters work in FIND?
No. FIND treats * and ? as literal characters and matches case-sensitively.
