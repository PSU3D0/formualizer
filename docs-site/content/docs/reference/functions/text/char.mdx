Returns the character specified by a number Excel uses Windows-1252 encoding for codes 1-255.

Returns the character represented by a numeric code.

 `CHAR` follows Excel-style Windows-1252 behavior for codes `1..255`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHAR(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |

## Return type

Can return text.

## Remarks
 - Input is truncated to an integer code.
 - Codes in the Windows-1252 extension range (128-159) are mapped to Unicode equivalents.
 - Errors are propagated unchanged.

## Error cases

 - Valid code range is `1` through `255`; outside this range returns `#VALUE!`.

## FAQ

### Which character set does CHAR use for codes 128-159?
It follows Excel-style Windows-1252 mappings, including extended symbols in that range.
