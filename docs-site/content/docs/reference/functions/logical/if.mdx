Returns one value when a condition is TRUE and another when FALSE.

`IF(condition, value_if_true, [value_if_false])` supports two or three arguments.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IF(logical_test, value_if_true, [value_if_false])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `logical_test` | any | Required | — |
| `value_if_true` | any | Required | — |
| `value_if_false` | any | Optional | — |

## Return type

Can return a reference when evaluated in a reference context.

## Remarks
 - Condition coercion: booleans are used directly, numbers use `0` as FALSE and non-zero as TRUE.
 - A blank condition is treated as FALSE.
 - With only two arguments, the FALSE branch defaults to logical `FALSE`.
 - Array and range conditions select elementwise. Scalar branches and singleton
   axes broadcast; incompatible non-singleton dimensions return `#VALUE!`.
 - Each needed branch evaluates once; an unused branch is not evaluated and
   does not contribute to the result shape. Condition errors remain positional.
 - Generated arrays use the shared size cap (`#NUM!`); cancellation and
   resource failures abort evaluation rather than becoming array elements.

## Error cases

 - Text or other non-numeric/non-boolean conditions return `#VALUE!`.

## Examples

<FunctionExample
  title={"Choose between two text values with a numeric comparison."}
  formula={"=IF(2>1,\"Large\",\"Small\")"}
  grid={{}}
  expected={"Large"}
/>

<FunctionExample
  title={"Omit the value for a false comparison."}
  formula={"=IF(2>1,\"Large\")"}
  grid={{}}
  expected={"Large"}
/>

<FunctionExample
  title={"Equal values make the strict greater-than comparison false."}
  formula={"=IF(2>2,\"Large\",\"Small\")"}
  grid={{}}
  expected={"Small"}
/>

<FunctionExample
  title={"The selected result expression divides by zero."}
  formula={"=IF(2>1,1/0,0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Numeric condition"}
  formula={"=IF(2, \"yes\", \"no\")"}
  grid={{}}
  expected={"yes"}
/>

<FunctionExample
  title={"Two-argument IF defaults false branch"}
  formula={"=IF(0, 10)"}
  grid={{}}
  expected={"FALSE"}
/>

## FAQ

### What is returned when IF has only two arguments and condition is FALSE?
The false branch defaults to logical FALSE when value_if_false is omitted.
