Returns the logical constant FALSE.

Use `FALSE` for the logical value false in formulas.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FALSE`

## Return type

Can return a logical value (TRUE or FALSE).

## Remarks
 - `FALSE` takes no arguments and always returns the boolean value `FALSE`.
 - No coercion or evaluation side effects are involved.

## Examples
