Returns TRUE when any supplied value evaluates to TRUE.

`OR` evaluates every argument left to right, as Excel does: a `TRUE`
 does not hide a later error.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=OR(logical1, [logical2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `logical1` | any | Required | — |
| `logical2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Logical (TRUE or FALSE)

## Remarks
 - Booleans and numbers are accepted (`0` is FALSE, non-zero is TRUE).
 - Text and blank cells inside a reference or array are ignored.
 - A direct text argument yields `#VALUE!`.
 - The first error in argument order (ranges scanned row by row) is returned.
 - With no logical values at all, the result is `#VALUE!`.

## Examples

<FunctionExample
  title={"Combine one true condition with one false condition."}
  formula={"=OR(TRUE,FALSE)"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Add a third condition and compare the result."}
  formula={"=OR(TRUE,TRUE,FALSE)"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Evaluate the logical operation with just one false argument."}
  formula={"=OR(FALSE)"}
  grid={{}}
  expected={"FALSE"}
/>

<FunctionExample
  title={"A supplied argument evaluates to an error."}
  formula={"=OR(TRUE,1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"One truthy value makes OR true"}
  formula={"=OR(FALSE, 0, 2)"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"No true values and text input"}
  formula={"=OR(FALSE, \"x\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

## FAQ

### How does OR treat blanks and text?
Text and blank cells in a reference or array are ignored; a direct text argument returns #VALUE!. If nothing logical remains, OR returns #VALUE!.
