Returns the logical constant TRUE.

Use `TRUE` for the logical value true in formulas.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TRUE`

## Return type

Can return a logical value (TRUE or FALSE).

## Remarks
 - `TRUE` takes no arguments and always returns the boolean value `TRUE`.
 - No coercion or evaluation side effects are involved.
