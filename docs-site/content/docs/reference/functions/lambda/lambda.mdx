Creates an anonymous callable that can be invoked with spreadsheet arguments.

`LAMBDA` captures its defining local scope and returns a reusable function value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LAMBDA([parameter1, ...], calculation)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `parameter1` | any | Optional | — |
| `calculation` | any | Required | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - All arguments except the last are parameter names; the last argument is the body expression.
 - Parameter names must be unique (case-insensitive), or `#VALUE!` is returned.
 - Invocation arity must exactly match the declared parameter count.
 - Returning an uninvoked lambda as a final cell value yields a `#CALC!` in evaluation.

## Differences from Excel
 Excel-style immediate invocation, such as `LAMBDA(x,x+1)(1)`, returns `#N/IMPL!` in
 Formualizer. Bind the LAMBDA to a name with LET before invoking it.

## Examples

<FunctionExample
  title={"Bind a one-parameter calculation to a local name and invoke it."}
  formula={"=LET(double,LAMBDA(amount,amount*2),double(7))"}
  grid={{}}
  expected={"14"}
/>

<FunctionExample
  title={"Invoke a local calculation with separate price and quantity arguments."}
  formula={"=LET(total,LAMBDA(price,quantity,price*quantity),total(7,3))"}
  grid={{}}
  expected={"21"}
/>

<FunctionExample
  title={"Invoke a locally bound calculation that has no parameters."}
  formula={"=LET(answer,LAMBDA(42),answer())"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"An error in the body is returned when the locally bound function is invoked."}
  formula={"=LET(double,LAMBDA(amount,amount/0),double(7))"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Inline invocation returns an unsupported operation error"}
  formula={"=LAMBDA(x,x+1)(41)"}
  grid={{}}
  expected={"#N/IMPL!"}
/>

<FunctionExample
  title={"Lambda captures outer LET bindings"}
  formula={"=LET(k,10,addk,LAMBDA(n,n+k),addk(5))"}
  grid={{}}
  expected={"15"}
/>

<FunctionExample
  title={"Duplicate parameter names are invalid"}

  grid={{}}

## FAQ

### Why does =LAMBDA(x,x+1) return #CALC! instead of a number?
LAMBDA returns a callable value. In a cell result position, invoke a local binding such as =LET(inc,LAMBDA(x,x+1),inc(1)).

### Does a LAMBDA read outer LET variables at call time or definition time?
Definition time. The closure captures its lexical environment when created.

### Can I call a LAMBDA with fewer or extra arguments?
No. Invocation arity must match the declared parameter count exactly, or #VALUE! is returned.
