Returns distinct rows or columns from a range.

`UNIQUE` preserves first-occurrence order and can optionally return only values that appear once.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=UNIQUE(array, [by_col], [exactly_once])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range (range) | Required | — |
| `by_col` | logical | Optional | `false` |
| `exactly_once` | logical | Optional | `false` |

## Remarks
 - Defaults: `by_col=FALSE`, `exactly_once=FALSE`.
 - With `by_col=FALSE`, uniqueness is evaluated by full rows.
 - With `by_col=TRUE`, uniqueness is evaluated by full columns.
 - With `exactly_once=TRUE`, only entries with frequency 1 are returned.
 - Result spills as an array.

## Examples

<FunctionExample
  title={"Return one entry for each distinct region."}
  formula={"=UNIQUE({\"East\";\"West\";\"East\"})"}
  grid={{}}
  expected={"{\"East\"; \"West\"}"}
/>

<FunctionExample
  title={"Return only names that occur exactly once."}
  formula={"=UNIQUE({\"East\";\"West\";\"East\"},FALSE,TRUE)"}
  grid={{}}
  expected={"West"}
/>

<FunctionExample
  title={"A single entry is its own unique result."}
  formula={"=UNIQUE({\"East\"})"}
  grid={{}}
  expected={"East"}
/>

<FunctionExample
  title={"A division-by-zero error propagates from the input."}
  formula={"=UNIQUE(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Unique values by row"}
  formula={"=UNIQUE(A1:A4)"}
  grid={{"A1":"\"A\"","A2":"\"A\"","A3":"\"B\"","A4":"\"C\""}}
  expected={"{\"A\"; \"B\"; \"C\"}"}
/>

<FunctionExample
  title={"Only values that appear once"}
  formula={"=UNIQUE(A1:A4,FALSE,TRUE)"}
  grid={{"A1":"1","A2":"1","A3":"2","A4":"3"}}
  expected={"{2; 3}"}
/>

## FAQ

### What does exactly_once=TRUE change?
Instead of returning first occurrences, UNIQUE returns only rows or columns whose full key appears exactly one time.

### How does by_col affect uniqueness checks?
by_col=FALSE compares entire rows, while by_col=TRUE compares entire columns and spills unique columns.
