Looks up a value in one array and returns the aligned value from another array.

`XLOOKUP` supports exact, approximate, and wildcard matching with forward or reverse search.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `lookup_value` | any | Required | — |
| `lookup_array` | range (range) | Required | — |
| `return_array` | range (range) | Required | — |
| `if_not_found` | any | Optional | — |
| `match_mode` | number | Optional | `0` |
| `search_mode` | number | Optional | `1` |

## Remarks
 - Defaults: `match_mode=0` (exact), `search_mode=1` (first-to-last).
 - In exact and wildcard modes, a blank lookup value selects only a blank candidate; numeric zero and empty text remain distinct.
 - `match_mode`: `0` exact, `-1` exact-or-next-smaller, `1` exact-or-next-larger, `2` wildcard.
 - `search_mode`: `1` forward, `-1` reverse; approximate `2`/`-2` use linear forward/reverse fallback with ascending/descending sorted input.
 - Exact/wildcard `2`/`-2` retain forward fallback. Approximate ties follow scan direction.
 - Approximate modes otherwise retain the ascending-input requirement.
 - If `return_array` is multi-column or multi-row, the matched row/column is returned as a spill.

## Error cases

 - `if_not_found` is optional; if omitted and no match exists, returns `#N/A`.
 - `lookup_array` must be 1D. Invalid shape returns `#VALUE!`.

## Examples

  title={"Find a name and return the corresponding number."}

<FunctionExample
  title={"Use a custom result for a missing key."}

  grid={{}}
  expected={"No match"}
/>

<FunctionExample
  title={"Search a one-item array from the end for an exact match."}
  formula={"=XLOOKUP(\"Bo\",{\"Bo\"},{20},\"\",0,-1)"}
  grid={{}}
  expected={"20"}
/>

<FunctionExample
  title={"A missing lookup without a fallback returns an error."}
  formula={"=XLOOKUP(\"Dee\",{\"Ana\";\"Bo\";\"Cy\"},{10;20;30})"}
  grid={{}}
  expected={"#N/A"}
/>

<FunctionExample

  formula={"=XLOOKUP(102,A2:A3,B2:B3,\"Missing\")"}

## FAQ

### How do match_mode and search_mode interact?
match_mode controls exact/approximate/wildcard behavior, while search_mode controls scan direction; reverse search (-1) returns the last matching position.

### What happens when no match is found?
If if_not_found is provided, XLOOKUP returns that value; otherwise it returns #N/A.

### Why do I get #VALUE! from XLOOKUP on valid ranges?
The lookup_array must be one-dimensional (single row or single column); multi-row-and-column lookup ranges return #VALUE!.
