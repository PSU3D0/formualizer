Filters rows from an array using a Boolean include mask.

`FILTER` returns only rows where the include condition evaluates to true.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FILTER(array, include, [if_empty])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range (range) | Required | — |
| `include` | range (range) | Required | — |
| `if_empty` | any | Optional | — |

## Remarks
 - `include` must have the same row count as `array`, or a single row used as broadcast.
 - A row is kept if any include cell for that row is truthy.
 - If no rows match, `if_empty` is returned when supplied; otherwise `#CALC!`.
 - Results spill as dynamic arrays.

## Error cases

 - Dimension mismatches return `#VALUE!`.

## Examples

<FunctionExample
  title={"Keep two rows according to a Boolean selector."}
  formula={"=FILTER({10;20;30},{TRUE;FALSE;TRUE})"}
  grid={{}}
  expected={"{10; 30}"}
/>

<FunctionExample
  title={"Supply a text fallback for an empty filtered result."}
  formula={"=FILTER({10;20;30},{FALSE;FALSE;FALSE},\"No match\")"}
  grid={{}}
  expected={"No match"}
/>

<FunctionExample
  title={"Filter the smallest nonempty array with one true condition."}
  formula={"=FILTER({10},{TRUE})"}
  grid={{}}
  expected={"10"}
/>

<FunctionExample
  title={"An empty result without a fallback returns an error."}
  formula={"=FILTER({10;20;30},{FALSE;FALSE;FALSE})"}
  grid={{}}
  expected={"#CALC!"}
/>

<FunctionExample
  title={"Filter active records"}
  formula={"=FILTER(A1:A3,B1:B3)"}
  grid={{"A1":"\"Ana\"","A2":"\"Bo\"","A3":"\"Cy\"","B1":"TRUE","B2":"FALSE","B3":"TRUE"}}
  expected={"{\"Ana\"; \"Cy\"}"}
/>

<FunctionExample
  title={"Return fallback when no rows match"}
  formula={"=FILTER(A1:A2,B1:B2,\"No matches\")"}
  grid={{"A1":"10","A2":"20","B1":"FALSE","B2":"FALSE"}}
  expected={"No matches"}
/>

## FAQ

### What happens when include has no TRUE rows?
FILTER returns if_empty when provided; otherwise it returns #CALC! to signal an empty result set.

### How strict is include shape matching?
include must match array row count or be a single broadcast row; incompatible dimensions return #VALUE!.
