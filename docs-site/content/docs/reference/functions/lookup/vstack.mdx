Concatenates arrays vertically into a single spilled array.

`VSTACK` appends rows from each argument top-to-bottom.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VSTACK(array1, [array2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array1` | range or any (range) | Required | — |
| `array2` | range or any (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - The output has the maximum input column count.
 - Scalar arguments are treated as 1x1 values.
 - Missing columns in narrower inputs are padded with `#N/A`.
 - Empty inputs are skipped; if all inputs are empty, result is an empty spill.

## Examples

<FunctionExample
  title={"Join two equally sized rectangular arrays."}
  formula={"=VSTACK({1,2;3,4},{5,6;7,8})"}
  grid={{}}
  expected={"{1, 2; 3, 4; 5, 6; 7, 8}"}
/>

<FunctionExample
  title={"Join three arrays in their argument order."}
  formula={"=VSTACK({1,2},{3,4},{5,6})"}
  grid={{}}
  expected={"{1, 2; 3, 4; 5, 6}"}
/>

<FunctionExample
  title={"Pass the smallest array as the only argument."}
  formula={"=VSTACK({42})"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"A division-by-zero error is carried into the assembled output."}
  formula={"=VSTACK(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}

<FunctionExample

  formula={"=VSTACK(A1:B1,A2:B2)"}
  grid={{"A1":"1","A2":"2","B1":"10","B2":"20"}}
  expected={"{1, 10; 2, 20}"}

<FunctionExample
  title={"Stack scalar values"}

## FAQ

### How does VSTACK combine ranges of different widths?
The output uses the widest input and pads narrower inputs with #N/A.

### What happens if all VSTACK inputs are empty ranges?
Empty inputs are skipped, and if every argument is empty the function returns an empty spill.
