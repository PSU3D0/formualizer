Concatenates arrays horizontally into a single spilled array.

`HSTACK` appends columns from each argument left-to-right.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HSTACK(array1, [array2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array1` | range or any (range) | Required | — |
| `array2` | range or any (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - The output has the maximum input row count.
 - Scalar arguments are treated as 1x1 values.
 - Missing rows in shorter inputs are padded with `#N/A`.
 - Empty inputs are skipped; if all inputs are empty, result is an empty spill.

## Examples

<FunctionExample
  title={"Join two equally sized rectangular arrays."}
  formula={"=HSTACK({1,2;3,4},{5,6;7,8})"}
  grid={{}}
  expected={"{1, 2, 5, 6; 3, 4, 7, 8}"}
/>

<FunctionExample
  title={"Join three arrays in their argument order."}
  formula={"=HSTACK({1,2},{3,4},{5,6})"}
  grid={{}}
  expected={"{1, 2, 3, 4, 5, 6}"}
/>

<FunctionExample
  title={"Pass the smallest array as the only argument."}
  formula={"=HSTACK({42})"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"A division-by-zero error is carried into the assembled output."}
  formula={"=HSTACK(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Join two 2-row ranges side by side"}
  formula={"=HSTACK(A1:A2,B1:B2)"}
  grid={{"A1":"1","A2":"2","B1":"10","B2":"20"}}
  expected={"{1, 10; 2, 20}"}
/>

<FunctionExample
  title={"Append a scalar column"}
  formula={"=HSTACK(A1,\"OK\")"}
  grid={{"A1":"\"Item\""}}

/>

## FAQ

### How does HSTACK combine ranges of different heights?
The output uses the tallest input and pads shorter inputs with #N/A.

### How are scalar arguments treated in HSTACK?
Each scalar is treated as a 1x1 block, with #N/A below it when other inputs are taller.
