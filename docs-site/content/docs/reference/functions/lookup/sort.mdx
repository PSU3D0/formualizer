Sorts an array by a selected row or column and returns a spilled result.

`SORT` can order rows (default) or columns.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SORT(array, [sort_index], [sort_order], [by_col])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range (range) | Required | — |
| `sort_index` | number | Optional | `1` |
| `sort_order` | number | Optional | `1` |
| `by_col` | logical | Optional | `false` |

## Remarks
 - Defaults: `sort_index=1`, `sort_order=1` (ascending), `by_col=FALSE`.
 - `sort_index` is 1-based in the active sort axis.
 - `sort_order &lt; 0` sorts descending; otherwise ascending.
 - Empty input returns an empty spill.

## Error cases

 - Invalid sort indexes return `#VALUE!`.

## Examples

<FunctionExample
  title={"Sort a column in ascending order."}
  formula={"=SORT({30;10;20})"}
  grid={{}}
  expected={"{10; 20; 30}"}
/>

<FunctionExample
  title={"Sort a two-column table descending by its first column."}
  formula={"=SORT({30,\"Cy\";10,\"Ana\";20,\"Bo\"},1,-1)"}
  grid={{}}
  expected={"{30, \"Cy\"; 20, \"Bo\"; 10, \"Ana\"}"}
/>

<FunctionExample
  title={"Sorting a one-element array leaves the element in place."}
  formula={"=SORT({42})"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"A sort index outside the available columns cannot select a key."}
  formula={"=SORT({30;10;20},2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Sort rows by second column"}
  formula={"=SORT(A1:B3,2,1,FALSE)"}
  grid={{"A1":"\"C\"","A2":"\"A\"","A3":"\"B\"","B1":"30","B2":"10","B3":"20"}}
  expected={"{\"A\", 10; \"B\", 20; \"C\", 30}"}
/>

<FunctionExample
  title={"Sort columns by first row descending"}
  formula={"=SORT(A1:C2,1,-1,TRUE)"}
  grid={{"A1":"1","A2":"\"A\"","B1":"3","B2":"\"C\"","C1":"2","C2":"\"B\""}}
  expected={"{3, 2, 1; \"C\", \"B\", \"A\"}"}
/>

## FAQ

### What changes when by_col is TRUE?
SORT reorders columns instead of rows, and sort_index is interpreted as a row index used as the sort key.

### What causes #VALUE! in SORT?
If sort_index is outside the active axis (row or column axis based on by_col), SORT returns #VALUE!.
