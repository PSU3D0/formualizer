Converts an array or range into a single row.

Flattens input values into one row, with options to ignore blanks/errors and
 to scan by row or by column.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TOROW(array, [ignore], [scan_by_column])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range or any (range) | Required | — |
| `ignore` | number | Optional | `0` |
| `scan_by_column` | logical or number | Optional | `false` |

## Remarks
 - `ignore` values are `0` keep all, `1` ignore blanks, `2` ignore errors, `3` ignore both.
 - `scan_by_column` defaults to FALSE, so values are read row by row.

## Examples

<FunctionExample
  title={"Flatten a rectangular array with the default scanning order."}
  formula={"=TOROW({1,2;3,4})"}
  grid={{}}
  expected={"{1, 2, 3, 4}"}
/>

<FunctionExample
  title={"Scan down each column before advancing to the next."}
  formula={"=TOROW({1,2;3,4},0,TRUE)"}
  grid={{}}
  expected={"{1, 3, 2, 4}"}
/>

<FunctionExample
  title={"Flatten an array containing just one value."}
  formula={"=TOROW({42})"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"An unsupported ignore code cannot select a filtering rule."}
  formula={"=TOROW({1,2;3,4},9)"}
  grid={{}}
  expected={"#VALUE!"}
/>

## FAQ

### Does TOROW preserve row order by default?
Yes. The default scan order is row-major.
