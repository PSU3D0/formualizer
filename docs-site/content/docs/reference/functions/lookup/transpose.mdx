Swaps rows and columns in an input range.

`TRANSPOSE` returns a spilled array whose shape is the inverse of the source shape.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TRANSPOSE(array)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range (range) | Required | — |

## Remarks
 - Input with shape `R x C` returns output shape `C x R`.
 - Empty input returns an empty spill.
 - Errors in source cells are preserved in transposed positions.

## Examples

<FunctionExample
  title={"Turn a two-row, three-column rectangle into a three-row, two-column rectangle."}
  formula={"=TRANSPOSE({1,2,3;4,5,6})"}
  grid={{}}
  expected={"{1, 4; 2, 5; 3, 6}"}
/>

<FunctionExample
  title={"Turn a text column into a row."}
  formula={"=TRANSPOSE({\"A\";\"B\";\"C\"})"}
  grid={{}}
  expected={"{\"A\", \"B\", \"C\"}"}
/>

<FunctionExample
  title={"A single-cell array keeps the same dimensions."}
  formula={"=TRANSPOSE({42})"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"An error cannot be transposed as a rectangular array."}
  formula={"=TRANSPOSE(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Transpose a row into a column"}
  formula={"=TRANSPOSE(A1:C1)"}
  grid={{"A1":"10","B1":"20","C1":"30"}}
  expected={"{10; 20; 30}"}
/>

<FunctionExample
  title={"Transpose a 2x2 matrix"}
  formula={"=TRANSPOSE(A1:B2)"}
  grid={{"A1":"1","A2":"3","B1":"2","B2":"4"}}
  expected={"{1, 3; 2, 4}"}
/>

## FAQ

### What happens to errors inside the source array?
TRANSPOSE preserves error values and only changes their position in the output matrix.

### Does TRANSPOSE return a scalar for 1x1 inputs?
Yes. After transposition, a 1x1 result collapses to a scalar in this engine.
