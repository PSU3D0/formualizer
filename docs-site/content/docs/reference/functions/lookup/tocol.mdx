Converts an array or range into a single column.

Flattens input values into one column, with options to ignore blanks/errors
 and to scan by row or by column.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TOCOL(array, [ignore], [scan_by_column])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range or any (range) | Required | — |
| `ignore` | number | Optional | `0` |
| `scan_by_column` | logical or number | Optional | `false` |

## Remarks
 - `ignore` values are `0` keep all, `1` ignore blanks, `2` ignore errors, `3` ignore both.
 - `scan_by_column` defaults to FALSE, so values are read row by row.

## Examples

<FunctionExample
  title={"Flatten a rectangular array with the default scanning order."}
  formula={"=TOCOL({1,2;3,4})"}
  grid={{}}
  expected={"{1; 2; 3; 4}"}
/>

<FunctionExample
  title={"Scan down each column before advancing to the next."}
  formula={"=TOCOL({1,2;3,4},0,TRUE)"}
  grid={{}}
  expected={"{1; 3; 2; 4}"}
/>

<FunctionExample
  title={"Flatten an array containing just one value."}
  formula={"=TOCOL({42})"}
  grid={{}}
  expected={"42"}
/>

<FunctionExample
  title={"An unsupported ignore code cannot select a filtering rule."}
  formula={"=TOCOL({1,2;3,4},9)"}
  grid={{}}
  expected={"#VALUE!"}
/>

## FAQ

### Can TOCOL filter blanks and errors?
Yes. Use the ignore argument to drop blanks, errors, or both.
