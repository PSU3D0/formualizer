Returns selected columns from an array or range.

`CHOOSECOLS` builds a new spilled array containing only the requested columns, in the
 order provided.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHOOSECOLS(array, col_num1, [col_num2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | range or any (range) | Required | — |
| `col_num1` | number | Required | — |
| `col_num2` | value | Optional | — |

Accepts a variable number of arguments. Minimum: 2.

## Remarks
 - Column indexes are 1-based; negative indexes count from the end (`-1` is last column).
 - Repeated indexes are allowed and duplicate columns in the output.
 - The result spills as an array unless it collapses to a single cell.

## Error cases

 - Index `0` or out-of-bounds indexes return `#VALUE!`.

## Examples

<FunctionExample
  title={"Select the middle column from a two-row array."}
  formula={"=CHOOSECOLS({1,2,3;4,5,6},2)"}
  grid={{}}
  expected={"{2; 5}"}
/>

<FunctionExample
  title={"Use a negative index to select the last column, then append the first."}
  formula={"=CHOOSECOLS({1,2,3;4,5,6},-1,1)"}
  grid={{}}
  expected={"{3, 1; 6, 4}"}
/>

<FunctionExample
  title={"A one-cell input also has a first column."}
  formula={"=CHOOSECOLS({7},1)"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"A column index beyond the array dimensions is invalid."}
  formula={"=CHOOSECOLS({1,2,3;4,5,6},4)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Select first and third columns"}
  formula={"=CHOOSECOLS(A1:C2,1,3)"}
  grid={{"A1":"\"Name\"","A2":"\"Ana\"","B1":"\"Dept\"","B2":"\"Ops\"","C1":"\"Score\"","C2":"91"}}
  expected={"{\"Name\", \"Score\"; \"Ana\", 91}"}
/>

<FunctionExample
  title={"Select the last column with a negative index"}
  formula={"=CHOOSECOLS(A1:C1,-1)"}
  grid={{"A1":"10","B1":"20","C1":"30"}}
  expected={"30"}
/>

## FAQ

### How do negative column indexes work?
Negative indexes count from the right edge of the array, so -1 selects the last column, -2 the second-to-last, and so on.

### What triggers #VALUE! in CHOOSECOLS?
Index 0 and any index whose absolute position falls outside the source width return #VALUE!.
