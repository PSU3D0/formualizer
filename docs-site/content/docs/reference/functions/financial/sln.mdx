Returns straight-line depreciation for a single period.

`SLN` spreads the depreciable amount (`cost - salvage`) evenly across `life` periods.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SLN(cost, salvage, life)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `cost` | number | Required | — |
| `salvage` | number | Required | — |
| `life` | number | Required | — |

## Remarks
 - Formula: `(cost - salvage) / life`.
 - This function returns the algebraic result: if `salvage &gt; cost`, depreciation is negative.
 - Inputs are interpreted as scalar numeric values in matching currency/period units.

## Error cases

 - `life` must be non-zero; `life = 0` returns `#DIV/0!`.

## FAQ

### Can `SLN` return a negative value?
Yes. If `salvage &gt; cost`, `(cost - salvage) / life` is negative.

### What happens when `life` is zero?
`SLN` returns `#DIV/0!`.
