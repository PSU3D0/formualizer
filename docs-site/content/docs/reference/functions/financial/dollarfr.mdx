Converts a decimal dollar value into fractional-dollar notation.

This is the inverse-style formatting helper used for quoted fractional price conventions.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DOLLARFR(decimal_dollar, fraction)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `decimal_dollar` | number | Required | — |
| `fraction` | number | Required | — |

## Remarks
 - `fraction` is truncated to an integer denominator and must be `&gt;= 1`.
 - Sign convention: sign is preserved (`-x` maps to `-result`).
 - No periodic rate is involved in this conversion.
 - Fraction output is encoded by denominator digit width (`ceil(log10(fraction))`).

## Error cases

 - Returns `#NUM!` when `fraction &lt; 1` after truncation.

## FAQ

### How does `DOLLARFR` encode the fractional part?
It scales the numerator into decimal digits based on `ceil(log10(fraction))`, preserving the input sign.
