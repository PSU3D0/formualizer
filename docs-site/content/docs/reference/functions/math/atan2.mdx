Returns the arctangent of `y/x`, preserving quadrant information.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ATAN2(x_num, y_num)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x_num` | number | Required | — |
| `y_num` | number | Required | — |

## Remarks
 - Formualizer uses Excel-style argument order: `ATAN2(x_num, y_num)`.

## Error cases

 - Returns `#DIV/0!` when both arguments are zero.

## FAQ

### Why does ATAN2 return #DIV/0! at (0,0)?
The origin has no defined direction angle, so ATAN2 reports #DIV/0!.
