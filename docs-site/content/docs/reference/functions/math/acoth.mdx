Returns the inverse hyperbolic cotangent of a number.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ACOTH(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Inverts hyperbolic cotangent. The real expression ln((x + 1) / (x − 1)) / 2 requires |x| &gt; 1.

## FAQ

### When does ACOTH return #NUM!?
ACOTH requires |x| &gt; 1, so inputs between -1 and 1 inclusive return #NUM!.
