Rounds a number down to the nearest multiple of a significance.

This implementation defaults significance to `1` and normalizes negative significance to positive.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FLOOR(number, significance)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Required | — |

## Differences from Excel

Formualizer defaults the significance to 1 if it is omitted. Excel requires it.

## Remarks
 - If `significance` is omitted, `1` is used.
 - Negative significance is treated as its absolute value in this fallback behavior.

## Error cases

 - `significance = 0` returns `#DIV/0!`.

## FAQ

### Why does FLOOR move negative values farther from zero?
FLOOR rounds down to a lower multiple, which is more negative for negative inputs.
