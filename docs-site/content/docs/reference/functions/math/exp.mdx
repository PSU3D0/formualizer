Returns Euler's number `e` raised to the given power.

`EXP` is the inverse of `LN` for positive-domain values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=EXP(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## Remarks
 - Computes `e^x` using floating-point math.
 - Input errors are propagated.

## Error cases

 - Finite inputs that overflow floating-point range return `#NUM!`.

## FAQ

### Can EXP overflow?
Yes. Very large finite positive inputs return #NUM! on overflow.
