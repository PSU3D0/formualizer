Returns the positive square root of a number.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SQRT(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## Remarks
 - Input must be greater than or equal to zero.

## Error cases

 - Negative input returns `#NUM!`.

## FAQ

### When does SQRT return #NUM!?
It returns #NUM! for negative inputs because real square roots are undefined there.
