Returns the hyperbolic secant of a number, defined as `1 / COSH(x)`.

`SECH` produces values in `(0, 1]` for real inputs.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SECH(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |

## How it works

Hyperbolic secant is 1 / cosh(x). It is defined for all real x and reaches its maximum of 1 at zero.

## Remarks
 - Domain: accepts any real number.
 - Radians: this function is hyperbolic, so the input is not treated as an angle in radians.

## Error cases

 - Errors: no function-specific domain errors are produced.

## FAQ

### Can SECH be negative for real inputs?
No. For real numbers, SECH = 1/COSH is always positive.
