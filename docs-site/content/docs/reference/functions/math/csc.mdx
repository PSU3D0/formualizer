Returns the cosecant of an angle, defined as `1 / SIN(angle)`.

Use `CSC` for reciprocal-sine calculations in radian-based formulas.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CSC(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Cosecant is 1 / sin(x) for a radian angle x. It is undefined where sine is zero, at integer multiples of π.

## Remarks
 - Domain: valid for all real angles except where `SIN(angle) = 0`.
 - Radians: input is interpreted in radians.

## Error cases

 - Errors: returns `#DIV/0!` at or near integer multiples of `PI()`.

## FAQ

### When does CSC return #DIV/0!?
CSC returns #DIV/0! when SIN(angle) is effectively zero.
