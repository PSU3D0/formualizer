Multiplies aligned values across arrays and returns the sum of those products.

`SUMPRODUCT` supports scalar or range inputs, applies broadcast semantics, and accumulates
 the product for each aligned cell position.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUMPRODUCT(array1, [array2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array1` | number (range) | Required | — |
| `array2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Non-numeric values are treated as `0` during multiplication.
 - Any explicit error value in the inputs propagates immediately.

## Error cases

 - Input shapes must be broadcast-compatible; otherwise `SUMPRODUCT` returns `#VALUE!`.

## FAQ

### Why does SUMPRODUCT return #VALUE! with some array shapes?
The argument arrays must be broadcast-compatible; incompatible shapes raise #VALUE!.

### How are text values handled in multiplication?
Non-numeric values are treated as 0, unless an explicit error is present.
