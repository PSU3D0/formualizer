Returns the mathematical constant π.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=PI()`

## Remarks
 - `PI()` takes no arguments.
 - Commonly used with trig and geometry formulas.

## Examples

<FunctionExample
  title={"Return the constant pi at spreadsheet precision."}
  formula={"=PI()"}
  grid={{}}
  expected={"3.14159265358979"}
/>

<FunctionExample
  title={"Use pi in the circumference formula for a circle of radius three."}
  formula={"=2*PI()*3"}
  grid={{}}
  expected={"18.8495559215388"}
/>

<FunctionExample
  title={"The area expression for a circle of radius zero evaluates to zero."}
  formula={"=PI()*0^2"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Circle circumference with radius 2"}
  formula={"=2*PI()*2"}
  grid={{}}
  expected={"12.5663706143592"}
/>

## FAQ

### Can PI take arguments?
No. PI() has arity zero and always returns the same constant.
