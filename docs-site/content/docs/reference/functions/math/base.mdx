Converts a non-negative integer to text in the requested radix.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BASE(number, radix, [min_length])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `radix` | number | Required | — |
| `min_length` | number | Optional | — |

## Return type

Can return text.

## Examples

<FunctionExample
  title={"Convert decimal 31 to a two-digit hexadecimal string."}
  formula={"=BASE(31,16)"}
  grid={{}}
  expected={"1F"}
/>

<FunctionExample
  title={"Set a minimum width to pad the hexadecimal result."}
  formula={"=BASE(31,16,5)"}
  grid={{}}
  expected={"0001F"}
/>

<FunctionExample
  title={"Convert zero in the smallest allowed radix."}
  formula={"=BASE(0,2)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Radix one is outside the supported range."}
  formula={"=BASE(31,1)"}
  grid={{}}
  expected={"#NUM!"}
/>

## FAQ

### What bases are supported?
BASE accepts radix values from 2 through 36.
