Rounds a number to a specified number of digits.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ROUND(number, num_digits)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `num_digits` | number | Required | — |

## Remarks
 - Positive `digits` rounds to the right of the decimal point.
 - Negative `digits` rounds to the left of the decimal point.
 - The input is first reduced to 15 significant decimal digits, matching Excel's
   numeric precision, then rounded at the requested position.
 - Halfway cases round away from zero.

## Examples

<FunctionExample
  title={"Round to two places to the right of the decimal point."}
  formula={"=ROUND(12.345,2)"}
  grid={{}}
  expected={"12.35"}
/>

<FunctionExample
  title={"Round to a place left of the decimal point."}
  formula={"=ROUND(127,-1)"}
  grid={{}}
  expected={"130"}
/>

<FunctionExample
  title={"Select zero decimal places to return an integer."}
  formula={"=ROUND(12.345,0)"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"The number cannot be read from nonnumeric text."}
  formula={"=ROUND(\"invalid\",2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Round to two decimals"}
  formula={"=ROUND(3.14159,2)"}
  grid={{}}
  expected={"3.14"}
/>

<FunctionExample
  title={"Round to nearest hundred"}
  formula={"=ROUND(1234,-2)"}
  grid={{}}
  expected={"1200"}
/>

## FAQ

### What does a negative digits argument do in ROUND?
It rounds digits to the left of the decimal point (for example, tens or hundreds).
