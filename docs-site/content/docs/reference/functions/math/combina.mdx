Returns the number of combinations with repetition.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COMBINA(number, number_chosen)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `number_chosen` | number | Required | — |

## FAQ

### How is COMBINA different from COMBIN?
COMBINA counts selections where the same item can be chosen more than once.
