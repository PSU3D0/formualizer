Rounds a number up toward positive infinity using absolute significance.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CEILING.PRECISE(number, [significance])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Optional | — |

## How it works

For nonzero significance s, the result is |s| times the least integer at least x / |s|. The sign of s does not change the result. A zero significance yields zero.

## FAQ

### Does the sign of significance matter?
No. CEILING.PRECISE uses the absolute value of significance.
