Returns the sum of squares of corresponding values from two arrays.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUMX2PY2(array1, array2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array1` | number (range) | Required | — |
| `array2` | number (range) | Required | — |

## FAQ

### Does SUMX2PY2 coerce booleans and blanks?
It follows the same collection rules as the engine's paired-array helpers, coercing booleans and treating blanks/text as zero.
