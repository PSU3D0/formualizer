Returns the logarithm of a number for a specified base.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LOG(number, [base])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `base` | number | Optional | — |

## Differences from Excel

A base of 1 returns `#NUM!` in Formualizer and `#DIV/0!` in Excel.

## Remarks
 - If `base` is omitted, base 10 is used.
 - `number` must be positive.
 - `base` must be positive and not equal to 1.

## Error cases

 - Invalid domains return `#NUM!`.
