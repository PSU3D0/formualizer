Rounds a number down toward negative infinity using absolute significance.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FLOOR.PRECISE(number, [significance])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Optional | — |

## How it works

For nonzero significance s, the result is |s| times the greatest integer at most x / |s|. A zero significance yields zero, and negative numbers round toward negative infinity on the nonzero grid.

## FAQ

### Does FLOOR.PRECISE keep negative significance?
No. Like Excel, this implementation uses the absolute value of significance.
