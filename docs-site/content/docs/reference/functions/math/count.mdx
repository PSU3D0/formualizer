Counts numeric values across scalars and ranges.

`COUNT` evaluates all arguments and counts how many are numeric values.
 Numbers, dates, and text representations of numbers (when supplied directly) are counted.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COUNT(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts a call with no arguments and returns zero. Excel requires the first argument.

## Remarks
 - Text values inside ranges are ignored and not counted.
 - Blank cells and logical values in ranges are ignored.

## Examples

<FunctionExample
  title={"Count numeric values in a range that also includes text."}
  formula={"=COUNT(A1:A3)"}
  grid={{"A1":"3","A2":"\"five\"","A3":"7"}}
  expected={"2"}
/>

<FunctionExample
  title={"Add a literal numeric argument to the range count."}
  formula={"=COUNT(A1:A3,12)"}
  grid={{"A1":"3","A2":"\"five\"","A3":"7"}}
  expected={"3"}
/>

<FunctionExample
  title={"A nonnumeric text argument contributes zero to the count."}
  formula={"=COUNT(\"x\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Counting mixed scalar inputs"}
  formula={"=COUNT(1, \"x\", 2, 3)"}
  grid={{}}
  expected={"3"}
/>

<FunctionExample
  title={"Counting in a range"}
  formula={"=COUNT(A1:A3)"}
  grid={{"A1":"10","A2":"\"foo\"","A3":"20"}}
  expected={"2"}
/>

## FAQ

### Why doesn't COUNT include text in a range?
COUNT only counts numeric values; text cells in ranges are ignored.

### Can direct text like "12" be counted?
Yes. Direct scalar arguments are coerced and counted when they parse as numbers.
