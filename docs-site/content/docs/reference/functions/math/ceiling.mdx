Rounds a number up to the nearest multiple of a significance.

This implementation defaults significance to `1`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CEILING(number, significance)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Required | — |

## Differences from Excel

Formualizer defaults the significance to 1 if it is omitted. Excel requires it.

## Remarks
 - If `significance` is omitted, `1` is used.
 - When both arguments are negative, rounds away from zero; positive significance rounds toward positive infinity.

## Error cases

 - `significance = 0` returns `#DIV/0!`.

## FAQ

### What happens if CEILING significance is 0?
It returns #DIV/0! because a zero multiple is invalid.
