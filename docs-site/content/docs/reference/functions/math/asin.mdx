Returns the angle in radians whose sine is the input value.

Use `ASIN` to recover an angle from a normalized ratio.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ASIN(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Inverts sine on the interval from −π/2 to π/2. A real result exists only for inputs from −1 through 1 inclusive.

## Remarks
 - Domain: input must be between `-1` and `1`, inclusive.
 - Radians: output is in the range `[-PI()/2, PI()/2]`.

## Error cases

 - Errors: returns `#NUM!` when the input is outside the valid domain.

## FAQ

### When does ASIN return #NUM!?
ASIN returns #NUM! when the input is outside the closed interval [-1, 1].
