Returns the secant of an angle, defined as `1 / COS(angle)`.

Use `SEC` for reciprocal-cosine calculations in radian-based formulas.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SEC(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Secant is 1 / cos(x) for a radian angle x. Its poles are π/2 plus integer multiples of π.

## Differences from Excel

At `PI()/2`, Formualizer reports `#DIV/0!` and Excel returns a finite approximation of about 1.63312E+16.

## Remarks
 - Domain: valid for all real angles except where `COS(angle) = 0`.
 - Radians: input is interpreted in radians.

## Error cases

 - Errors: returns `#DIV/0!` near odd multiples of `PI()/2`.

## FAQ

### When does SEC return #DIV/0!?
SEC returns #DIV/0! when COS(angle) is effectively zero.
