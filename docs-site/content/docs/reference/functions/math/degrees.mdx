Converts an angle from radians to degrees.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DEGREES(angle)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `angle` | any | Required | — |

## Remarks
 - Useful when converting the output of inverse trig functions.
 - Output is `radians * 180 / PI()`.

## Examples

<FunctionExample
  title={"Convert a right angle from radians to degrees."}
  formula={"=DEGREES(PI()/2)"}
  grid={{}}
  expected={"90"}

<FunctionExample

<FunctionExample

<FunctionExample
  title={"Convert PI radians"}
  formula={"=DEGREES(PI())"}
  grid={{}}
  expected={"180"}
/>

## FAQ

### Does DEGREES change the angle value or just units?
It converts units only, multiplying radians by 180/PI().
