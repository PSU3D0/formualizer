Returns the tangent of an angle in radians.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TAN(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Tangent is sin(x) / cos(x) for a radian angle x. It is undefined at π/2 plus integer multiples of π.

## Remarks
 - Input is interpreted as radians.
 - Near odd multiples of `PI()/2`, results can become very large.

## FAQ

### Why does TAN explode near PI()/2?
Because COS approaches zero there, TAN can become extremely large in magnitude.
