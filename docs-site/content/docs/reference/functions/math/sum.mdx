Adds numeric values across scalars and ranges.

`SUM` evaluates all arguments, coercing text to numbers where possible,
 and returns the total. Blank cells and logical values in ranges are ignored.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUM(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Number

## Differences from Excel

Formualizer accepts a call with no arguments and returns zero. Excel requires the first argument.

## Remarks
 - If any argument evaluates to an error, `SUM` propagates the first error it encounters.
 - Unparseable text literals (e.g., `"foo"`) will result in a `#VALUE!` error.

## Examples

<FunctionExample
  title={"Add two numeric cells and skip the third cell, which contains the text string N/A."}

<FunctionExample
  title={"The sum of a single zero is zero."}

## FAQ

### Why does SUM return #VALUE! for some text arguments?
Direct scalar text that cannot be parsed as a number raises #VALUE! during coercion.

### Do text and logical values inside ranges get added?
No. In ranged inputs, only numeric cells contribute to the total.
