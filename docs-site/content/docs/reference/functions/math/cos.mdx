Returns the cosine of an angle in radians.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COS(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Cosine is the horizontal coordinate on the unit circle at angle x, measured in radians. Its real domain is unrestricted.

## Remarks
 - Input must be in radians.
 - Supports elementwise evaluation for array inputs.

## FAQ

### Why can COS look wrong for degree values like 60?
COS interprets 60 as radians, not degrees; use COS(RADIANS(60)).
