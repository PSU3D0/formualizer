Returns the hyperbolic cotangent of a number, defined as `COSH(x) / SINH(x)`.

`COTH` is the reciprocal of `TANH` where defined.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COTH(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Hyperbolic cotangent is cosh(x) / sinh(x). The denominator is zero at x = 0, its only real pole.

## Remarks
 - Domain: valid for all real numbers except `0`.
 - Radians: this function is hyperbolic, so the input is not treated as an angle in radians.

## Error cases

 - Errors: returns `#DIV/0!` when `SINH(x)` is zero (at `x = 0`).

## FAQ

### Why is COTH undefined at zero?
COTH divides by SINH(x), and SINH(0) is zero, so #DIV/0! is returned.
