Adds values that satisfy multiple criteria.

`SUMIFS` applies all criteria pairs with logical AND and sums the matching cells.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUMIFS(sum_range, criteria_range1, criteria1, [(criteria_range2, criteria2), ...])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `sum_range` | any | Required | — |
| `criteria_range1` | any | Required | — |
| `criteria1` | any | Required | — |
| `criteria_range2` | any | Optional | — |
| `criteria2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 3.

## Differences from Excel

Formualizer accepts array constants as ranges. Excel requires references. An invalid INDIRECT result in the result range can raise `#NAME?` in Formualizer, where Excel returns `#REF!`.

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - The first argument is always the sum target range.
 - Criteria are supplied in `(criteria_range, criteria)` pairs.
 - Criteria ranges are broadcast/padded according to engine matching rules.

## Examples

<FunctionExample
  title={"Aggregate numbers from only the East records."}
  formula={"=SUMIFS(A1:A3,B1:B3,\"East\")"}
  grid={{"A1":"10","A2":"50","A3":"20","B1":"\"East\"","B2":"\"West\"","B3":"\"East\""}}
  expected={"30"}
/>

<FunctionExample
  title={"Add a second criterion so both conditions must hold."}
  formula={"=SUMIFS(A1:A3,B1:B3,\"East\",C1:C3,\"<5\")"}
  grid={{"A1":"10","A2":"50","A3":"20","B1":"\"East\"","B2":"\"West\"","B3":"\"East\"","C1":"2","C2":"4","C3":"6"}}
  expected={"10"}
/>

<FunctionExample
  title={"Aggregate the only row in a single-row data set."}
  formula={"=SUMIFS(A1:A1,B1:B1,\"East\",C1:C1,2)"}
  grid={{"A1":"10","B1":"\"East\"","C1":"2"}}
  expected={"10"}
/>

<FunctionExample
  title={"Sum with two conditions"}
  formula={"=SUMIFS(C1:C3, A1:A3, \"East\", B1:B3, \">=2025\")"}
  grid={{"A1":"\"East\"","A2":"\"East\"","A3":"\"West\"","B1":"2024","B2":"2025","B3":"2025","C1":"10","C2":"20","C3":"30"}}

## FAQ

### How are multiple SUMIFS criteria combined?
All criteria pairs are applied with logical AND; every condition must match.

### What if criteria range sizes differ?
Ranges are broadcast/padded under engine rules instead of strict Excel-size rejection.
