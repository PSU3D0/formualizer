Returns the largest numeric value from one or more arguments.

`MAX` scans scalar values and ranges, considering only values that can be treated as numbers.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MAX(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Unparseable text supplied directly, such as `"x"`, is ignored by Formualizer. Excel returns `#VALUE!`.

## Remarks
 - Errors in any scalar argument or range cell propagate immediately.
 - In ranges, non-numeric cells are ignored.
 - Scalar text is included only when it can be coerced to a number.
 - If no numeric value is found, `MAX` returns `0`.

## Examples

<FunctionExample
  title={"Find the largest numeric value of 4, 8 and 12."}
  formula={"=MAX(4,8,12)"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the largest numeric value."}
  formula={"=MAX({4,8,12})"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"The lone number is the maximum."}
  formula={"=MAX(7)"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the largest numeric value."}
  formula={"=MAX(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Maximum in a numeric range"}
  formula={"=MAX(A1:A3)"}
  grid={{"A1":"5","A2":"9","A3":"1"}}
  expected={"9"}
/>

<FunctionExample
  title={"Scalar text can be coerced"}
  formula={"=MAX(2, \"11\", 4)"}
  grid={{}}
  expected={"11"}
/>

## FAQ

### Why can MAX return 0 for non-numeric input sets?
When no numeric values are found, MAX returns 0 by design.

### Does MAX evaluate scalar text arguments?
Yes, but only when scalar text can be coerced to a numeric value.
