Returns the sum of squares of values in one array minus the squares in another.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUMX2MY2(array1, array2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array1` | number (range) | Required | — |
| `array2` | number (range) | Required | — |

## FAQ

### What happens when the arrays have different sizes?
SUMX2MY2 returns #N/A when the two inputs do not contain the same number of values.
