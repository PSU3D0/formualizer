Returns the average of cells that satisfy a single criterion.

`AVERAGEIF` tests each cell in `range`, then averages matching values from `average_range`
 (or from `range` when `average_range` is omitted).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=AVERAGEIF(range, criteria, [average_range])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `range` | any | Required | — |
| `criteria` | any | Required | — |
| `average_range` | any | Optional | — |

## Differences from Excel

Excel requires a reference for the optional result range, where Formualizer can evaluate a non-reference expression and propagate its error. Formualizer also accepts array constants as the criteria range, which Excel requires to be a reference.

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - Criteria support comparison operators and wildcard text patterns.
 - Non-numeric values in the averaged cells are ignored.

## Error cases

 - If no cells match, `AVERAGEIF` returns `#DIV/0!`.

## Examples

<FunctionExample
  title={"Select East records by label and aggregate the corresponding numbers."}
  formula={"=AVERAGEIF(A1:A3,\"East\",B1:B3)"}

<FunctionExample

  grid={{"C1":"2","C2":"4","C3":"6"}}

## FAQ

### When does AVERAGEIF return #DIV/0!?
It returns #DIV/0! when no matching cells contribute numeric values.

### If average_range is omitted, what gets averaged?
The function averages matching numeric cells from the criteria range itself.
