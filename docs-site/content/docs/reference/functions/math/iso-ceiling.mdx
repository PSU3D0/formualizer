Rounds a number up using ISO ceiling semantics.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISO.CEILING(number, [significance])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Optional | — |

## FAQ

### How does ISO.CEILING differ from legacy CEILING?
ISO.CEILING always uses a positive significance and rounds toward positive infinity.
