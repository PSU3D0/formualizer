Counts non-empty cells and scalar arguments.

`COUNTA` counts any value except true empty cells.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COUNTA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | any | Required | — |
| `value2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Numbers, text, booleans, and errors all count.
 - Empty string values (`""`) are counted as non-empty.
 - Truly empty cells are the only values excluded.

## Examples

<FunctionExample
  title={"Count a number and text while leaving the blank cell out."}
  formula={"=COUNTA(A1:A3)"}
  grid={{"A1":"3","A2":"\"five\"","A3":"(blank)"}}
  expected={"2"}
/>

<FunctionExample
  title={"Include an error cell, which is still a populated cell."}
  formula={"=COUNTA(A1:A4)"}
  grid={{"A1":"3","A2":"\"five\"","A3":"(blank)","A4":"=1/0"}}
  expected={"3"}
/>

<FunctionExample
  title={"A reference to a genuinely empty cell contributes zero."}
  formula={"=COUNTA(A3)"}
  grid={{"A3":"(blank)"}}
  expected={"0"}
/>

<FunctionExample
  title={"Count mixed populated values"}
  formula={"=COUNTA(1, \"x\", TRUE, \"\")"}
  grid={{}}
  expected={"4"}
/>

<FunctionExample
  title={"Range count excludes only true blanks"}
  formula={"=COUNTA(A1:A3)"}
  grid={{"A1":"10","A2":"\"\""}}
  expected={"2"}
/>

<FunctionExample
  title={"Errors are counted"}
  formula={"=COUNTA(1/0, 5)"}
  grid={{}}
  expected={"2"}
/>

## FAQ

### Does COUNTA count empty-string results like ""?
Yes. Empty text is counted as non-empty by COUNTA.

### Are error values counted?
Yes. Errors are considered populated values and increase the count.
