Converts text in a given radix back to a decimal number.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DECIMAL(text, radix)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |
| `radix` | number | Required | — |

## Examples

<FunctionExample
  title={"Convert a hexadecimal string to a decimal value."}
  formula={"=DECIMAL(\"1F\",16)"}
  grid={{}}
  expected={"31"}
/>

<FunctionExample
  title={"Parse the same kind of text in base two."}
  formula={"=DECIMAL(\"10101\",2)"}
  grid={{}}
  expected={"21"}
/>

<FunctionExample
  title={"A zero digit represents a value of zero at the minimum radix."}
  formula={"=DECIMAL(\"0\",2)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The digit 2 cannot appear in a binary number."}
  formula={"=DECIMAL(\"2\",2)"}
  grid={{}}
  expected={"#NUM!"}
/>

## FAQ

### Is DECIMAL case-sensitive for alphabetic digits?
No. Inputs like "ff" and "FF" both work for hexadecimal conversions.
