Returns the angle in radians whose cotangent is the input value.

`ACOT` maps real inputs to principal angles in `(0, PI())`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ACOT(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Inverts cotangent on the open interval from 0 to π. Every finite real input is valid and zero maps to π/2.

## Remarks
 - Domain: accepts any real number, including `0`.
 - Radians: output is in `(0, PI())`, with `ACOT(0) = PI()/2`.

## Error cases

 - Errors: no function-specific domain errors are produced.

### What is ACOT(0)?
ACOT(0) is PI()/2 in the principal-value branch used here.
