Rounds a number up to the nearest integer or multiple using `CEILING.MATH` rules.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CEILING.MATH(number, [significance])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Optional | — |

## Remarks
 - If `significance` is omitted (or passed as `0`), the function uses `1`.
 - `significance` is treated as a positive magnitude.
 - Negative numbers round toward positive infinity.

## Differences from Excel
 Formualizer accepts one or two arguments. Supplying Excel's third argument, `mode`, returns `#VALUE!`.

### How are negative numbers rounded?
