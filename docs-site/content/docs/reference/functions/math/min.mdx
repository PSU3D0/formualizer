Returns the smallest numeric value from one or more arguments.

`MIN` scans scalar values and ranges, considering only values that can be treated as numbers.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MIN(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Unparseable text supplied directly, such as `"x"`, is ignored by Formualizer. Excel returns `#VALUE!`.

## Remarks
 - Errors in any scalar argument or range cell propagate immediately.
 - In ranges, non-numeric cells are ignored.
 - Scalar text is included only when it can be coerced to a number.
 - If no numeric value is found, `MIN` returns `0`.

## Examples

<FunctionExample
  title={"Find the smallest numeric value of 4, 8 and 12."}
  formula={"=MIN(4,8,12)"}

<FunctionExample
  title={"Pass one three-element array to compute the smallest numeric value."}

<FunctionExample
  title={"The lone number is also the minimum."}
  formula={"=MIN(7)"}
  grid={{}}

/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the smallest numeric value."}
  formula={"=MIN(4,1/0,12)"}

  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Minimum in a numeric range"}
  formula={"=MIN(A1:A3)"}
  grid={{"A1":"8","A2":"-2","A3":"5"}}
  expected={"-2"}
/>

<FunctionExample
  title={"Coercible scalar text participates"}
  formula={"=MIN(10, \"3\", 7)"}
  grid={{}}
  expected={"3"}
/>

## FAQ

### Why can MIN return 0 even when no numbers are present?
If nothing numeric is found after coercion/scan, MIN falls back to 0.

### Do errors in referenced ranges get ignored?
No. Any encountered range or scalar error is propagated.
