Returns the double factorial of a number.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FACTDOUBLE(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## Examples

<FunctionExample
  title={"Evaluate the factorial product for a positive odd integer."}
  formula={"=FACTDOUBLE(7)"}
  grid={{}}
  expected={"105"}
/>

<FunctionExample
  title={"Pass a fractional value to see how the input is truncated."}

<FunctionExample
  title={"Evaluate the product at zero."}

## FAQ

### What does FACTDOUBLE do with 0 or -1?
It returns 1, matching spreadsheet double-factorial conventions.
