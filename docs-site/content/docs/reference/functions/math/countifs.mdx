Counts cells that satisfy all supplied criteria pairs.

`COUNTIFS` applies each `(criteria_range, criteria)` pair and counts rows where all tests pass.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COUNTIFS(criteria_range1, criteria1, [(criteria_range2, criteria2), ...])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `criteria_range1` | any | Required | — |
| `criteria1` | any | Required | — |
| `criteria_range2` | any | Optional | — |
| `criteria2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 2.

## Differences from Excel

Formualizer accepts array constants as criteria ranges. Excel requires references. An invalid INDIRECT result in a criteria range can raise `#NAME?` in Formualizer, where Excel returns `#REF!`.

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - Requires one or more criteria pairs.
 - Criteria support operators and wildcard matching.
 - A row contributes to the result only when every criterion evaluates true.

## Examples

<FunctionExample
  title={"Count records from one region with a single criteria pair."}
  formula={"=COUNTIFS(A1:A3,\"East\")"}
  grid={{"A1":"\"East\"","A2":"\"West\"","A3":"\"East\""}}
  expected={"2"}
/>

<FunctionExample
  title={"Count records that meet both the region and numeric requirements."}
  formula={"=COUNTIFS(A1:A3,\"East\",B1:B3,\">15\")"}
  grid={{"A1":"\"East\"","A2":"\"West\"","A3":"\"East\"","B1":"10","B2":"50","B3":"20"}}
  expected={"1"}
/>

<FunctionExample
  title={"No row meets the missing region criterion, so the match count is zero."}
  formula={"=COUNTIFS(A1:A3,\"South\",B1:B3,\">15\")"}
  grid={{"A1":"\"East\"","A2":"\"West\"","A3":"\"East\"","B1":"10","B2":"50","B3":"20"}}
  expected={"0"}
/>

<FunctionExample
  title={"Count rows matching two filters"}
  formula={"=COUNTIFS(A1:A3, \"East\", B1:B3, \">=10\")"}
  grid={{"A1":"\"East\"","A2":"\"East\"","A3":"\"West\"","B1":"12","B2":"8","B3":"15"}}
  expected={"1"}
/>

## FAQ

### Why can COUNTIFS return 0 even when one criterion matches rows?
Each row must satisfy every criterion pair; partial matches are excluded.

### Does COUNTIFS require at least one criteria pair?
Yes. It expects arguments in (range, criteria) pairs.
