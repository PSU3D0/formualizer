Returns the average of cells that satisfy multiple criteria.

`AVERAGEIFS` filters by all criteria pairs, then averages matching numeric values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=AVERAGEIFS(average_range, criteria_range1, criteria1, [(criteria_range2, criteria2), ...])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `average_range` | any | Required | — |
| `criteria_range1` | any | Required | — |
| `criteria1` | any | Required | — |
| `criteria_range2` | any | Optional | — |
| `criteria2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 3.

## Differences from Excel

Formualizer accepts array constants as ranges. Excel requires references. An invalid INDIRECT result in the result range can raise `#NAME?` in Formualizer, where Excel returns `#REF!`.

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - The first argument is the average target range.
 - Criteria are supplied in `(criteria_range, criteria)` pairs.

## Error cases

 - If no numeric cells match, the function returns `#DIV/0!`.

## FAQ

### When does AVERAGEIFS return #DIV/0!?
It returns #DIV/0! when no matching numeric cells are available to average.

### Do non-numeric matched cells count in the average?
No. Only numeric target cells contribute to sum and count.
