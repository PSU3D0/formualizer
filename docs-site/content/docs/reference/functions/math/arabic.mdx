Converts a Roman numeral string to its Arabic numeric value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ARABIC(text)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `text` | any | Required | — |

## Remarks
 - Accepts text input containing Roman symbols (`I,V,X,L,C,D,M`).
 - Surrounding whitespace is trimmed.
 - Empty text returns `0`.

## Error cases

 - Invalid Roman syntax returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Convert a Roman numeral that includes subtractive notation."}
  formula={"=ARABIC(\"XIV\")"}
  grid={{}}
  expected={"14"}
/>

<FunctionExample
  title={"Test lowercase Roman letters."}
  formula={"=ARABIC(\"xiv\")"}
  grid={{}}
  expected={"14"}
/>

<FunctionExample
  title={"Convert a zero-length text input."}
  formula={"=ARABIC(\"\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A character outside the Roman alphabet invalidates the input."}
  formula={"=ARABIC(\"XYZ\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Roman to Arabic"}
  formula={"=ARABIC(\"MCMXCIX\")"}
  grid={{}}
  expected={"1999"}
/>

<FunctionExample
  title={"Trimmed input"}
  formula={"=ARABIC(\"  XLIV  \")"}
  grid={{}}
  expected={"44"}
/>

## FAQ

### What causes ARABIC to return #VALUE!?
Invalid Roman symbols/syntax, non-text input, or overlength text produce #VALUE!.
