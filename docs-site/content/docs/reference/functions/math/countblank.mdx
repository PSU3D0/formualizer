Counts blank cells, including empty-string text results.

`COUNTBLANK` treats both true empty cells and `""` text values as blank.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COUNTBLANK(range, [range2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `range` | any | Required | — |
| `range2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts multiple arguments and can count scalar values. Excel takes a single range reference.

## Remarks
 - Empty-string text values are counted.
 - Numbers, booleans, and non-empty text are not counted.
 - Supports scalar arguments and ranges.

## Examples

<FunctionExample
  title={"Count one genuinely empty cell and one formula returning empty text."}
  formula={"=COUNTBLANK(A1:A3)"}
  grid={{"A1":"3","A2":"(blank)","A3":"=\"\""}}
  expected={"2"}
/>

<FunctionExample
  title={"Formualizer accepts multiple references and counts one blank in A2 and two in B1:B2."}
  formula={"=COUNTBLANK(A2,B1:B2)"}
  grid={{"A2":"(blank)","B1":"(blank)","B2":"(blank)"}}
  expected={"3"}
/>

<FunctionExample
  title={"A populated numeric cell contributes no blanks."}
  formula={"=COUNTBLANK(A1)"}
  grid={{"A1":"3"}}
  expected={"0"}
/>

<FunctionExample
  title={"Count blanks in a range"}
  formula={"=COUNTBLANK(A1:A3)"}
  grid={{"A1":"10","A2":"\"\""}}
  expected={"2"}
/>

## FAQ

### Does COUNTBLANK include cells that contain ""?
Yes. Empty-string text values are treated as blank for COUNTBLANK.

### Are numeric zeros considered blank?
No. Zero is a numeric value, so it is not counted as blank.
