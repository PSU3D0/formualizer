Truncates a number toward zero, optionally at a specified digit position.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TRUNC(number, [num_digits])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `num_digits` | number | Optional | — |

## Remarks
 - If `num_digits` is omitted, truncation is to an integer.
 - Positive `num_digits` keeps decimal places; negative values zero places to the left.

## Error cases

 - Passing more than two arguments returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Omit the precision to truncate at the decimal point."}
  formula={"=TRUNC(12.345)"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"Retain two places to the right of the decimal point."}
  formula={"=TRUNC(12.345,2)"}
  grid={{}}
  expected={"12.34"}
/>

<FunctionExample
  title={"Truncate to a place left of the decimal point."}
  formula={"=TRUNC(127,-1)"}
  grid={{}}
  expected={"120"}
/>

<FunctionExample
  title={"The number argument cannot be read from nonnumeric text."}
  formula={"=TRUNC(\"invalid\",2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Truncate to two decimal places"}
  formula={"=TRUNC(12.3456,2)"}
  grid={{}}
  expected={"12.34"}
/>

<FunctionExample
  title={"Truncate toward zero at the hundreds place"}
  formula={"=TRUNC(-987.65,-2)"}
  grid={{}}
  expected={"-900"}
/>

## FAQ

### How does TRUNC differ from INT for negative numbers?
TRUNC removes digits toward zero, while INT floors toward negative infinity.
