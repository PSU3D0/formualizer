The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SUBTOTAL(function_num, ref1, [ref2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `function_num` | number (range) | Required | — |
| `ref1` | number (range) | Required | — |
| `ref2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 2.

## Examples

<FunctionExample
  title={"Select the sum operation over three source cells."}
  formula={"=SUBTOTAL(9,A1:A3)"}
  grid={{"A1":"5","A2":"10","A3":"20"}}
  expected={"35"}
/>

<FunctionExample
  title={"Use operation one to calculate their average instead."}
  formula={"=SUBTOTAL(1,A1:A3)"}
  grid={{"A1":"5","A2":"10","A3":"20"}}
  expected={"11.6666666666667"}
/>

<FunctionExample
  title={"Include a referenced nested SUBTOTAL to check how it contributes to the outer sum."}
  formula={"=SUBTOTAL(9,A1:A3,B1)"}
  grid={{"A1":"5","A2":"10","A3":"20","B1":"=SUBTOTAL(9,A1:A2)"}}
  expected={"35"}
/>

<FunctionExample
  title={"An unsupported operation number cannot select a subtotal calculation."}
  formula={"=SUBTOTAL(99,A1:A3)"}
  grid={{"A1":"5","A2":"10","A3":"20"}}
  expected={"#VALUE!"}
/>
