Returns the inverse hyperbolic sine of a number.

`ASINH` is the inverse of `SINH` over all real inputs.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ASINH(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Inverts hyperbolic sine. It equals ln(x + √(x² + 1)) and is real for every real x.

## Remarks
 - Domain: accepts any real number.
 - Radians: this function is hyperbolic, so the output is not an angle in radians.

## Error cases

 - Errors: no function-specific domain errors are produced.
