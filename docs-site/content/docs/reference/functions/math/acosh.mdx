Returns the inverse hyperbolic cosine of a number.

`ACOSH` is the inverse of `COSH` for inputs at or above `1`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ACOSH(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |

## How it works

Inverts hyperbolic cosine on nonnegative outputs. It equals ln(x + √(x² − 1)) for x at least 1 and is nonreal below 1.

## Remarks
 - Domain: input must be greater than or equal to `1`.
 - Radians: this function is hyperbolic, so the output is not an angle in radians.

## Error cases

 - Errors: returns `#NUM!` when the input is less than `1`.
