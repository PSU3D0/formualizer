Rounds a number away from zero to a specified number of digits.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ROUNDUP(number, num_digits)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `num_digits` | number | Required | — |

## Remarks
 - Positive `num_digits` affects decimals; negative values affect digits left of the decimal.
 - Any discarded non-zero part increases the magnitude of the result.
 - Input errors are propagated.

## Examples

<FunctionExample
  title={"Round to two places to the right of the decimal point."}
  formula={"=ROUNDUP(12.345,2)"}
  grid={{}}
  expected={"12.35"}
/>

<FunctionExample
  title={"Round to a place left of the decimal point."}
  formula={"=ROUNDUP(127,-1)"}
  grid={{}}
  expected={"130"}
/>

<FunctionExample
  title={"Select zero decimal places to return an integer."}
  formula={"=ROUNDUP(12.345,0)"}
  grid={{}}
  expected={"13"}
/>

<FunctionExample
  title={"The number cannot be read from nonnumeric text."}
  formula={"=ROUNDUP(\"invalid\",2)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Round up decimals away from zero"}
  formula={"=ROUNDUP(3.14159,3)"}
  grid={{}}
  expected={"3.142"}
/>

<FunctionExample
  title={"Round up a negative value at the hundreds place"}
  formula={"=ROUNDUP(-987.65,-2)"}
  grid={{}}
  expected={"-1000"}
/>

## FAQ

### What does ROUNDUP do when discarded digits are already zero?
It leaves the value unchanged because no non-zero discarded part remains.
