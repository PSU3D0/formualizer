Returns the inverse hyperbolic tangent of a number.

`ATANH` is the inverse of `TANH` on the open interval `(-1, 1)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ATANH(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |

## How it works

Inverts hyperbolic tangent. It equals ln((1 + x) / (1 − x)) / 2 for −1 &lt; x &lt; 1, with singularities at both endpoints.

## Remarks
 - Domain: input must be strictly between `-1` and `1`.
 - Radians: this function is hyperbolic, so the output is not an angle in radians.

## Error cases

 - Errors: returns `#NUM!` when the input is `&lt;= -1` or `&gt;= 1`.

### Which inputs are invalid for ATANH?
ATANH is only defined on (-1, 1); endpoints and outside values return #NUM!.
