Rounds a number down to the nearest integer or multiple using `FLOOR.MATH` rules.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FLOOR.MATH(number, [significance])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `significance` | number | Optional | — |

## Remarks
 - If `significance` is omitted (or passed as `0`), the function uses `1`.
 - `significance` is treated as a positive magnitude.
 - Negative numbers round away from zero.

## Differences from Excel
 Formualizer accepts one or two arguments. Supplying Excel's third argument, `mode`, returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Round a fractional number to a multiple of two."}

/>

<FunctionExample
  title={"A number already at a multiple of the significance stays at that multiple."}

<FunctionExample

<FunctionExample

### How are negative numbers rounded?
With the supported arguments, negative numbers round away from zero.
