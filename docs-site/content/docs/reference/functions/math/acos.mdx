Returns the angle in radians whose cosine is the input value.

Use `ACOS` when you need an angle from a normalized adjacent/hypotenuse ratio.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ACOS(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Inverts cosine on the interval from 0 to π. The real input must be from −1 through 1 inclusive.

## Remarks
 - Domain: input must be between `-1` and `1`, inclusive.
 - Radians: output is in the range `[0, PI()]`.

## Error cases

 - Errors: returns `#NUM!` when the input is outside the valid domain.

## FAQ

### Why does ACOS reject values like 1.0001?
ACOS is only defined on [-1, 1], so out-of-range inputs return #NUM!.
