Returns the angle in radians whose tangent is the input value.

`ATAN` is useful for recovering a slope angle from a ratio.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ATAN(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## How it works

Inverts tangent on the open interval from −π/2 to π/2. Every finite real input has an angle in that interval.

## Remarks
 - Domain: accepts any real number.
 - Radians: output is in the range `(-PI()/2, PI()/2)`.

## Error cases

 - Errors: no function-specific domain errors are produced.

## FAQ

### Does ATAN ever return #NUM! for large values?
No. ATAN accepts any real input and asymptotically approaches +/-PI()/2.
