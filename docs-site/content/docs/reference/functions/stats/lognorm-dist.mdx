Returns the log-normal probability at `x` as either a cumulative value or density.

`LOGNORM.DIST` models positive-valued variables where `ln(X)` follows a normal distribution.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LOGNORM.DIST(x, mean, standard_dev, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `mean` | number | Required | — |
| `standard_dev` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

Standardize ln(x) to z = (ln(x) − mean) / standard_dev. The cumulative probability is Φ(z) and the density is φ(z) / (x × standard_dev). Both x and the standard deviation must be positive.

## Remarks
 - Set `cumulative` to non-zero for CDF mode; set it to `0` for PDF mode.
 - Requires `x &gt; 0` and `standard_dev &gt; 0`.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` when `x &lt;= 0` or `standard_dev &lt;= 0`.
