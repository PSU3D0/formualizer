Returns the inverse of the cumulative beta distribution (legacy name).

`BETAINV(probability, alpha, beta, [A], [B])` is the `x` with
 `BETADIST(x, alpha, beta, A, B) = probability`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BETAINV(probability, alpha, beta, [a], [b])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `alpha` | number | Required | — |
| `beta` | number | Required | — |
| `a` | number | Optional | — |
| `b` | number | Optional | — |

## How it works

Legacy spelling of BETA.INV with the same argument order. Finds the point in the supplied interval whose cumulative beta probability matches probability. Both shape parameters must be positive.

## Remarks
 - `A` and `B` default to `0` and `1`.

## Error cases

 - Returns `#NUM!` when `alpha &lt;= 0`, `beta &lt;= 0`, `probability &lt;= 0`, `probability &gt; 1`,
   or `A &gt;= B`.
