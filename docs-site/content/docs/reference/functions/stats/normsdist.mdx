Returns the standard normal cumulative distribution at `z` (legacy name).

`NORMSDIST(z)` is `NORM.S.DIST(z, TRUE)`: the compatibility form has no
 `cumulative` argument and always returns the cumulative probability.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NORMSDIST(z)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `z` | number | Required | — |

## How it works

Maps to NORM.S.DIST with cumulative set to TRUE. Integrates the standard normal density from negative infinity to z, for any real z.

## Error cases

 - A non-numeric `z` returns `#VALUE!`.
