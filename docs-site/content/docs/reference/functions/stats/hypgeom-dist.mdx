Returns hypergeometric probabilities for successes drawn without replacement.

Use `HYPGEOM.DIST` for finite-population sampling where each draw changes remaining odds.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HYPGEOM.DIST(sample_s, number_sample, population_s, number_pop, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `sample_s` | number | Required | — |
| `number_sample` | number | Required | — |
| `population_s` | number | Required | — |
| `number_pop` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

For k sample successes among n draws from N items with K successes, the point probability is C(K,k) C(N−K,n−k) / C(N,n). The counts must support drawing without replacement. The cumulative option sums the feasible counts through k.

## Remarks
 - Count inputs are truncated to integers.
 - Requires valid population/sample bounds and feasible success counts.
 - Set `cumulative` to non-zero for CDF mode, or `0` for PMF mode.

## Error cases

 - Returns `#NUM!` for invalid population setup; out-of-support PMF values return `0`.
