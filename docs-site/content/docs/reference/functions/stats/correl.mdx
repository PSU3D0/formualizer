Returns the Pearson correlation coefficient between two numeric arrays.

`CORREL` measures linear relationship strength from `-1` (perfect inverse) to `1` (perfect
 direct).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CORREL(array1, array2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array1` | number (range) | Required | — |
| `array2` | number (range) | Required | — |

## Remarks
 - Both arrays must produce the same number of numeric values.

## Error cases

 - Returns `#N/A` when array lengths differ.
 - Returns `#DIV/0!` when either series has zero variance.

## Examples

<FunctionExample
  title={"Evaluate matched observations in two equally sized arrays."}

  expected={"0.981155781039212"}
/>

<FunctionExample
  title={"Reverse the second series to compare opposite movement."}

  expected={"-0.981155781039212"}
/>

<FunctionExample
  title={"Use two observations that follow a perfect positive linear pattern."}
  formula={"=CORREL({1,2},{2,4})"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"Each observation needs a partner in the other array."}
  formula={"=CORREL({1,2,3,4},{1,4,5})"}
  grid={{}}
  expected={"#N/A"}
/>

<FunctionExample
  title={"Perfect positive linear correlation"}
  formula={"=CORREL({2,4,6},{1,2,3})"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
