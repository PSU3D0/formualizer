Returns the right-tailed or two-tailed Student's t probability (legacy name).

`TDIST(x, deg_freedom, 1)` is `P(T &gt; x)` (`T.DIST.RT`) and
 `TDIST(x, deg_freedom, 2)` is `P(|T| &gt; x)` (`T.DIST.2T`).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TDIST(x, deg_freedom, tails)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |
| `tails` | number | Required | — |

## How it works

A tails argument of 1 maps to T.DIST.RT(x, degrees_freedom). A value of 2 maps to T.DIST.2T(x, degrees_freedom). The legacy argument x must be nonnegative and degrees of freedom positive.

## Remarks
 - `deg_freedom` and `tails` are truncated to integers.

## Error cases

 - Returns `#NUM!` when `x &lt; 0`, `deg_freedom &lt; 1`, or `tails` is not 1 or 2.
