Returns the negative binomial probability of `number_f` failures (legacy name).

`NEGBINOMDIST(number_f, number_s, probability_s)` is the probability mass form of
 `NEGBINOM.DIST`: the chance of exactly `number_f` failures before the `number_s`-th success.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NEGBINOMDIST(number_f, number_s, probability_s)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number_f` | number | Required | — |
| `number_s` | number | Required | — |
| `probability_s` | number | Required | — |

## How it works

Maps to NEGBINOM.DIST with cumulative set to FALSE. The result at f failures before the rth success is the binomial coefficient C(f+r−1,f) times pʳ(1−p)ᶠ. Counts require f ≥ 0 and r ≥ 1, with probability in [0,1].

## Remarks
 - `number_f` and `number_s` are truncated to integers.

## Error cases

 - Returns `#NUM!` when `probability_s &lt; 0`, `probability_s &gt; 1`, `number_f &lt; 0`, or
   `number_s &lt; 1`.
