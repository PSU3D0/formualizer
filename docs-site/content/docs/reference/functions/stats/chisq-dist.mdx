Returns the chi-square probability for `x` with the specified degrees of freedom.

Use `CHISQ.DIST` in cumulative mode for left-tail probability or density mode for the PDF.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHISQ.DIST(x, deg_freedom, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

The chi-squared distribution with ν degrees of freedom is a gamma distribution with shape ν/2 and scale 2. Use a nonnegative statistic and positive degrees of freedom. The cumulative flag selects probability from zero through x or the density at x.

## Remarks
 - Set `cumulative` to non-zero for CDF mode, or `0` for PDF mode.
 - Requires `x &gt;= 0` and `deg_freedom &gt;= 1`.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` for negative `x` or invalid degrees of freedom.
