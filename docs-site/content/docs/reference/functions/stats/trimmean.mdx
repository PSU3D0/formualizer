Returns the mean after trimming a percentage of values from both tails.

`TRIMMEAN` sorts numeric data, removes an equal count from low and high ends, then averages the
 remaining interior values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TRIMMEAN(array, percent)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | number (range) | Required | — |
| `percent` | number (range) | Required | — |

## Remarks
 - `percent` must satisfy `0 &lt;= percent &lt; 1`.
 - The trimmed count per side is `floor(n * percent / 2)`.

## Error cases

 - Returns `#NUM!` for invalid percent values or when no numeric values are available.

## Examples

<FunctionExample
  title={"Trim the smallest and largest observations before averaging."}
  formula={"=TRIMMEAN({1,10,12,13,50},0.4)"}
  grid={{}}
  expected={"11.6666666666667"}
/>

<FunctionExample
  title={"Compare a smaller fraction whose trimming count rounds down."}
  formula={"=TRIMMEAN({1,10,12,13,50},0.2)"}
  grid={{}}
  expected={"17.2"}
/>

<FunctionExample
  title={"A zero trim fraction uses every value."}
  formula={"=TRIMMEAN({1,10,12,13,50},0)"}
  grid={{}}
  expected={"17.2"}
/>

<FunctionExample
  title={"The excluded fraction cannot exceed the full sample."}
  formula={"=TRIMMEAN({1,10,12,13,50},1.1)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Trimmed mean from direct values"}
  formula={"=TRIMMEAN({1,2,3,4,5,6},0.3333333333333333)"}
  grid={{}}
  expected={"3.5"}
/>

<FunctionExample
  title={"Trimmed mean from a range"}
  formula={"=TRIMMEAN(A1:A6,0.4)"}

/>
