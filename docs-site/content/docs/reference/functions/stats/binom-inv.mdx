Returns the smallest number of successes whose cumulative binomial probability meets a threshold.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BINOM.INV(trials, probability_s, alpha)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `trials` | number | Required | — |
| `probability_s` | number | Required | — |
| `alpha` | number | Required | — |

## How it works

Finds the first integer k for which the binomial cumulative probability P(X ≤ k) is at least alpha. Both p and alpha are probabilities, and k can never exceed the trial count.
