Returns the cumulative beta distribution (legacy name).

`BETADIST(x, alpha, beta, [A], [B])` is `BETA.DIST(x, alpha, beta, TRUE, A, B)`: the
 compatibility form is always cumulative and takes the bounds as its 4th and 5th arguments.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BETADIST(x, alpha, beta, [a], [b])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `alpha` | number | Required | — |
| `beta` | number | Required | — |
| `a` | number | Optional | — |
| `b` | number | Optional | — |

## How it works

Legacy equivalent of BETA.DIST with cumulative set to TRUE. Lower and upper limits follow beta directly because BETADIST has no cumulative switch. The density is supported on the interval between those limits, with both shapes positive.

## Remarks
 - `A` and `B` default to `0` and `1`.

## Error cases

 - Returns `#NUM!` when `alpha &lt;= 0`, `beta &lt;= 0`, `x &lt; A`, `x &gt; B`, or `A = B`.
