Returns population variance using `n` in the denominator.

`VAR.P` describes dispersion for a complete population of numeric values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VAR.P(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Requires at least one numeric value.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#DIV/0!` when no numeric values are provided.

## FAQ

### What is the denominator difference vs VAR.S?
VAR.P divides by n, while VAR.S divides by n-1.
