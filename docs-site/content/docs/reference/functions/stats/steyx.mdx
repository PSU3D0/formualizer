Returns the standard error of y-estimates from a simple linear regression.

`STEYX` measures the typical residual size around the fitted regression line.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=STEYX(known_ys, known_xs)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `known_ys` | number (range) | Required | — |
| `known_xs` | number (range) | Required | — |

## Remarks
 - Requires paired x/y inputs with matching numeric lengths.
 - Requires at least three paired points.
 - Pairing and shape mismatches return spreadsheet errors from paired-array validation.

## Error cases

 - Returns `#DIV/0!` when `n &lt; 3` or x-values have zero variance.
