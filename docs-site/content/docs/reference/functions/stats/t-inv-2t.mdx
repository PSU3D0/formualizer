Returns the positive t critical value for a two-tailed probability.

`T.INV.2T` solves for `t` such that `P(|T| &gt; t) = probability`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=T.INV.2T(probability, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Finds the nonnegative cutoff q with P(|T| ≥ q) equal to the requested probability. Degrees of freedom must be positive.

## Remarks
 - `probability` must satisfy `0 &lt; probability &lt;= 1`.
 - `deg_freedom` must be at least `1`.
 - The compatibility name `TINV` is a separate function that also truncates `deg_freedom`.

## Error cases

 - Returns `#NUM!` for invalid probability or degree-of-freedom arguments.
