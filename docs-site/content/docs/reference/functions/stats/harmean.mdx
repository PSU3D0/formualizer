Returns the harmonic mean of positive numeric values.

`HARMEAN` emphasizes smaller values and is useful for averaging rates and ratios.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HARMEAN(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - All numeric inputs must be strictly greater than `0`.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#NUM!` if any value is `&lt;= 0`, or if no numeric values are provided.

## Examples

<FunctionExample
  title={"Find the harmonic mean of 4, 8 and 12."}

  expected={"6.54545454545455"}
/>

<FunctionExample
  title={"Taking the reciprocal twice returns the sole harmonic-mean input."}
  formula={"=HARMEAN(7)"}
  grid={{}}

/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the harmonic mean."}
  formula={"=HARMEAN(4,1/0,12)"}

  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Harmonic mean from scalar values"}
  formula={"=HARMEAN(1,2,4)"}
  grid={{}}
  expected={"1.71428571428571"}
/>

<FunctionExample
  title={"Harmonic mean from a range"}
  formula={"=HARMEAN(A1:A3)"}

## FAQ

### Why does HARMEAN fail on zeros?
Harmonic mean uses reciprocals, so inputs must be strictly positive.
