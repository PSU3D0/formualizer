Returns the F-distribution probability for `x` with numerator and denominator degrees of freedom.

Use `F.DIST` for left-tail cumulative probabilities or density values in variance-ratio tests.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=F.DIST(x, deg_freedom1, deg_freedom2, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom1` | number | Required | — |
| `deg_freedom2` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

An F variate is the ratio (U/d₁)/(V/d₂) of independent chi-squared variates divided by their degrees of freedom. Input x must be nonnegative and both degrees of freedom positive. The cumulative flag selects the area to the left of x or the density there.

## Remarks
 - Set `cumulative` to non-zero for CDF mode, or `0` for PDF mode.
 - Requires `x &gt;= 0`, `deg_freedom1 &gt;= 1`, and `deg_freedom2 &gt;= 1`.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` when any domain constraint is violated.
