Returns the largest value after applying A-variant coercion rules.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MAXA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.

## Examples

<FunctionExample
  title={"Find the maximum with logical and text coercion of 4, 8 and 12."}
  formula={"=MAXA(4,8,12)"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the maximum with logical and text coercion."}
  formula={"=MAXA({4,8,12})"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"With no other values to coerce, 7 is the maximum."}
  formula={"=MAXA(7)"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the maximum with logical and text coercion."}
  formula={"=MAXA(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Find the maximum of −4, TRUE and Pending. TRUE contributes 1 and wins."}
  formula={"=MAXA(A1:A3)"}
  grid={{"A1":"-4","A2":"TRUE","A3":"\"Pending\""}}
  expected={"1"}
/>

## FAQ

### What do text values contribute to MAXA?
Text contributes 0, so negative numeric inputs can still be smaller than text in the aggregate.
