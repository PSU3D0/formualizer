Returns the F value whose left-tail probability equals `probability`.

`F.INV` inverts `F.DIST(x, deg_freedom1, deg_freedom2, TRUE)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=F.INV(probability, deg_freedom1, deg_freedom2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom1` | number | Required | — |
| `deg_freedom2` | number | Required | — |

## How it works

Solves P(F ≤ q) = probability for the lower-tail F quantile, with positive numerator and denominator degrees of freedom.

## Remarks
 - `probability` must be strictly between `0` and `1`.
 - `deg_freedom1` and `deg_freedom2` must each be at least `1`.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` for invalid probability or degree-of-freedom arguments.
