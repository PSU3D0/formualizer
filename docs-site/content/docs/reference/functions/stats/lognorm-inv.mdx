Returns the positive value `x` whose log-normal cumulative probability is `probability`.

This function inverts `LOGNORM.DIST(x, mean, standard_dev, TRUE)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LOGNORM.INV(probability, mean, standard_dev)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `mean` | number | Required | — |
| `standard_dev` | number | Required | — |

## How it works

Converts a standard normal quantile z into exp(mean + standard_dev × z). The probability must lie strictly between zero and one and the standard deviation must be positive.

## Remarks
 - `probability` must be strictly between `0` and `1`.
 - `standard_dev` must be strictly greater than `0`.
 - Invalid numeric coercions propagate as spreadsheet errors.
 - Alias `LOGINV` (the Excel 2007 compatibility name) is supported.

## Error cases

 - Returns `#NUM!` when inputs violate probability or scale constraints.
