Returns the two-tailed Student's t probability beyond `x`.

`T.DIST.2T` computes `P(|T| &gt; x)` for the specified degrees of freedom.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=T.DIST.2T(x, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

For nonnegative x, returns P(|T| ≥ x), twice the right-tail probability of a Student t variate. Degrees of freedom must be positive. At x = 0 the two tails cover all outcomes.

## Remarks
 - Requires `x &gt;= 0` and `deg_freedom &gt;= 1`.
 - Represents a two-sided tail area.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` when arguments are outside valid ranges.
