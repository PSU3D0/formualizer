Returns the normal-distribution probability at `x` for a given mean and standard deviation.

Use `NORM.DIST` for either cumulative probabilities or point density under a non-standard
 normal model.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NORM.DIST(x, mean, standard_dev, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `mean` | number | Required | — |
| `standard_dev` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

Standardize x to z = (x − mean) / standard_dev. The cumulative result is Φ(z), the standard normal area below z. The density is φ(z) divided by the standard deviation, which must be positive.

## Remarks
 - Set `cumulative` to non-zero for `P(X &lt;= x)`; set it to `0` for density mode.
 - `standard_dev` must be strictly greater than `0`.
 - Invalid numeric coercions propagate as spreadsheet errors.
 - Alias `NORMDIST` (the Excel 2007 compatibility name) is supported.

## Error cases

 - Returns `#NUM!` when `standard_dev &lt;= 0`.
