Returns the k-th largest value in a data set.

`LARGE` is useful for top-N analysis, such as highest score, second-highest sale, or third-best
 result.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LARGE(array, k)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | number (range) | Required | — |
| `k` | number (range) | Required | — |

## Remarks
 - `k` must be at least `1`.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#NUM!` if `k` is greater than the count of numeric values.

## FAQ

### When does LARGE return #NUM!?
It returns #NUM! when k &lt; 1, k exceeds numeric count, or no numeric values exist.
