Returns the inverse of the right-tailed chi-squared probability (legacy name).

`CHIINV(probability, deg_freedom)` is the `x` with `CHIDIST(x, deg_freedom) =
 probability`, the same as `CHISQ.INV.RT`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHIINV(probability, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Maps to CHISQ.INV.RT with the same two arguments. Inverts the upper chi-squared tail for positive degrees of freedom and a probability greater than zero and at most one.

## Remarks
 - `deg_freedom` is truncated to an integer.

## Error cases

 - Returns `#NUM!` when `probability` is outside `[0, 1]` or `deg_freedom &lt; 1`.
