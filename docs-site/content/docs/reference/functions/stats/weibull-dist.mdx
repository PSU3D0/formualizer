Returns the Weibull-distribution probability at `x` for shape `alpha` and scale `beta`.

`WEIBULL.DIST` is commonly used for reliability and time-to-failure analysis.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=WEIBULL.DIST(x, alpha, beta, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `alpha` | number | Required | — |
| `beta` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

With positive shape α and scale β, the Weibull CDF is 1 − exp(−(x/β) raised to α). Density is its derivative with respect to x. The observation must be nonnegative.

## Remarks
 - Requires `x &gt;= 0`, `alpha &gt; 0`, and `beta &gt; 0`.
 - Set `cumulative` to non-zero for CDF mode, or `0` for PDF mode.
 - In PDF mode at `x = 0`, behavior follows the Weibull shape-specific limit.
 - Alias `WEIBULL` (the Excel 2007 compatibility name) is supported.

## Error cases

 - Returns `#NUM!` when parameters fall outside valid ranges.
