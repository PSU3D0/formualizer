Returns the inverse of the right-tailed F-distribution.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=F.INV.RT(probability, deg_freedom1, deg_freedom2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom1` | number | Required | — |
| `deg_freedom2` | number | Required | — |

## How it works

Solves P(F ≥ q) = probability for the upper-tail F cutoff. Increasing the probability moves the cutoff downward for fixed positive degrees of freedom.

## FAQ

### What p-values are valid for F.INV.RT?
p must lie in the range 0 to 1, and p=0 returns #NUM! because the inverse diverges.
