Returns the sample variance using A-variant coercion semantics.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VARA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.

## Examples

<FunctionExample
  title={"Find the sample variance with logical and text coercion of 4, 8 and 12."}
  formula={"=VARA(4,8,12)"}
  grid={{}}
  expected={"16"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the sample variance with logical and text coercion."}
  formula={"=VARA({4,8,12})"}
  grid={{}}
  expected={"16"}
/>

<FunctionExample
  title={"Use 4 and 12, the minimum two observations for the sample variance with logical and text coercion."}
  formula={"=VARA(4,12)"}
  grid={{}}
  expected={"32"}
/>

<FunctionExample
  title={"A lone observation cannot supply the denominator for the sample variance with logical and text coercion."}
  formula={"=VARA(4)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Compute sample variance over 4, TRUE and Pending with the coerced values 4, 1 and 0."}
  formula={"=VARA(A1:A3)"}
  grid={{"A1":"4","A2":"TRUE","A3":"\"Pending\""}}
  expected={"4.33333333333333"}
/>

## FAQ

### How are blanks handled in VARA?
Blanks are ignored, while booleans and text are coerced under A-variant rules.
