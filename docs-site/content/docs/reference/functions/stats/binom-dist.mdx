Returns the binomial probability for a count of successes across independent trials.

Use `BINOM.DIST` to evaluate either exact-success probability (PMF) or cumulative probability
 up to a success count (CDF).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BINOM.DIST(number_s, trials, probability_s, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number_s` | number | Required | — |
| `trials` | number | Required | — |
| `probability_s` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

For k successes in n independent trials, the point mass is C(n,k) pᵏ(1−p)ⁿ⁻ᵏ. The cumulative mode sums point masses from zero through k. Valid counts satisfy 0 ≤ k ≤ n and p is between zero and one.

## Remarks
 - `number_s` and `trials` are truncated to integers.
 - Requires `0 &lt;= number_s &lt;= trials`, `trials &gt;= 0`, and `0 &lt;= probability_s &lt;= 1`.
 - Set `cumulative` to non-zero for CDF mode, or `0` for PMF mode.
 - Alias `BINOMDIST` (the Excel 2007 compatibility name) is supported.

## Error cases

 - Returns `#NUM!` for invalid count or probability ranges.
