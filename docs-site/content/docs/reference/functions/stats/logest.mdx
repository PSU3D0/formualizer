Returns parameters for an exponential model fitted to known data.

`LOGEST` fits `y = b * m^x` and returns either `[m, b]` or an expanded statistics matrix.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=LOGEST(known_ys, [known_xs], [const], [stats])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `known_ys` | number (range) | Required | — |
| `known_xs` | number (range) | Optional | — |
| `const` | number (range) | Optional | — |
| `stats` | number (range) | Optional | — |

## Remarks
 - All known y-values must be strictly greater than `0`.
 - `known_x` defaults to `1..n` when omitted; several variables are laid out as in `LINEST`
   and the bases come back in reverse order of the variables, then `b`.
 - `const` controls whether `b` is fitted (`TRUE` by default).
 - `stats=TRUE` returns the `LINEST` statistics block of the fit of `ln(y)`.

## Examples

<FunctionExample
  title={"Fit coefficients using three observations and their known x values."}
  formula={"=LOGEST({2;4;8},{1;2;3})"}
  grid={{}}
  expected={"{2, 1}"}
/>

<FunctionExample
  title={"Return exponential regression statistics for three imperfectly aligned observations."}
  formula={"=LOGEST({2;4;7},{1;2;3},TRUE,TRUE)"}
  grid={{}}
  expected={"{1.87082869338697, 1.09310353301279; 0.0385471927385168, 0.083271453596626; 0.996227180101123, 0.0545139627622202; 264.053733494562, 1; 0.784707527616663, 0.00297177213604073}"}
/>

<FunctionExample
  title={"Use two observations with distinct x values."}
  formula={"=LOGEST({2;4},{1;2})"}
  grid={{}}
  expected={"{2, 1}"}
/>

<FunctionExample
  title={"The independent and dependent observations do not align."}
  formula={"=LOGEST({2;4;8},{1;2})"}
  grid={{}}
  expected={"#REF!"}
/>

<FunctionExample
  title={"Exponential base and intercept"}
  formula={"=LOGEST({2,4,8},{1,2,3})"}
  grid={{}}
  expected={"{2, 1}"}
/>

<FunctionExample
  title={"Alternative growth series"}
  formula={"=LOGEST({3,6,12},{1,2,3})"}

/>
