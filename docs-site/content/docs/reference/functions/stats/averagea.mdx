Returns the arithmetic mean while treating logical values and text as numeric inputs.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=AVERAGEA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Number

## Differences from Excel

Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.

## Examples

<FunctionExample
  title={"Find the mean with logical and text coercion of 4, 8 and 12."}
  formula={"=AVERAGEA(4,8,12)"}
  grid={{}}
  expected={"8"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the mean with logical and text coercion."}
  formula={"=AVERAGEA({4,8,12})"}
  grid={{}}
  expected={"8"}
/>

<FunctionExample
  title={"With a lone numeric observation the coerced mean is 7."}
  formula={"=AVERAGEA(7)"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the mean with logical and text coercion."}
  formula={"=AVERAGEA(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Average 4, TRUE and the text Pending as the values 4, 1 and 0."}
  formula={"=AVERAGEA(A1:A3)"}
  grid={{"A1":"4","A2":"TRUE","A3":"\"Pending\""}}
  expected={"1.66666666666667"}
/>

## FAQ

### How does AVERAGEA treat text and booleans?
TRUE counts as 1, FALSE and text count as 0, and blanks are ignored.
