Returns the natural logarithm of the gamma function.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GAMMALN(x)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |

## How it works

Returns the natural logarithm of Γ(x), the gamma function. For positive integer n, Γ(n) = (n − 1)!. This spreadsheet function requires positive x.
