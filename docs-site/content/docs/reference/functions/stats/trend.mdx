Returns fitted y-values along a linear trend derived from known data.

`TREND` fits the same least-squares model as `LINEST` and returns predictions for `new_x`
 (or defaults).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TREND(known_ys, [known_xs], [new_xs], [const])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `known_ys` | number (range) | Required | — |
| `known_xs` | number (range) | Optional | — |
| `new_xs` | number (range) | Optional | — |
| `const` | number (range) | Optional | — |

## Remarks
 - `known_y` is required; `known_x` defaults to `1..n` when omitted.
 - `new_x` defaults to `known_x` when omitted. With one variable the result has the shape of
   `new_x`; with several, `new_x` holds one observation per row (or per column when `known_y`
   is a row).
 - `const` defaults to `TRUE`; set to `FALSE` to force a zero intercept.

## Error cases

 - Returns `#VALUE!` for non-numeric data and `#REF!` for incompatible shapes.

## Examples

<FunctionExample
  title={"Fit the observed series with default x values."}
  formula={"=TREND({2;4;8})"}
  grid={{}}
  expected={"{1.66666666666667; 4.66666666666667; 7.66666666666667}"}
/>

<FunctionExample
  title={"Predict two new observations with explicitly supplied x values."}
  formula={"=TREND({2;4;8},{1;2;3},{4;5},TRUE)"}
  grid={{}}
  expected={"{10.6666666666667; 13.6666666666667}"}
/>

<FunctionExample
  title={"Predict at the first of two known x values."}
  formula={"=TREND({2;4},{1;2},{1})"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"The known x and y arrays must have corresponding observations."}
  formula={"=TREND({2;4;8},{1;2},{4})"}
  grid={{}}
  expected={"#REF!"}
/>

<FunctionExample
  title={"Predict two future points on a line"}
  formula={"=TREND({2,4,6},{1,2,3},{4,5})"}
  grid={{}}
  expected={"{8, 10}"}
/>

<FunctionExample
  title={"Default x-values with fitted trend"}
  formula={"=TREND({3,5,7})"}
  grid={{}}
  expected={"{3, 5, 7}"}
/>
