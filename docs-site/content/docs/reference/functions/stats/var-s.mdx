Estimates sample variance using `n-1` in the denominator.

`VAR.S` is the squared counterpart of `STDEV.S` for sample-based variability.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VAR.S(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Requires at least two numeric values.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#DIV/0!` when fewer than two numeric values are provided.

## Examples

<FunctionExample
  title={"Find the sample variance of 4, 8 and 12."}
  formula={"=VAR.S(4,8,12)"}
  grid={{}}
  expected={"16"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the sample variance."}
  formula={"=VAR.S({4,8,12})"}
  grid={{}}
  expected={"16"}
/>

<FunctionExample
  title={"Use 4 and 12, the minimum two observations for the sample variance."}
  formula={"=VAR.S(4,12)"}
  grid={{}}
  expected={"32"}
/>

<FunctionExample
  title={"A lone observation cannot supply the denominator for the sample variance."}
  formula={"=VAR.S(4)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Sample variance from scalar arguments"}
  formula={"=VAR.S(2,4,6)"}
  grid={{}}
  expected={"4"}
/>

<FunctionExample
  title={"Sample variance from a range"}
  formula={"=VAR.S(A1:A3)"}
  grid={{"A1":"1","A2":"2","A3":"3"}}
  expected={"1"}
/>
