Returns the middle value of a numeric data set.

For an even number of values, `MEDIAN` returns the average of the two center values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MEDIAN(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Ignores non-numeric values in referenced ranges.
 - Supports both scalar arguments and range inputs.

## Error cases

 - Returns `#NUM!` when no numeric values are available.

## FAQ

### When does MEDIAN return #NUM!?
MEDIAN returns #NUM! when no numeric values are available after filtering/coercion.
