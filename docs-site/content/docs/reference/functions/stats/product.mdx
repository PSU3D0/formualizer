Multiplies all numeric arguments and returns their product.

`PRODUCT` is useful for chained growth factors, scaling ratios, and compound multipliers.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=PRODUCT(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Non-numeric values in referenced ranges are ignored.
 - Returns `0` when no numeric values are found.
 - Direct scalar arguments still attempt numeric coercion.

## Examples

<FunctionExample
  title={"Find the product of 4, 8 and 12."}
  formula={"=PRODUCT(4,8,12)"}
  grid={{}}
  expected={"384"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the product."}
  formula={"=PRODUCT({4,8,12})"}
  grid={{}}
  expected={"384"}
/>

<FunctionExample
  title={"With one factor, the product equals that factor."}
  formula={"=PRODUCT(7)"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the product."}
  formula={"=PRODUCT(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Product of scalar values"}
  formula={"=PRODUCT(2,3,4)"}
  grid={{}}
  expected={"24"}
/>

<FunctionExample
  title={"Product from a range"}
  formula={"=PRODUCT(A1:A3)"}
  grid={{"A1":"1","A2":"5","A3":"10"}}
  expected={"50"}
/>

## FAQ

### Why does PRODUCT return 0 when no numeric inputs are found?
This implementation returns 0 for an empty numeric set after filtering.
