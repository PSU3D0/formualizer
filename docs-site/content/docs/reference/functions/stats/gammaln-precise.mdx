Returns the natural logarithm of the gamma function using Excel's precise naming variant.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GAMMALN.PRECISE(x)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |

## How it works

Evaluates ln(Γ(x)) on positive real inputs. Γ(x) continues the factorial through Γ(n) = (n − 1)! for positive integers. The real function used here excludes zero and negative arguments.
