Estimates sample standard deviation using `n-1` in the denominator.

`STDEV.S` measures spread when your values represent a sample of a larger population.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=STDEV.S(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Requires at least two numeric values.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#DIV/0!` when fewer than two numeric values are provided.

## Examples

<FunctionExample
  title={"Find the sample standard deviation of 4, 8 and 12."}
  formula={"=STDEV.S(4,8,12)"}
  grid={{}}

<FunctionExample
  title={"Pass one three-element array to compute the sample standard deviation."}

  expected={"4"}
/>

<FunctionExample
  title={"Use 4 and 12, the minimum two observations for the sample standard deviation."}
  formula={"=STDEV.S(4,12)"}
  grid={{}}

/>

<FunctionExample
  title={"A lone observation cannot supply the denominator for the sample standard deviation."}

  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Sample standard deviation from scalar arguments"}
  formula={"=STDEV.S(2,4,6)"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
