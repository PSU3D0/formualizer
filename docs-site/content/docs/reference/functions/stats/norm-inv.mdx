Returns the value `x` whose normal cumulative probability equals `probability`.

This function is the inverse of `NORM.DIST(x, mean, standard_dev, TRUE)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NORM.INV(probability, mean, standard_dev)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `mean` | number | Required | — |
| `standard_dev` | number | Required | — |

## How it works

Adds mean to standard_dev times the standard normal quantile at the supplied probability. Standard deviation must be positive and the probability must lie strictly between zero and one.

## Remarks
 - `probability` must be strictly between `0` and `1`.
 - `standard_dev` must be strictly greater than `0`.
 - Invalid numeric coercions propagate as spreadsheet errors.
 - Alias `NORMINV` (the Excel 2007 compatibility name) is supported.

## Error cases

 - Returns `#NUM!` for invalid probability bounds or non-positive standard deviation.
