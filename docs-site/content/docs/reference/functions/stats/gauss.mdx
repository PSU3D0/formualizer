Returns the standard normal area between `0` and `z`.

`GAUSS` computes `NORM.S.DIST(z, TRUE) - 0.5`, preserving the sign of `z`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GAUSS(z)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `z` | number | Required | — |

## How it works

Gives Φ(z) − 0.5, the signed standard-normal area between zero and z. Any real z is valid and the result changes sign when z does.

## Remarks
 - Positive `z` returns a positive area; negative `z` returns a negative area.
 - `GAUSS(0)` returns `0`.
 - Output magnitude is always less than `0.5`.
 - Invalid numeric coercions propagate as spreadsheet errors.
