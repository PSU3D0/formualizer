Returns an exclusive quartile value for a data set.

`QUARTILE.EXC` applies exclusive percentile interpolation and supports quartiles `1` through
 `3`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=QUARTILE.EXC(array, quart)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | number (range) | Required | — |
| `quart` | number (range) | Required | — |

## Remarks
 - Valid quartile index values are `1`, `2`, and `3`.

## Error cases

 - Returns `#NUM!` for invalid quartile index values.
 - Returns `#NUM!` when the input is too small for exclusive quartile interpolation.

## FAQ

### Why can QUARTILE.EXC return #NUM! on small datasets?
Exclusive quartiles need enough data for valid interior rank interpolation.
