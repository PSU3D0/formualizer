Returns the inverse of the right-tailed F probability (legacy name).

`FINV(probability, deg_freedom1, deg_freedom2)` is the `x` with
 `FDIST(x, deg_freedom1, deg_freedom2) = probability`, the same as `F.INV.RT`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FINV(probability, deg_freedom1, deg_freedom2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom1` | number | Required | — |
| `deg_freedom2` | number | Required | — |

## How it works

Maps to F.INV.RT with the same arguments. Finds the nonnegative F statistic that leaves a given right-tail probability, using numerator degrees of freedom before denominator degrees of freedom.

## Remarks
 - Both degrees of freedom are truncated to integers.

## Error cases

 - Returns `#NUM!` when `probability` is outside `[0, 1]` or either degrees of freedom is
   `&lt; 1` or `&gt;= 10^10`.
