Returns the right-tailed Student's t-distribution probability.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=T.DIST.RT(x, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

For nonnegative x, returns P(T ≥ x) for a Student t variate with positive degrees of freedom. At x = 0 the right tail is half the probability.
