Returns the standard normal probability for a z-score as either a CDF or PDF value.

Use `NORM.S.DIST` for z-based probability lookups when the distribution has mean `0` and
 standard deviation `1`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NORM.S.DIST(z, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `z` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

With cumulative TRUE, returns the integral of exp(−t²/2) / √(2π) up to z from negative infinity. With FALSE it returns the integrand at z. The domain is the real line.

## Remarks
 - Set `cumulative` to a non-zero value for the cumulative distribution `P(Z &lt;= z)`.
 - Set `cumulative` to `0` for the probability density at exactly `z`.
 - Accepts any real-valued `z`; no domain clipping is applied.
 - Invalid numeric coercions propagate as spreadsheet errors.
