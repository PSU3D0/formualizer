Returns the most frequently occurring value in a data set.

`MODE.SNGL` returns a single mode value and reports `#N/A` if no value repeats.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MODE.SNGL(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Returns the first mode encountered after sorting when frequencies tie.
 - Alias `MODE` is supported.

## Error cases

 - Returns `#N/A` when every numeric value appears only once.

## Examples

<FunctionExample
  title={"Find a repeated value among four entries."}

<FunctionExample

/>

<FunctionExample

/>

<FunctionExample

  formula={"=MODE.SNGL(1,2,2,3)"}

## FAQ

### When does MODE.SNGL return #N/A?
It returns #N/A when no value repeats in the numeric dataset.
