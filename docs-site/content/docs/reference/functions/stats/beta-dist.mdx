Returns the beta-distribution probability for `x`, with optional lower/upper bounds.

`BETA.DIST` can evaluate either the cumulative probability or density on `[A, B]` (default
 `[0, 1]`).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BETA.DIST(x, alpha, beta, cumulative, [a], [b])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `alpha` | number | Required | — |
| `beta` | number | Required | — |
| `cumulative` | number | Required | — |
| `a` | number | Optional | — |
| `b` | number | Optional | — |

## How it works

With t = (x − A)/(B − A), the density on [A,B] is proportional to t raised to alpha − 1 times (1 − t) raised to beta − 1. Both shapes must be positive, B must exceed A, and x must lie within the closed interval. The cumulative switch integrates that density from A to x.

## Remarks
 - Requires `alpha &gt; 0`, `beta &gt; 0`, and `A &lt; B`.
 - `x` must lie within the inclusive interval `[A, B]`.
 - Set `cumulative` to non-zero for CDF mode, or `0` for PDF mode.

## Error cases

 - Returns `#NUM!` for invalid bounds, parameters, or out-of-range `x`.
