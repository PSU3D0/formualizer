Returns the value of the gamma function.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GAMMA(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |

## Examples

<FunctionExample
  title={"Compute Γ(4), which equals the factorial of three."}
  formula={"=GAMMA(4)"}
  grid={{}}
  expected={"6"}
/>

<FunctionExample
  title={"Evaluate Γ(1/2), the square root of π."}
  formula={"=GAMMA(0.5)"}
  grid={{}}
  expected={"1.77245385090551"}
/>

<FunctionExample
  title={"At one, Formualizer returns a value just below the mathematical result of one."}
  formula={"=GAMMA(1)"}
  grid={{}}
  expected={"0.999999999999999"}
/>

<FunctionExample
  title={"A zero argument is outside the supported domain."}
  formula={"=GAMMA(0)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Gamma extends factorials"}
  formula={"=GAMMA(5)"}
  grid={{}}
  expected={"24"}
/>

## FAQ

### When does GAMMA return #NUM!?
It returns #NUM! for zero and negative integers, where the gamma function has poles.
