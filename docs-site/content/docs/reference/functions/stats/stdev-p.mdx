Returns population standard deviation using `n` in the denominator.

Use `STDEV.P` when your values represent the entire population, not a sample.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=STDEV.P(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Requires at least one numeric value.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#DIV/0!` when no numeric values are provided.

## Examples

<FunctionExample
  title={"Find the population standard deviation of 4, 8 and 12."}
  formula={"=STDEV.P(4,8,12)"}
  grid={{}}
  expected={"3.2659863237109"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the population standard deviation."}
  formula={"=STDEV.P({4,8,12})"}
  grid={{}}
  expected={"3.2659863237109"}
/>

<FunctionExample
  title={"A one-value population has standard deviation zero."}
  formula={"=STDEV.P(7)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the population standard deviation."}
  formula={"=STDEV.P(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Population standard deviation from scalar arguments"}
  formula={"=STDEV.P(2,4,6)"}
  grid={{}}
  expected={"1.63299316185545"}
/>

<FunctionExample
  title={"Population standard deviation from a range"}
