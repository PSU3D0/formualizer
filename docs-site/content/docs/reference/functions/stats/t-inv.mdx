Returns the t-value whose left-tail probability equals `probability`.

`T.INV` is the inverse of `T.DIST(x, deg_freedom, TRUE)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=T.INV(probability, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Solves P(T ≤ q) = probability for a Student t variate with positive degrees of freedom. Probabilities below one half return a negative quantile.

## Remarks
 - `probability` must be strictly between `0` and `1`.
 - `deg_freedom` must be at least `1`.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` for out-of-range probability or invalid degrees of freedom.
