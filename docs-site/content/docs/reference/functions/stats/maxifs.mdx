Returns the maximum numeric value in a range that meets all criteria.

`MAXIFS` applies one or more `(criteria_range, criteria)` pairs and returns the largest
 matching numeric value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MAXIFS(max_range, criteria_range1, criteria1, [(criteria_range2, criteria2), ...])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `max_range` | any | Required | — |
| `criteria_range1` | any | Required | — |
| `criteria1` | any | Required | — |
| `criteria_range2` | any | Optional | — |
| `criteria2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 3.

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - Arguments must be `target_range` plus one or more criteria pairs.
 - Criteria are combined with logical AND.
 - Returns `0` when no cells satisfy all criteria.
 - Non-numeric cells in `target_range` are ignored.

## Examples

<FunctionExample
  title={"Aggregate numbers from only the East records."}
  formula={"=MAXIFS(A1:A3,B1:B3,\"East\")"}
  grid={{"A1":"10","A2":"50","A3":"20","B1":"\"East\"","B2":"\"West\"","B3":"\"East\""}}
  expected={"20"}
/>

<FunctionExample
  title={"Add a second criterion so both conditions must hold."}
  formula={"=MAXIFS(A1:A3,B1:B3,\"East\",C1:C3,\"<5\")"}
  grid={{"A1":"10","A2":"50","A3":"20","B1":"\"East\"","B2":"\"West\"","B3":"\"East\"","C1":"2","C2":"4","C3":"6"}}
  expected={"10"}
/>

<FunctionExample
  title={"Aggregate the only row in a single-row data set."}
  formula={"=MAXIFS(A1:A1,B1:B1,\"East\",C1:C1,2)"}
  grid={{"A1":"10","B1":"\"East\"","C1":"2"}}
  expected={"10"}
/>

<FunctionExample
  title={"Maximum value for one condition"}
  formula={"=MAXIFS(A1:A3,B1:B3,\"East\")"}
  grid={{"A1":"10","A2":"20","A3":"15","B1":"\"East\"","B2":"\"West\"","B3":"\"East\""}}
  expected={"15"}
/>

<FunctionExample
  title={"Maximum value with two criteria"}
  formula={"=MAXIFS(A1:A4,B1:B4,\"B\",C1:C4,\"Q1\")"}
  grid={{"A1":"100","A2":"80","A3":"90","A4":"70","B1":"\"A\"","B2":"\"A\"","B3":"\"B\"","B4":"\"B\"","C1":"\"Q1\"","C2":"\"Q2\"","C3":"\"Q1\"","C4":"\"Q1\""}}
  expected={"90"}
/>

## FAQ

### What does MAXIFS return when no rows match all criteria?
It returns 0 when no numeric target cells satisfy every criterion.
