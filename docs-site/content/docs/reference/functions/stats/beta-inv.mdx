Returns the inverse cumulative beta distribution, optionally scaled to custom bounds.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BETA.INV(probability, alpha, beta, [a], [b])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `alpha` | number | Required | — |
| `beta` | number | Required | — |
| `a` | number | Optional | — |
| `b` | number | Optional | — |

## How it works

Solves the cumulative beta equation F(x) = probability for x in [A,B]. Both shapes must be positive and the probability must be in [0,1]. The two extreme probabilities give the endpoints.

## FAQ

### When does BETA.INV return #NUM!?
It returns #NUM! for non-positive alpha or beta, invalid bounds, or probabilities outside 0..1.
