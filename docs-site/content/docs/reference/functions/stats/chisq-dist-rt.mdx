Returns the right-tailed chi-squared distribution probability.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHISQ.DIST.RT(x, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Returns P(X ≥ x) for a chi-squared variate, the integral above x of a gamma density with shape ν/2 and scale 2. The statistic must be nonnegative and ν positive.
