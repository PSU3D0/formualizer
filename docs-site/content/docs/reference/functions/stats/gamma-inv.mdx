Returns the inverse cumulative gamma distribution.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GAMMA.INV(probability, alpha, beta)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `alpha` | number | Required | — |
| `beta` | number | Required | — |

## How it works

Takes a probability and solves for the nonnegative x whose gamma CDF equals that probability at the chosen positive shape and scale. Zero probability gives zero.
