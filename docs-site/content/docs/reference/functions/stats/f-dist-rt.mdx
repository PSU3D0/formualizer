Returns the right-tailed F-distribution probability.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=F.DIST.RT(x, deg_freedom1, deg_freedom2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom1` | number | Required | — |
| `deg_freedom2` | number | Required | — |

## How it works

Gives P((U/d₁)/(V/d₂) ≥ x) for independent chi-squared variates. Both degrees of freedom must be positive. Swapping them generally changes the tail at the same nonnegative x.
