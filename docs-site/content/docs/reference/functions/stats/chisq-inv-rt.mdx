Returns the inverse of the right-tailed chi-squared distribution.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHISQ.INV.RT(probability, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Finds the cutoff q with P(X ≥ q) equal to the requested probability. With positive degrees of freedom and probability 1, the right-tail cutoff is zero.

## FAQ

### What p-values are valid for CHISQ.INV.RT?
p must lie in the range 0 to 1, and p=0 returns #NUM! because the right-tail inverse diverges.
