Returns the population variance using A-variant coercion semantics.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=VARPA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.

## Examples

<FunctionExample
  title={"Find the population variance with logical and text coercion of 4, 8 and 12."}
  formula={"=VARPA(4,8,12)"}
  grid={{}}
  expected={"10.6666666666667"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the population variance with logical and text coercion."}
  formula={"=VARPA({4,8,12})"}
  grid={{}}
  expected={"10.6666666666667"}
/>

<FunctionExample
  title={"With just one value to coerce, the population variance is zero."}
  formula={"=VARPA(7)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the population variance with logical and text coercion."}
  formula={"=VARPA(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Compute population variance across 4, TRUE and Pending with the denominator including the logical and text cells."}
  formula={"=VARPA(A1:A3)"}
  grid={{"A1":"4","A2":"TRUE","A3":"\"Pending\""}}
  expected={"2.88888888888889"}
/>

## FAQ

### When does VARPA return #DIV/0!?
It returns #DIV/0! when no coerced values remain after evaluation.
