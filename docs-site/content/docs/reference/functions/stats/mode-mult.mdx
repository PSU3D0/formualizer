Returns all modal values as a vertical array.

Use `MODE.MULT` when a data set can have multiple values with the same highest frequency.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MODE.MULT(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Can return an array.

## Remarks
 - Returns each tied mode as a separate row in the result array.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#N/A` when every numeric value appears only once.

## Examples

<FunctionExample
  title={"Find a repeated value among four entries."}
  formula={"=MODE.MULT(7,7,2,9)"}
  grid={{}}
  expected={"7"}
/>

<FunctionExample
  title={"Supply an array with two equally frequent values."}
  formula={"=MODE.MULT({7,7,2,2,9})"}
  grid={{}}
  expected={"{2; 7}"}
/>

<FunctionExample
  title={"Use a pair of identical values, the minimum input with a mode."}
  formula={"=MODE.MULT(8,8)"}
  grid={{}}
  expected={"8"}
/>

<FunctionExample
  title={"With no repeated value there is no mode."}
  formula={"=MODE.MULT(7,2,9)"}
  grid={{}}
  expected={"#N/A"}
/>

<FunctionExample
  title={"Multiple modes from direct values"}
  formula={"=MODE.MULT({1,2,2,3,3,4})"}
  grid={{}}
  expected={"{2; 3}"}
/>

<FunctionExample
  title={"Single repeated mode still returns an array"}
  formula={"=MODE.MULT(A1:A4)"}
  grid={{"A1":"5","A2":"5","A3":"2","A4":"1"}}
  expected={"5"}
/>

## FAQ

### Why can MODE.MULT return an array result?
It emits every value tied for highest frequency as separate rows.
