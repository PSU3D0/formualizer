Returns the population standard deviation using A-variant coercion semantics.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=STDEVPA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.

## Examples

<FunctionExample
  title={"Find the population standard deviation with logical and text coercion of 4, 8 and 12."}
  formula={"=STDEVPA(4,8,12)"}
  grid={{}}
  expected={"3.2659863237109"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the population standard deviation with logical and text coercion."}
  formula={"=STDEVPA({4,8,12})"}
  grid={{}}
  expected={"3.2659863237109"}
/>

<FunctionExample
  title={"One numeric cell value gives a population standard deviation of zero."}
  formula={"=STDEVPA(7)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"A division error among 4 and 12 prevents computing the population standard deviation with logical and text coercion."}
  formula={"=STDEVPA(4,1/0,12)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Treat 4, TRUE and Pending as a population of three values, with TRUE and text contributing 1 and 0."}
  formula={"=STDEVPA(A1:A3)"}
  grid={{"A1":"4","A2":"TRUE","A3":"\"Pending\""}}
  expected={"1.69967317119759"}
/>

## FAQ

### What is the difference between STDEVA and STDEVPA?
STDEVA uses the sample denominator n-1, while STDEVPA uses the population denominator n.
