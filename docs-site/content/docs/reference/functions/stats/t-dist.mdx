Returns the Student's t probability for `x` and a given degrees-of-freedom value.

Use `T.DIST` in either cumulative mode (left-tail probability) or density mode.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=T.DIST(x, deg_freedom, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

For positive degrees of freedom ν, Student’s t density is proportional to (1 + x²/ν) raised to −(ν+1)/2. The cumulative option integrates that density from negative infinity through the supplied statistic.

## Remarks
 - Set `cumulative` to non-zero for CDF mode, or `0` for PDF mode.
 - `deg_freedom` must be at least `1`.
 - Invalid numeric coercions propagate as spreadsheet errors.

## Error cases

 - Returns `#NUM!` when `deg_freedom &lt; 1`.
