Returns the slope of the linear regression line for paired data.

`SLOPE` fits `y = m*x + b` and returns `m`, the rate of change in `y` per unit of `x`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SLOPE(known_ys, known_xs)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `known_ys` | number (range) | Required | — |
| `known_xs` | number (range) | Required | — |

## Remarks
 - `known_y` and `known_x` must have the same numeric length.

## Error cases

 - Returns `#N/A` for mismatched lengths.
 - Returns `#DIV/0!` if all `x` values are identical.

## Examples

<FunctionExample
  title={"Describe a linear fit between paired x and y observations."}

<FunctionExample
