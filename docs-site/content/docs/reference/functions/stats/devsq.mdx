Returns the sum of squared deviations from the mean.

`DEVSQ` is useful for variance-related calculations and diagnostics of spread.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DEVSQ(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - Non-numeric values in referenced ranges are ignored.
 - Uses the arithmetic mean of included values.

## Error cases

 - Returns `#NUM!` when no numeric values are available.
