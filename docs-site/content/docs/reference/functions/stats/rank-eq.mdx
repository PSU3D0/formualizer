Returns the rank position of a number within a data set, with ties sharing the same rank.

`RANK.EQ` defaults to descending order (largest value is rank 1), and can switch to ascending
 order when `order` is non-zero.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=RANK.EQ(number, ref, [order])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number (range) | Required | — |
| `ref` | number (range) | Required | — |
| `order` | number (range) | Optional | — |

## Remarks
 - Omitting `order`, or setting `order` to `0`, ranks values in descending order.
 - Any non-zero `order` ranks values in ascending order.
 - Tied values receive the same rank (the first matching position in the sorted list).

## Error cases

 - Returns `#N/A` if `number` is not found in `ref`.

## Examples

<FunctionExample
  title={"Rank a value tied with a second observation."}
  formula={"=RANK.EQ(20,{10,20,20,40,50})"}
  grid={{}}
  expected={"3"}
/>

<FunctionExample
  title={"Select ascending ranking instead of descending ranking."}
  formula={"=RANK.EQ(20,{10,20,20,40,50},1)"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"The largest value is ranked first in descending order."}
  formula={"=RANK.EQ(40,{10,20,20,40})"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"A value absent from the source array has no rank."}
  formula={"=RANK.EQ(25,{10,20,20,40})"}
  grid={{}}
  expected={"#N/A"}
/>

<FunctionExample
  title={"Descending rank with direct values"}
  formula={"=RANK.EQ(7,{10,7,4,2})"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"Ascending rank with ties in a range"}
  formula={"=RANK.EQ(A2,A1:A5,1)"}
  grid={{"A1":"50","A2":"20","A3":"20","A4":"10","A5":"5"}}
  expected={"3"}
/>

## FAQ

### When does RANK.EQ return #N/A?
It returns #N/A when the target number does not appear in the reference set.
