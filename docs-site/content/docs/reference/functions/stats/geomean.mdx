Returns the geometric mean of positive numeric values.

`GEOMEAN` is commonly used for rates of change and multiplicative growth comparisons.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GEOMEAN(number1, [number2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number1` | number (range) | Required | — |
| `number2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Remarks
 - All numeric inputs must be strictly greater than `0`.
 - Non-numeric values in referenced ranges are ignored.

## Error cases

 - Returns `#NUM!` if any value is `&lt;= 0`, or if no numeric values are provided.

## Examples

<FunctionExample
  title={"Find the geometric mean of 4, 8 and 12."}

<FunctionExample
  title={"With a single positive factor, the geometric mean is the factor itself."}

  grid={{}}

<FunctionExample

/>

<FunctionExample
  title={"Geometric mean from scalar values"}
  formula={"=GEOMEAN(4,16)"}
  grid={{}}

/>

<FunctionExample

## FAQ

### When does GEOMEAN return #NUM!?
GEOMEAN returns #NUM! if any numeric value is &lt;= 0 or if no numeric values exist.
