Returns the sample standard deviation using A-variant coercion semantics.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=STDEVA(value1, [value2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value1` | number (range) | Required | — |
| `value2` | number (range) | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Differences from Excel

Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.

## Examples

<FunctionExample
  title={"Find the sample standard deviation with logical and text coercion of 4, 8 and 12."}
  formula={"=STDEVA(4,8,12)"}
  grid={{}}
  expected={"4"}
/>

<FunctionExample
  title={"Pass one three-element array to compute the sample standard deviation with logical and text coercion."}
  formula={"=STDEVA({4,8,12})"}
  grid={{}}
  expected={"4"}
/>

<FunctionExample
  title={"Use 4 and 12, the minimum two observations for the sample standard deviation with logical and text coercion."}
  formula={"=STDEVA(4,12)"}
  grid={{}}
  expected={"5.65685424949238"}
/>

<FunctionExample
  title={"A lone observation cannot supply the denominator for the sample standard deviation with logical and text coercion."}
  formula={"=STDEVA(4)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Compute sample standard deviation over 4, TRUE and Pending, treating the last two as 1 and 0."}
  formula={"=STDEVA(A1:A3)"}
  grid={{"A1":"4","A2":"TRUE","A3":"\"Pending\""}}
  expected={"2.08166599946613"}
/>

## FAQ

### When does STDEVA return #DIV/0!?
It returns #DIV/0! when fewer than two coerced values remain after evaluation.
