Returns the half-width of a confidence interval using a normal critical value.

`CONFIDENCE.NORM` computes `z_crit * standard_dev / sqrt(size)` for two-sided intervals.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CONFIDENCE.NORM(alpha, standard_dev, size)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `alpha` | number | Required | — |
| `standard_dev` | number | Required | — |
| `size` | number | Required | — |

## Remarks
 - `alpha` must satisfy `0 &lt; alpha &lt; 1`.
 - `standard_dev` must be greater than `0`.
 - `size` must be at least `1`.

## Error cases

 - Returns `#NUM!` when any input is outside valid bounds.
