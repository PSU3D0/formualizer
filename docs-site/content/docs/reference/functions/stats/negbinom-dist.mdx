Returns negative-binomial probabilities for failures observed before a target success count.

`NEGBINOM.DIST` supports exact-failure mode (PMF) and cumulative mode (CDF).

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NEGBINOM.DIST(number_f, number_s, probability_s, cumulative)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number_f` | number | Required | — |
| `number_s` | number | Required | — |
| `probability_s` | number | Required | — |
| `cumulative` | number | Required | — |

## How it works

At f failures before the rth success, the probability is C(f+r−1,f) pʳ(1−p)ᶠ. The cumulative mode counts at most f failures. Valid inputs have f ≥ 0, r ≥ 1 and p in [0,1].

## Remarks
 - `number_f` is truncated and must be `&gt;= 0`.
 - `number_s` is truncated and must be `&gt;= 1`.
 - `probability_s` must satisfy `0 &lt; p &lt; 1`.

## Error cases

 - Returns `#NUM!` when counts or probability are outside valid ranges.
