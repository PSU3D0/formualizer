Returns the one-tailed p-value of a z-test against hypothesized mean `x`.

`Z.TEST` evaluates whether the sample mean is significantly greater than the target value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=Z.TEST(array, x, [sigma])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `array` | number (range) | Required | — |
| `x` | number | Required | — |
| `sigma` | number | Optional | — |

## Remarks
 - Uses provided `sigma` when supplied; otherwise uses the sample standard deviation
   (`STDEV.S`), as Excel does.

## Error cases

 - Returns `#NUM!` when `sigma &lt;= 0`.
 - Returns `#DIV/0!` when `sigma` is omitted and there are fewer than two values or the
   sample standard deviation is zero.
 - Returns `#N/A` when the data array has no numeric values.

## Examples

/>

<FunctionExample

<FunctionExample
  title={"Compare the sample with a hypothesized mean equal to its observed mean."}
  formula={"=Z.TEST({8,10,12,14,16},12,3)"}

/>

<FunctionExample
  title={"A population standard deviation of zero cannot be used for the test."}

  expected={"#NUM!"}
/>
