Returns the right-tailed chi-squared probability (legacy name).

`CHIDIST(x, deg_freedom)` is `P(X &gt; x)`, the same as `CHISQ.DIST.RT`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=CHIDIST(x, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Maps to CHISQ.DIST.RT(x, degrees_freedom), with both arguments in the same order. Integrates the chi-squared density above nonnegative x, with positive degrees of freedom.

## Remarks
 - `deg_freedom` is truncated to an integer.

## Error cases

 - Returns `#NUM!` when `x &lt; 0`, `deg_freedom &lt; 1`, or `deg_freedom &gt; 10^10`.
