Returns a vertical frequency distribution for numeric data across bin cutoffs.

`FREQUENCY` counts values into `&lt;= first bin`, intermediate right-closed bins, and an overflow
 bucket above the final bin.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FREQUENCY(data_array, bins_array)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `data_array` | number (range) | Required | — |
| `bins_array` | number (range) | Required | — |

## Return type

Can return an array.

## Remarks
 - Returns an array with `bins + 1` rows.
 - Bins are sorted before counting.
 - If `bins_array` has no numeric values, result is a single count of all data points.
 - Non-numeric values in input ranges are ignored by statistical-collection rules.

## Examples

<FunctionExample
  title={"Count observations in two bins and an overflow bin."}
  formula={"=FREQUENCY({1,3,7,10},{3,7})"}
  grid={{}}
  expected={"{2; 1; 1}"}
/>

<FunctionExample
  title={"Replace the bin boundaries with narrower intervals."}
  formula={"=FREQUENCY({1,3,7,10},{2,4,6,8})"}
  grid={{}}
  expected={"{1; 1; 0; 1; 1}"}
/>

<FunctionExample
  title={"An observation equal to a bin limit belongs to the bin ending there."}
  formula={"=FREQUENCY({3},{3})"}
  grid={{}}
  expected={"{1; 0}"}
/>

<FunctionExample
  title={"A division-by-zero error cannot provide a data array."}
  formula={"=FREQUENCY(1/0,{3,7})"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Frequency buckets with two bins"}
  formula={"=FREQUENCY({1,2,3,4,5},{2,4})"}
  grid={{}}
  expected={"{2; 2; 1}"}
/>

<FunctionExample
  title={"Frequency with repeated values"}
  formula={"=FREQUENCY({1,1,2,2,3},{1,2})"}
  grid={{}}
  expected={"{2; 2; 1}"}
/>
