Returns the right-tailed F probability (legacy name).

`FDIST(x, deg_freedom1, deg_freedom2)` is `P(F &gt; x)`, the same as `F.DIST.RT`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FDIST(x, deg_freedom1, deg_freedom2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | number | Required | — |
| `deg_freedom1` | number | Required | — |
| `deg_freedom2` | number | Required | — |

## How it works

Maps to F.DIST.RT(x, degrees_freedom1, degrees_freedom2) with the same arguments. Finds the probability above x in a ratio of independent sample variances, with nonnegative x and two positive degrees of freedom.

## Remarks
 - Both degrees of freedom are truncated to integers.

## Error cases

 - Returns `#NUM!` when `x &lt; 0` or either degrees of freedom is `&lt; 1` or `&gt;= 10^10`.
