Returns the two-tailed inverse of the Student's t distribution (legacy name).

`TINV(probability, deg_freedom)` is the `t` with `P(|T| &gt; t) = probability`,
 the same as `T.INV.2T`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TINV(probability, deg_freedom)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `probability` | number | Required | — |
| `deg_freedom` | number | Required | — |

## How it works

Maps to T.INV.2T with the same argument order. It finds the nonnegative cutoff with the given probability outside the interval from −x to x. Degrees of freedom must be positive.

## Remarks
 - `deg_freedom` is truncated to an integer.

## Error cases

 - Returns `#NUM!` when `probability &lt;= 0`, `probability &gt; 1`, or `deg_freedom &lt; 1`.
