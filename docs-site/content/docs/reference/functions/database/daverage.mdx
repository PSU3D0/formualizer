Returns the arithmetic mean of values in a database field for matching records.

`DAVERAGE` applies criteria filtering first, then averages the numeric values in `field`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DAVERAGE(database, field, criteria)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `database` | any | Required | — |
| `field` | any | Required | — |
| `criteria` | any | Required | — |

## Return type

Number

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - Criteria rows are OR conditions, while criteria columns in the same row are AND conditions.

## Error cases

 - `field` can be a case-insensitive header name or a 1-based column index; invalid field resolution returns `#VALUE!`.
 - If no numeric values match, the function returns `#DIV/0!`.

## FAQ

### What happens if criteria match rows but field values are non-numeric?
DAVERAGE skips non-numeric values and returns #DIV/0! if no numeric values remain after filtering.
