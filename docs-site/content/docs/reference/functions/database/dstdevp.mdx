Returns the population standard deviation of a database field for matching records.

`DSTDEVP` computes standard deviation with the population denominator (`n`) after criteria filtering.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DSTDEVP(database, field, criteria)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `database` | any | Required | — |
| `field` | any | Required | — |
| `criteria` | any | Required | — |

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - Criteria rows are OR branches, and each row's populated criteria columns are ANDed.
 - At least one numeric value must match criteria, otherwise the result is `#DIV/0!`.

## Error cases

 - `field` can be a case-insensitive header label or 1-based index; invalid lookup returns `#VALUE!`.

## FAQ

### When should I prefer DSTDEVP over DSTDEV?
Use DSTDEVP when matching rows represent the full population; DSTDEV is for samples.
