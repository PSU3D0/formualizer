Counts non-blank values in a database field for records matching criteria.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DCOUNTA(database, field, criteria)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `database` | any | Required | — |
| `field` | any | Required | — |
| `criteria` | any | Required | — |

## Remarks
 - An equality criterion for a date or number (`"10/26/1999"`, `"36459"`, `36459`) also
   matches text cells holding that date; `&lt;&gt;` and ordering criteria do not read date text.
 - `DCOUNTA` counts both text and numeric non-empty values.
 - Criteria rows are OR-ed; criteria columns in the same row are AND-ed.
 - Blank cells are excluded from the count.

## Examples

<FunctionExample
  title={"Count the populated values in the Score column for the two East records."}
  formula={"=DCOUNTA(A1:B4,\"Score\",D1:D2)"}

  expected={"2"}
/>

<FunctionExample

  expected={"2"}
/>

<FunctionExample

## FAQ

### What is treated as blank in DCOUNTA?
Empty cells and empty strings are treated as blank; other value types are counted when their row matches criteria.
