Returns the tangent of a complex number.

Accepts an Excel-style complex number string and returns the complex tangent
 as text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMTAN(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex tangent is sin(z) / cos(z). It is undefined at the zeros of cos(z), which occur at π/2 plus integer multiples of π.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Examples

<FunctionExample
  title={"Divide the complex sine of 3 + 4i by its cosine."}
  formula={"=IMTAN(\"3+4i\")"}
  grid={{}}
  expected={"-0.000187346204629488+0.999355987381473i"}
/>

<FunctionExample
  title={"Reflect the input to flip the imaginary sign of the tangent."}
  formula={"=IMTAN(\"3-4j\")"}
  grid={{}}
  expected={"-0.000187346204629488-0.999355987381473j"}
/>

<FunctionExample
  title={"With a real argument the result is tan(1)."}
  formula={"=IMTAN(\"1\")"}
  grid={{}}
  expected={"1.5574077246549"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the complex tangent."}
  formula={"=IMTAN(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Tangent of zero"}
  formula={"=IMTAN(\"0\")"}
  grid={{}}
  expected={"0"}
/>

## FAQ

### How is IMTAN related to sine and cosine?
It computes the complex tangent, equivalent to IMSIN divided by IMCOS.
