Converts a hexadecimal text value to octal text.

Supports optional left-padding through the `places` argument.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HEX2OCT(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |
| `places` | any | Optional | — |

## Return type

Can return text.

## Remarks
 - Input must be hexadecimal text up to 10 characters and may be signed two's-complement.
 - Converted values must fit the octal range `[-2^29, 2^29 - 1]`, or `#NUM!` is returned.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Examples

<FunctionExample
  title={"Convert hexadecimal 1E with no output padding."}
  formula={"=HEX2OCT(\"1E\")"}
  grid={{}}
  expected={"36"}
/>

<FunctionExample
  title={"Use eight output characters to preserve leading zeros."}
  formula={"=HEX2OCT(\"1E\",8)"}
  grid={{}}
  expected={"00000036"}
/>

<FunctionExample
  title={"Convert zero with a one-place width."}
  formula={"=HEX2OCT(\"0\",1)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The input contains an invalid hexadecimal digit."}
  formula={"=HEX2OCT(\"G\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Convert hex to octal"}
  formula={"=HEX2OCT(\"1F\")"}
  grid={{}}
  expected={"37"}
/>

<FunctionExample
  title={"Convert signed hex"}
  formula={"=HEX2OCT(\"FFFFFFFFFF\")"}
  grid={{}}
  expected={"7777777777"}
/>

## FAQ

### What causes `HEX2OCT` to return `#NUM!`?
The decoded value must fit octal output range `[-2^29, 2^29 - 1]`, and optional `places` must be valid.
