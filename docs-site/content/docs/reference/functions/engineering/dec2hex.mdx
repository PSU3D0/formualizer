Converts a decimal integer to hexadecimal text.

Optionally pads the result with leading zeros using `places`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DEC2HEX(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `places` | number | Optional | — |

## Return type

Can return text.

## Remarks
 - `number` is coerced to an integer and must be in `[-2^39, 2^39 - 1]`.
 - Negative values are returned as 10-digit two's-complement hexadecimal strings.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Examples

<FunctionExample
  title={"Convert a decimal integer using the shortest output."}
  formula={"=DEC2HEX(30)"}
  grid={{}}
  expected={"1E"}
/>

<FunctionExample
  title={"Request eight characters to see the leading-zero padding."}
  formula={"=DEC2HEX(30,8)"}
  grid={{}}
  expected={"0000001E"}
/>

<FunctionExample
  title={"Convert a negative value to its signed representation."}
  formula={"=DEC2HEX(-1)"}
  grid={{}}
  expected={"FFFFFFFFFF"}
/>

<FunctionExample
  title={"A nonzero value cannot fit in a zero-place output."}
  formula={"=DEC2HEX(30,0)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Convert decimal to hex"}
  formula={"=DEC2HEX(255)"}
  grid={{}}
  expected={"FF"}
/>

<FunctionExample
  title={"Pad hexadecimal output"}
  formula={"=DEC2HEX(31,4)"}
  grid={{}}
  expected={"001F"}
/>

## FAQ

### How are negative values formatted by `DEC2HEX`?
Negative outputs use 10-digit two's-complement hexadecimal representation.
