Converts a hexadecimal text value to binary text.

Supports optional left-padding through the `places` argument.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HEX2BIN(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |
| `places` | any | Optional | — |

## Return type

Can return text.

## Remarks
 - Input must be hexadecimal text up to 10 characters and may be signed two's-complement.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Error cases

 - The converted decimal value must be in `[-512, 511]`, or the function returns `#NUM!`.

## Examples

<FunctionExample
  title={"Convert hexadecimal 1E with no output padding."}
  formula={"=HEX2BIN(\"1E\")"}
  grid={{}}
  expected={"11110"}
/>

<FunctionExample
  title={"Use eight output characters to preserve leading zeros."}
  formula={"=HEX2BIN(\"1E\",8)"}
  grid={{}}
  expected={"00011110"}
/>

<FunctionExample
  title={"Convert zero with a one-place width."}
  formula={"=HEX2BIN(\"0\",1)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The input contains an invalid hexadecimal digit."}
  formula={"=HEX2BIN(\"G\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Convert positive hex to binary"}
  formula={"=HEX2BIN(\"1F\")"}
  grid={{}}
  expected={"11111"}
/>

<FunctionExample
  title={"Convert signed hex"}
  formula={"=HEX2BIN(\"FFFFFFFFFF\")"}
  grid={{}}
  expected={"1111111111"}
/>

## FAQ

### Why can valid hex text still produce `#NUM!` in `HEX2BIN`?
After conversion, the decimal value must fit `[-512, 511]`; otherwise binary output is rejected.
