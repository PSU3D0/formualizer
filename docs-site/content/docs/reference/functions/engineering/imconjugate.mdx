Returns the complex conjugate of a complex number.

Negates the imaginary coefficient and keeps the real coefficient unchanged.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMCONJUGATE(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## Return type

Can return text.

## How it works

Conjugation reflects a + bi across the real axis to a − bi. Real inputs are unchanged.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Inputs are coerced to complex-number text before parsing.
 - Preserves the original suffix style (`i` or `j`) when possible.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"Reflect 3 + 4i to 3 − 4i across the real axis."}
  formula={"=IMCONJUGATE(\"3+4i\")"}
  grid={{}}
  expected={"3-4i"}
/>

<FunctionExample
  title={"Flip the sign of the j coefficient and keep the j suffix."}
  formula={"=IMCONJUGATE(\"3-4j\")"}
  grid={{}}
  expected={"3+4j"}
/>

<FunctionExample
  title={"The conjugate of a real unit is unchanged."}
  formula={"=IMCONJUGATE(\"1\")"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the conjugate."}
  formula={"=IMCONJUGATE(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Conjugate with j suffix"}
  formula={"=IMCONJUGATE(\"-2j\")"}
  grid={{}}
  expected={"2j"}
/>

## FAQ

### Does `IMCONJUGATE` keep the `i`/`j` suffix style?
Yes. It negates only the imaginary coefficient and preserves the parsed suffix form.
