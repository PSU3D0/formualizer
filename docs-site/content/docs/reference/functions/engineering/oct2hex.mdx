Converts an octal text value to hexadecimal text.

Supports optional left-padding through the `places` argument.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=OCT2HEX(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `places` | number | Optional | — |

## Return type

Can return text.

## Remarks
 - Input must be octal text up to 10 digits and may be signed two's-complement.
 - Signed values are converted through their decimal representation.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Examples

<FunctionExample
  title={"Convert octal 36 with no output padding."}
  formula={"=OCT2HEX(\"36\")"}
  grid={{}}
  expected={"1E"}
/>

<FunctionExample

  formula={"=OCT2HEX(\"36\",8)"}

/>

<FunctionExample
  title={"Convert zero with a one-place width."}
  formula={"=OCT2HEX(\"0\",1)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The input contains a digit outside base eight."}
  formula={"=OCT2HEX(\"8\")"}

/>

<FunctionExample

  formula={"=OCT2HEX(\"77\")"}
  grid={{}}

## FAQ

### How does `OCT2HEX` treat signed octal input?
Signed 10-digit octal is decoded via two's-complement and then emitted as hex, preserving signed meaning.
