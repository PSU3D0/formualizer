Returns the argument (angle in radians) of a complex number.

The angle is measured from the positive real axis.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMARGUMENT(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The principal angle of z = a + bi is atan2(b, a) in radians. Zero has no direction.

## Remarks
 - Inputs are coerced to complex-number text before parsing.

## Error cases

 - Returns `#DIV/0!` for `0+0i`, where the angle is undefined.
 - Invalid complex text returns `#NUM!`.

## Examples

## FAQ

### Why does `IMARGUMENT(0)` return `#DIV/0!`?
The argument (angle) of `0+0i` is undefined, so the function returns `#DIV/0!`.
