Returns the cotangent of a complex number.

Computes the reciprocal of the complex tangent for an Excel-style complex
 number string.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMCOT(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex cotangent is cos(z) / sin(z). It has poles at integer multiples of π, including zero.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Examples

<FunctionExample
  title={"Divide complex cosine by complex sine at 3 + 4i."}
  formula={"=IMCOT(\"3+4i\")"}
  grid={{}}
  expected={"-0.000187587737983679-1.00064439247156i"}
/>

<FunctionExample
  title={"Reflect the input across the real axis to reflect the cotangent."}
  formula={"=IMCOT(\"3-4j\")"}
  grid={{}}
  expected={"-0.000187587737983679+1.00064439247156j"}
/>

<FunctionExample
  title={"For a real radian angle of one, this returns the ordinary cotangent."}
  formula={"=IMCOT(\"1\")"}
  grid={{}}
  expected={"0.642092615934331"}
/>
