Converts a hexadecimal text value to decimal.

Supports up to 10 hex digits, including signed two's-complement values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=HEX2DEC(number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | any | Required | — |

## Remarks
 - Input is coerced to text and must contain only hexadecimal characters.
 - 10-digit values beginning with `8`-`F` are interpreted as signed 40-bit numbers.

## Error cases

 - Returns `#NUM!` for invalid characters or inputs longer than 10 digits.

## Examples

<FunctionExample

## FAQ

### When is a 10-digit hex input treated as negative in `HEX2DEC`?
If the first digit is `8` through `F`, it is decoded as signed 40-bit two's-complement.
