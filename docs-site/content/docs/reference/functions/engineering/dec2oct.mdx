Converts a decimal integer to octal text.

Optionally pads the result with leading zeros using `places`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DEC2OCT(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `places` | number | Optional | — |

## Return type

Can return text.

## Remarks
 - `number` is coerced to an integer and must be in `[-2^29, 2^29 - 1]`.
 - Negative values are returned as 10-digit two's-complement octal strings.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Examples

<FunctionExample
  title={"Convert a decimal integer using the shortest output."}
  formula={"=DEC2OCT(30)"}
  grid={{}}
  expected={"36"}
/>

<FunctionExample
  title={"Request eight characters to see the leading-zero padding."}

/>

<FunctionExample
  title={"Convert a negative value to its signed representation."}
  formula={"=DEC2OCT(-1)"}
  grid={{}}
  expected={"7777777777"}
/>

<FunctionExample
  title={"A nonzero value cannot fit in a zero-place output."}
  formula={"=DEC2OCT(30,0)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Convert decimal to octal"}
  formula={"=DEC2OCT(64)"}
  grid={{}}
  expected={"100"}
/>
