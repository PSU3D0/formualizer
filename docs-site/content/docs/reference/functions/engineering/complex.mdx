Builds a complex number text value from real and imaginary coefficients.

Returns canonical text such as `3+4i` or `-2j`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=COMPLEX(real_num, i_num, [suffix])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `real_num` | any | Required | — |
| `i_num` | any | Required | — |
| `suffix` | any | Optional | — |

## Return type

Can return text.

## How it works

Builds the text representation of a + bi or a + bj from real coefficients a and b. The suffix must be i or j.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - `real_num` and `i_num` are numerically coerced.
 - `suffix` may be `"i"`, `"j"`, empty text, or omitted; empty/omitted defaults to `i`.

## Error cases

 - Any other suffix returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Build complex text with nonzero real and imaginary coefficients."}
  formula={"=COMPLEX(3,4)"}
  grid={{}}
  expected={"3+4i"}
/>

<FunctionExample
  title={"Use j as the imaginary-unit suffix."}
  formula={"=COMPLEX(3,4,\"j\")"}
  grid={{}}
  expected={"3+4j"}
/>

<FunctionExample
  title={"Combine two zero coefficients."}
  formula={"=COMPLEX(0,0)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Only supported imaginary-unit suffixes can be used."}
  formula={"=COMPLEX(3,4,\"k\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Build with j suffix"}
  formula={"=COMPLEX(0,-1,\"j\")"}
  grid={{}}
  expected={"-j"}
/>

## FAQ

### Which suffix values are valid in `COMPLEX`?
Only suffixes i or j are accepted (empty or omitted defaults to i); other suffix strings return `#VALUE!`.
