Returns the imaginary coefficient of a complex number.

Accepts complex text (for example `a+bi`) or numeric values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMAGINARY(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

For z = a + bi, the result is b, the signed imaginary coefficient. A purely real input has imaginary coefficient zero.

## Remarks
 - Inputs are coerced to complex-number text before parsing.
 - Purely real values return `0`.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

## FAQ

### What does `IMAGINARY` return for a real-only input?
It returns `0` because there is no imaginary component.
