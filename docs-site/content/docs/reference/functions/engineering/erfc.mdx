Returns the complementary error function of a number.

`ERFC(x)` is equivalent to `1 - ERF(x)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ERFC(x)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | any | Required | — |

## How it works

The complementary error function is the area under exp(−t²) from x to infinity, scaled by 2 / √π. The result is 1 at x = 0 and approaches 2 as x goes to negative infinity.

## Remarks
 - Input is numerically coerced.
 - Results are approximate floating-point values.
 - Propagates input errors.

## FAQ

### Is `ERFC(x)` equivalent to `1-ERF(x)` here?
Yes. It computes the complementary error function and matches `1 - erf(x)` behavior.
