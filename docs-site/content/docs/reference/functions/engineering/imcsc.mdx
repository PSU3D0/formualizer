Returns the cosecant of a complex number.

Computes `1 / IMSIN(inumber)` for an Excel-style complex number string.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMCSC(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex cosecant is 1 / sin(z). It has poles at integer multiples of π.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Examples

<FunctionExample
  title={"Take the reciprocal of the complex sine of 3 + 4i."}
  formula={"=IMCSC(\"3+4i\")"}
  grid={{}}
  expected={"0.0051744731840194+0.036275889628626i"}
/>

<FunctionExample
  title={"Use the conjugate input to reverse the imaginary part of the reciprocal."}
  formula={"=IMCSC(\"3-4j\")"}
  grid={{}}
  expected={"0.0051744731840194-0.036275889628626j"}
/>

<FunctionExample
  title={"For one real radian, take the reciprocal of the ordinary sine."}
  formula={"=IMCSC(\"1\")"}
  grid={{}}
  expected={"1.18839510577812"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the complex cosecant."}
  formula={"=IMCSC(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Cosecant of pi over two"}
  formula={"=IMCSC(\"1.5707963267948966\")"}
  grid={{}}
  expected={"1"}
/>
