Returns the error function of a number.

This is the one-argument precise variant of `ERF`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ERF.PRECISE(x)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | any | Required | — |

## How it works

Integrates exp(−t²) from zero to x and multiplies the result by 2 / √π. It is defined on the real line and changes sign when x does. Unlike ERF, it takes just one limit.

## Remarks
 - Input is numerically coerced.
 - Equivalent to `ERF(x)` in single-argument mode.
 - Results are approximate floating-point values.

## FAQ

### How is `ERF.PRECISE` different from `ERF`?
`ERF.PRECISE` is the one-argument form only; numerically it matches `ERF(x)` for single input mode.
