Raises a complex number to a real power.

Uses polar form and returns the principal-value result as complex text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMPOWER(inumber, number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |
| `number` | any | Required | — |

## Return type

Can return text.

## How it works

For nonzero z and real p, the principal power is exp(p ln(z)), using the principal complex logarithm. Zero to a negative power is undefined.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - `inumber` is coerced to complex-number text; `n` is numerically coerced.

## Error cases

 - Returns `#NUM!` for undefined zero-power cases such as `0^0` or `0^-1`.
 - Invalid complex text returns `#NUM!`.

## FAQ

### How does `IMPOWER` handle zero base with non-positive exponent?
`0^0` and `0` raised to a negative exponent are treated as undefined and return `#NUM!`.
