Returns the modified Bessel function Kn(x).

Computes the modified Bessel function of the second kind for a positive real
 value `x` and a non-negative integer order `n`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=BESSELK(x, n)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | any | Required | — |
| `n` | any | Required | — |

## Remarks
 - Arguments are supplied as `BESSELK(x, n)`.
 - `x` must be positive and `n` must truncate to a non-negative integer.

## Error cases

 - Invalid domains or non-finite results return `#NUM!`.

## FAQ

### Why can BESSELK return #NUM!?
BESSELK is undefined for non-positive x values and negative orders.
