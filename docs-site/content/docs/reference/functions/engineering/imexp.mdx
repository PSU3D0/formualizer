Returns the complex exponential of a complex number.

Computes `e^(a+bi)` and returns the result as complex text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMEXP(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## Return type

Can return text.

## How it works

For a + bi, the exponential is exp(a) times cos(b) + i sin(b). It exists for every complex input.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Input is coerced to complex-number text before parsing.
 - Uses Euler's identity for the imaginary component.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"Scale a rotation of four radians by exp(3)."}
  formula={"=IMEXP(\"3+4i\")"}
  grid={{}}
  expected={"-13.1287830814622-15.200784463068i"}
/>

<FunctionExample
  title={"Reverse the rotation while leaving its magnitude unchanged."}
  formula={"=IMEXP(\"3-4j\")"}
  grid={{}}
  expected={"-13.1287830814622+15.200784463068j"}
/>

<FunctionExample
  title={"At real one the result reduces to the constant e."}
  formula={"=IMEXP(\"1\")"}
  grid={{}}
  expected={"2.71828182845905"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to exponentiate."}
  formula={"=IMEXP(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Exponential of zero"}
  formula={"=IMEXP(\"0\")"}
  grid={{}}
  expected={"1"}
/>
