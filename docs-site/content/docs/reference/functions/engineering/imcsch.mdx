Returns the hyperbolic cosecant of a complex number.

Computes `1 / IMSINH(inumber)` for an Excel-style complex number string.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMCSCH(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex hyperbolic cosecant is 1 / sinh(z). It has poles at integer multiples of πi.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Examples

<FunctionExample
  title={"Take the reciprocal of the hyperbolic sine of 3 + 4i."}
  formula={"=IMCSCH(\"3+4i\")"}
  grid={{}}
  expected={"-0.0648774713706355+0.0754898329158637i"}
/>

<FunctionExample
  title={"Reverse the sign of the imaginary coefficient before computing the reciprocal."}
  formula={"=IMCSCH(\"3-4j\")"}
  grid={{}}
  expected={"-0.0648774713706355-0.0754898329158637j"}
/>

<FunctionExample
  title={"At real one, the result is the reciprocal of sinh(1)."}
  formula={"=IMCSCH(\"1\")"}
  grid={{}}
  expected={"0.850918128239322"}
/>
