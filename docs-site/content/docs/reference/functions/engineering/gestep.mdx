Returns `1` when a number is greater than or equal to a step value.

Returns `0` when the number is below the step.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=GESTEP(number, [step])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `step` | number | Optional | — |

## Remarks
 - If `step` is omitted, it defaults to `0`.
 - Inputs are numerically coerced.
 - Propagates input errors.

## FAQ

### What default threshold does `GESTEP` use?
If omitted, `step` defaults to `0`, so the function returns `1` for non-negative inputs.
