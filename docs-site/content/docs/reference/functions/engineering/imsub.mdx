Returns the difference between two complex numbers.

Subtracts the second complex value from the first.

The Formualizer engine in this repository at 0.14.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMSUB(inumber1, inumber2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber1` | any | Required | — |
| `inumber2` | any | Required | — |

## Return type

Can return text.

## How it works

Subtract corresponding components to get (a − c) + (b − d)i. Subtraction is defined for every pair of complex numbers.

## Differences from Excel

When the first operand is purely real and the second uses a j suffix, Formualizer uses i in the result where Excel preserves j. The examples display each coefficient to at most 15 significant digits.

## Remarks
 - Inputs are coerced to complex-number text before parsing.
 - The output uses the suffix style of the first argument, defaulting to `i` for a purely real first argument.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"Subtract the real and imaginary components of two complex numbers."}
  formula={"=IMSUB(\"3+4i\",\"1+i\")"}
  grid={{}}
  expected={"2+3i"}
/>

<FunctionExample
  title={"Subtract a purely real value from a j-suffixed complex value."}
  formula={"=IMSUB(\"3+4j\",\"2\")"}
  grid={{}}
  expected={"1+4j"}
/>

<FunctionExample
  title={"Equal complex values cancel both coefficients."}
  formula={"=IMSUB(\"1+i\",\"1+i\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The second argument cannot be parsed as a complex value."}
  formula={"=IMSUB(\"1+i\",\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Subtract a+bi values"}
  formula={"=IMSUB(\"5+3i\",\"2+i\")"}
  grid={{}}
  expected={"3+2i"}
/>

## FAQ

### How is subtraction ordered in `IMSUB`?
It always computes `inumber1 - inumber2`; swapping arguments changes the sign of the result.
