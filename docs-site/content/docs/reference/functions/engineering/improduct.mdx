Returns the product of one or more complex numbers.

Multiplies values sequentially using complex multiplication rules.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMPRODUCT(inumber1, [inumber2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber1` | any | Required | — |
| `inumber2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Can return text.

## How it works

Multiplying a + bi by c + di gives (ac − bd) + (ad + bc)i. Each additional operand multiplies the accumulated product. Any complex value is allowed.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Each argument is coerced to complex-number text before parsing.
 - Accepts any number of arguments from one upward.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"Multiply 3 + 4i by 1 + i using i² = −1."}

<FunctionExample
  title={"Multiply both coefficients of the complex product by the real factor two."}

  grid={{}}
  expected={"-2+14i"}
/>

<FunctionExample
  title={"With one factor, the product is that factor."}
  formula={"=IMPRODUCT(\"3+4i\")"}
  grid={{}}
  expected={"3+4i"}
/>

<FunctionExample
  title={"An operand that cannot be parsed as complex causes an error."}

  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Multiply conjugates"}
  formula={"=IMPRODUCT(\"1+i\",\"1-i\")"}

## FAQ

### Can `IMPRODUCT` multiply a single argument?
Yes. With one argument it returns that parsed complex value in canonical formatted form.
