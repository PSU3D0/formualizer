Returns the base-10 logarithm of a complex number.

Produces the principal complex logarithm in base 10.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMLOG10(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## Return type

Can return text.

## How it works

The principal logarithm in base 10 is the principal natural logarithm divided by ln(10). It is undefined at zero and inherits the negative real branch cut.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Input is coerced to complex-number text before parsing.

## Error cases

 - Returns `#NUM!` for zero input.
 - Invalid complex text returns `#NUM!`.

## FAQ

### What branch of the logarithm does `IMLOG10` use?
It returns the principal complex logarithm (base 10), derived from principal argument `atan2(imag, real)`.
