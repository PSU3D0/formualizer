Converts a decimal integer to binary text.

Optionally pads the result with leading zeros using `places`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DEC2BIN(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `places` | number | Optional | — |

## Return type

Can return text.

## Remarks
 - `number` is coerced to an integer and must be in `[-512, 511]`.
 - Negative values are returned as 10-bit two's-complement binary strings.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Examples

<FunctionExample
  title={"Convert a decimal integer using the shortest output."}
  formula={"=DEC2BIN(30)"}
  grid={{}}
  expected={"11110"}
/>

<FunctionExample
  title={"Request eight characters to see the leading-zero padding."}
  formula={"=DEC2BIN(30,8)"}
  grid={{}}
  expected={"00011110"}
/>

<FunctionExample
  title={"Convert a negative value to its signed representation."}
  formula={"=DEC2BIN(-1)"}
  grid={{}}
  expected={"1111111111"}
/>

<FunctionExample
  title={"A nonzero value cannot fit in a zero-place output."}
  formula={"=DEC2BIN(30,0)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Convert a positive integer"}
  formula={"=DEC2BIN(42)"}
  grid={{}}
  expected={"101010"}
/>

<FunctionExample
  title={"Pad binary output"}
  formula={"=DEC2BIN(5,8)"}
  grid={{}}
  expected={"00000101"}
/>

## FAQ

### What limits apply to `DEC2BIN`?
`number` must be in `[-512, 511]`, and optional `places` must be between output width and `10`, else `#NUM!`.
