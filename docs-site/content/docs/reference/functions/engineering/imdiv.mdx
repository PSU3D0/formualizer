Returns the quotient of two complex numbers.

Divides the first complex value by the second.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMDIV(inumber1, inumber2)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber1` | any | Required | — |
| `inumber2` | any | Required | — |

## Return type

Can return text.

## How it works

Dividing z by w is equivalent to multiplying z by the conjugate of w and dividing by |w|². A zero denominator is undefined.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Inputs are coerced to complex-number text before parsing.

## Error cases

 - Returns `#DIV/0!` when the divisor is `0+0i`.
 - Invalid complex text returns `#NUM!`.

## FAQ

### When does `IMDIV` return `#DIV/0!`?
If the divisor is `0+0i` (denominator magnitude near zero), division is undefined and returns `#DIV/0!`.
