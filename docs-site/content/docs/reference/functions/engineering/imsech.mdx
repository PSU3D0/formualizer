Returns the hyperbolic secant of a complex number.

Computes `1 / IMCOSH(inumber)` for an Excel-style complex number string.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMSECH(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex hyperbolic secant is 1 / cosh(z). Its poles are i times π/2 plus integer multiples of πi.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Examples

<FunctionExample
  title={"Invert the complex hyperbolic cosine at 3 + 4i."}
  formula={"=IMSECH(\"3+4i\")"}
  grid={{}}
  expected={"-0.0652940278579471+0.0752249603027732i"}
/>

<FunctionExample
  title={"Reflect the input to change the sign of the secant’s imaginary component."}
  formula={"=IMSECH(\"3-4j\")"}
  grid={{}}
  expected={"-0.0652940278579471-0.0752249603027732j"}
/>

<FunctionExample
  title={"At real one, the result is the reciprocal of cosh(1)."}
  formula={"=IMSECH(\"1\")"}
  grid={{}}
  expected={"0.648054273663885"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the hyperbolic secant."}
  formula={"=IMSECH(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Hyperbolic secant of zero"}
  formula={"=IMSECH(\"0\")"}
  grid={{}}
  expected={"1"}
/>
