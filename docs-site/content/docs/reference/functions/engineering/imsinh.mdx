Returns the hyperbolic sine of a complex number.

Accepts an Excel-style complex number string and returns the complex
 hyperbolic sine as text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMSINH(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex hyperbolic sine is (exp(z) − exp(−z)) / 2. It exists throughout the complex plane and vanishes at zero.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Examples

<FunctionExample

<FunctionExample
  title={"Compare hyperbolic sine below the real axis."}

  grid={{}}
  expected={"-6.548120040911+7.61923172032141j"}
/>

<FunctionExample
  title={"A real input of one reduces the formula to the ordinary hyperbolic sine."}
  formula={"=IMSINH(\"1\")"}
  grid={{}}
  expected={"1.1752011936438"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the hyperbolic sine."}
  formula={"=IMSINH(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Hyperbolic sine of zero"}
  formula={"=IMSINH(\"0\")"}
  grid={{}}
  expected={"0"}
/>
