Returns the natural logarithm of a complex number.

Produces the principal complex logarithm as text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMLN(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## Return type

Can return text.

## How it works

The principal logarithm of z is ln(|z|) + i arg(z). Zero has no logarithm, and the principal value uses a branch cut on the negative real axis.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Input is coerced to complex-number text before parsing.

## Error cases

 - Returns `#NUM!` for zero input because `ln(0)` is undefined.
 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"For 3 + 4i, combine the natural logarithm of its magnitude five with its angle."}
  formula={"=IMLN(\"3+4i\")"}
  grid={{}}

/>

<FunctionExample
  title={"A negative angle changes the imaginary term of the principal logarithm."}
  formula={"=IMLN(\"3-4j\")"}
  grid={{}}
  expected={"1.6094379124341-0.927295218001612j"}
/>

<FunctionExample
  title={"The natural logarithm of a positive real unit is zero."}
  formula={"=IMLN(\"1\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the natural logarithm."}
  formula={"=IMLN(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Natural log on imaginary axis"}
  formula={"=IMLN(\"i\")"}

## FAQ

### Why does `IMLN(0)` return `#NUM!`?
The complex logarithm at zero is undefined, so this implementation returns `#NUM!`.
