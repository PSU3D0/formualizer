Returns the hyperbolic cosine of a complex number.

Accepts an Excel-style complex number string and returns the complex
 hyperbolic cosine as text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMCOSH(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

The complex hyperbolic cosine is (exp(z) + exp(−z)) / 2. It is defined everywhere, and equals 1 at zero.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - The input may use either `i` or `j` as the imaginary suffix.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"Compute hyperbolic cosine at 3 + 4i by averaging opposite exponentials."}
  formula={"=IMCOSH(\"3+4i\")"}
  grid={{}}
  expected={"-6.58066304055116-7.58155274274654i"}
/>

<FunctionExample
  title={"Conjugating the input conjugates its hyperbolic cosine."}
  formula={"=IMCOSH(\"3-4j\")"}
  grid={{}}
  expected={"-6.58066304055116+7.58155274274654j"}
/>

<FunctionExample
  title={"On the real axis, use the hyperbolic cosine of one."}
  formula={"=IMCOSH(\"1\")"}
  grid={{}}
  expected={"1.54308063481524"}
/>

<FunctionExample
  title={"The text “invalid” has no complex value from which to take the hyperbolic cosine."}
  formula={"=IMCOSH(\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Hyperbolic cosine of zero"}
  formula={"=IMCOSH(\"0\")"}
  grid={{}}
  expected={"1"}
/>

### Does IMCOSH preserve the imaginary suffix?
Results preserve the input's i/j suffix when an imaginary part is present.
