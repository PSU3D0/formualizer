Returns the sum of one or more complex numbers.

Adds real parts together and imaginary parts together.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMSUM(inumber1, [inumber2], ...)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber1` | any | Required | — |
| `inumber2` | any | Optional | — |

Accepts a variable number of arguments. Minimum: 1.

## Return type

Can return text.

## How it works

Add corresponding components to get (a + c) + (b + d)i. An additional argument adds its real and imaginary coefficients independently.

## Differences from Excel

The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.

## Remarks
 - Each argument is coerced to complex-number text before parsing.
 - Accepts any number of arguments from one upward.

## Error cases

 - Invalid complex text returns `#NUM!`.

## Examples

<FunctionExample
  title={"Add the real and imaginary coefficients of 3 + 4i and 1 + i."}
  formula={"=IMSUM(\"3+4i\",\"1+i\")"}
  grid={{}}
  expected={"4+5i"}
/>

<FunctionExample
  title={"Add two to the real coefficient while leaving the imaginary sum fixed."}
  formula={"=IMSUM(\"3+4i\",\"1+i\",\"2\")"}
  grid={{}}
  expected={"6+5i"}
/>

<FunctionExample
  title={"With one operand, the sum is the input itself."}
  formula={"=IMSUM(\"3+4i\")"}
  grid={{}}
  expected={"3+4i"}
/>

<FunctionExample
  title={"An operand that cannot be parsed as complex causes an error."}
  formula={"=IMSUM(\"3+4i\",\"invalid\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Add multiple complex values"}
  formula={"=IMSUM(\"3+4i\",\"1-2i\",\"5\")"}
  grid={{}}
  expected={"9+2i"}
/>

<FunctionExample
  title={"Add j-suffix values"}
  formula={"=IMSUM(\"2j\",\"-j\")"}
  grid={{}}
  expected={"j"}
/>

## FAQ

### Can `IMSUM` take more than two arguments?
Yes. It is variadic and sums all provided complex arguments in sequence.
