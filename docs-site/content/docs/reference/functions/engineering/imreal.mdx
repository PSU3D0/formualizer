Returns the real coefficient of a complex number.

Accepts complex text (for example `a+bi`) or numeric values.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMREAL(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

For z = a + bi, the result is a. A purely imaginary input has real coefficient zero.

## Remarks
 - Inputs are coerced to complex-number text before parsing.
 - Purely imaginary values return `0`.

## Error cases

 - Invalid complex text returns `#NUM!`.

### What does `IMREAL` return for a purely imaginary input?
It returns `0` because the real coefficient is zero.
