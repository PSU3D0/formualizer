Returns the complementary error function of a number.

Computes `1 - ERF(x)` using the same one-argument precise behavior as Excel
 `ERFC.PRECISE`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ERFC.PRECISE(x)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `x` | any | Required | — |

## How it works

Evaluates 1 minus the error function at x, equivalently the Gaussian integral from x to infinity scaled by 2 / √π. It is defined for real x and tends to zero as x grows.

## Remarks
 - Accepts one numeric argument.
 - Numeric text is coerced using standard function coercion.
 - Results are approximate floating-point values.

## FAQ

### How is ERFC.PRECISE different from ERFC?
It exposes the precise one-argument complement form; numerically it matches ERFC(x) in this implementation.
