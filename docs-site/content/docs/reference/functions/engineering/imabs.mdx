Returns the modulus (absolute value) of a complex number.

Computes `sqrt(real^2 + imaginary^2)`.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=IMABS(inumber)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `inumber` | any | Required | — |

## How it works

For z = a + bi, the magnitude is √(a² + b²). It is defined for every complex number, including zero.

## Remarks
 - Inputs are coerced to complex-number text before parsing.
 - Returns a non-negative real number.

## Error cases

 - Invalid complex text returns `#NUM!`.

## FAQ

### Can `IMABS` return a negative result?
No. It computes the modulus `sqrt(a^2+b^2)`, which is always non-negative.
