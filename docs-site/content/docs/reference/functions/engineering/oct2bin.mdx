Converts an octal text value to binary text.

Supports optional left-padding through the `places` argument.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=OCT2BIN(number, [places])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `number` | number | Required | — |
| `places` | number | Optional | — |

## Return type

Can return text.

## Remarks
 - Input must be octal text up to 10 digits and may be signed two's-complement.
 - `places` must be at least the output width and at most `10`, or `#NUM!` is returned.

## Error cases

 - Converted values must fall in `[-512, 511]`, or the function returns `#NUM!`.

## Examples

<FunctionExample
  title={"Convert octal 36 with no output padding."}
  formula={"=OCT2BIN(\"36\")"}
  grid={{}}
  expected={"11110"}
/>

<FunctionExample
  title={"Use eight output characters to preserve leading zeros."}
  formula={"=OCT2BIN(\"36\",8)"}
  grid={{}}
  expected={"00011110"}
/>

<FunctionExample
  title={"Convert zero with a one-place width."}
  formula={"=OCT2BIN(\"0\",1)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The input contains a digit outside base eight."}
  formula={"=OCT2BIN(\"8\")"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Convert octal to binary"}
  formula={"=OCT2BIN(\"77\")"}
  grid={{}}
  expected={"111111"}
/>

<FunctionExample
  title={"Convert signed octal"}
  formula={"=OCT2BIN(\"7777777777\")"}
  grid={{}}
  expected={"1111111111"}
/>

## FAQ

### Why does `OCT2BIN` return `#NUM!` for some octal inputs?
After decoding, the value must be within `[-512, 511]` to be representable in Excel-style binary output.
