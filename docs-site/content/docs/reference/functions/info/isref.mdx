Returns TRUE when the argument resolves to a reference.

Checks reference metadata without materializing the referenced value or range.

Returns TRUE when the argument resolves to a reference.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISREF(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Return type

Logical (TRUE or FALSE)

## Examples

<FunctionExample
  title={"Test a reference to a populated cell."}
  formula={"=ISREF(A1)"}
  grid={{"A1":"7"}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"A rectangular range is also a reference."}
  formula={"=ISREF(A1:B2)"}
  grid={{"A1":"7"}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"A number written directly in the formula is a value."}
  formula={"=ISREF(7)"}
  grid={{}}
  expected={"FALSE"}
/>

<FunctionExample
  title={"Cell reference"}
  formula={"=ISREF(A1)"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Expression is not a reference"}
  formula={"=ISREF(1+1)"}
  grid={{}}
  expected={"FALSE"}
/>

## FAQ

### Does ISREF read cell values?
No. It inspects whether the argument can resolve as a reference.
