Returns the 1-based sheet index for the current sheet or a reference.

With no argument, returns the index of the sheet containing the formula. With
 a reference or sheet-name text argument, returns that sheet's index.

Returns the 1-based sheet index for the current sheet or a reference.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SHEET([reference])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `reference` | any | Optional | — |

## Examples

<FunctionExample
  title={"Use the default based on the workbook containing the formula."}
  formula={"=SHEET()"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"Supply a reference on a second sheet."}
  formula={"=SHEET(Sheet2!A1)"}
  grid={{"Sheet2!A1":"8"}}
  expected={"2"}
/>

<FunctionExample
  title={"Evaluate a reference to the first sheet."}
  formula={"=SHEET(A1)"}
  grid={{"A1":"7"}}
  expected={"1"}
/>

<FunctionExample
  title={"Referenced sheet index"}
  formula={"=SHEET(A1)"}
  grid={{}}
  expected={"1"}
/>

## FAQ

### Are sheet indexes 0-based?
No. SHEET returns Excel-style 1-based sheet indexes.
