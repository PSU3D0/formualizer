Returns whether the referenced cell contains a formula.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISFORMULA(reference)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `reference` | any | Required | — |

## Return type

Logical (TRUE or FALSE)

## Differences from Excel

Formualizer accepts scalar expressions and returns FALSE for them. Excel requires a reference.

## Remarks
 - Inspects the first cell of a reference, including named references.
 - Non-reference values return FALSE; the referenced value need not be evaluated.

## Error cases

 - Arity mismatch returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Test a reference to a cell that stores an arithmetic formula."}
  formula={"=ISFORMULA(A1)"}
  grid={{"A1":"=1+2"}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"The same calculated number stored directly is a value."}
  formula={"=ISFORMULA(A2)"}
  grid={{"A2":"3"}}
  expected={"FALSE"}
/>

<FunctionExample
  title={"A formula cell remains a formula cell if its calculation returns an error."}
  formula={"=ISFORMULA(B1)"}
  grid={{"B1":"=1/0"}}
  expected={"TRUE"}
/>

## FAQ

### Does a formula that returns an error count as a formula?
Yes. ISFORMULA inspects the cell definition rather than its calculated value.
