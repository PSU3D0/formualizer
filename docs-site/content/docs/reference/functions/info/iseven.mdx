Returns TRUE if number is even.

Returns TRUE when a number is even.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISEVEN(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Return type

Logical (TRUE or FALSE)

## Remarks
 - Numeric input is truncated toward zero before parity is checked.
 - Booleans are coerced (`TRUE` -&gt; 1, `FALSE` -&gt; 0).
 - Errors propagate unchanged.

## Error cases

 - Non-numeric text returns `#VALUE!`.

### How are decimals handled by ISEVEN?
