Returns the `#N/A` error value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NA()`

## Return type

Error (#N/A)

## Remarks
 - `NA()` is commonly used to mark missing lookup results.
 - The function takes no arguments.
 - The returned value is an error and propagates through dependent formulas.

## Examples

<FunctionExample
  title={"Mark an observation as missing and substitute descriptive text for it."}
  formula={"=IFNA(NA(),\"No observation\")"}
  grid={{}}
  expected={"No observation"}
/>

<FunctionExample
  title={"Check explicitly for the missing-value error."}
  formula={"=ISNA(NA())"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Count the numeric observations while representing missing data as empty text."}
  formula={"=COUNT({0,1},IFNA(NA(),\"\"))"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"Produce the missing-value error directly."}
  formula={"=NA()"}
  grid={{}}
  expected={"#N/A"}
/>

## FAQ

### When should I use NA() intentionally?
Use it to mark missing data so lookups and downstream checks can distinguish absent values from blanks.
