Returns TRUE for any error value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISERROR(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Return type

Logical (TRUE or FALSE)

## Remarks
 - Matches all error kinds, including `#N/A`.
 - Non-error values always return FALSE.

## Error cases

 - Arity mismatch returns `#VALUE!`.

### Does ISERROR include #N/A?
Yes. ISERROR returns TRUE for all error kinds, including #N/A.
