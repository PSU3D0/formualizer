Returns TRUE only for a truly empty value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISBLANK(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Return type

Logical (TRUE or FALSE)

## Remarks
 - Empty string `""` is text, not blank, so it returns FALSE.
 - Numeric zero and FALSE are not blank.
 - Errors return FALSE.

/>

## FAQ

### Why does ISBLANK("") return FALSE?
Because an empty string is text, not a truly empty cell value.
