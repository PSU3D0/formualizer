Converts a value to its numeric representation.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=N(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Remarks
 - Numbers pass through unchanged; booleans convert to `1`/`0`.
 - Text and blank values convert to `0`.
 - Errors propagate unchanged.
 - Temporal values are converted using serial number representation.

## Examples

<FunctionExample
  title={"Convert a logical value to its numeric equivalent."}
  formula={"=N(TRUE)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"Test the numeric-looking text case."}
  formula={"=N(\"17\")"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Convert the false logical value at the zero boundary."}
  formula={"=N(FALSE)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Preserve the error already present in the input."}
  formula={"=N(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Text to zero"}
  formula={"=N(\"hello\")"}
  grid={{}}
  expected={"0"}
/>

## FAQ

### What does N do with text and blanks?
Text and blank values convert to 0, while existing errors are passed through.
