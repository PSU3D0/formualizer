Returns the number of sheets in the workbook or reference span.

With no argument, returns the active workbook sheet count. With a reference,
 returns the number of sheets covered by that reference.

Returns the number of sheets in the workbook or covered by a 3D reference.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SHEETS([reference])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `reference` | any | Optional | — |

## Examples

<FunctionExample
  title={"Use the default based on the workbook containing the formula."}
  formula={"=SHEETS()"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"Supply a reference on a second sheet."}
  formula={"=SHEETS(Sheet2!A1)"}
  grid={{"Sheet2!A1":"8"}}
  expected={"1"}
/>

<FunctionExample
  title={"Evaluate a reference to the first sheet."}
  formula={"=SHEETS(A1)"}
  grid={{"A1":"7"}}
  expected={"1"}
/>

<FunctionExample
  title={"Single-sheet reference count"}
  formula={"=SHEETS(A1)"}
  grid={{}}
  expected={"1"}
/>

## FAQ

### What does SHEETS return for ordinary references?
Ordinary references cover one sheet, so the result is 1.
