Returns TRUE when the value is anything other than text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=ISNONTEXT(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Return type

Logical (TRUE or FALSE)

## Remarks
 - Text literals return FALSE.
 - Numbers, booleans, blanks, and errors return TRUE.
 - This is the logical complement of `ISTEXT` in the current engine semantics.

## Examples

<FunctionExample
  title={"Test whether an ordinary number is a non-text value."}
  formula={"=ISNONTEXT(42)"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"Test whether a logical result is also non-text."}
  formula={"=ISNONTEXT(TRUE)"}
  grid={{}}
  expected={"TRUE"}
/>

<FunctionExample
  title={"An empty string is still text."}
  formula={"=ISNONTEXT(\"\")"}
  grid={{}}
  expected={"FALSE"}
/>

<FunctionExample
  title={"Text is not non-text"}
  formula={"=ISNONTEXT(\"alpha\")"}
  grid={{}}
  expected={"FALSE"}
/>

## FAQ

### Do errors count as non-text values?
Yes. This implementation treats any non-text value, including errors, as TRUE for ISNONTEXT.
