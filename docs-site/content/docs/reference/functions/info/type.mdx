Returns an Excel TYPE code describing the value category.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=TYPE(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Remarks
 - Codes: `1` number, `2` text, `4` logical, `16` error, `64` array.
 - Spreadsheet errors return `16`; operation failures still propagate.
 - Blank values map to numeric code `1` in this implementation.

## Examples

<FunctionExample
  title={"Read the type code of a numeric value."}
  formula={"=TYPE(7)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"Read the different type code for text with the same displayed character."}
  formula={"=TYPE(\"7\")"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"Read the type code for a logical value."}
  formula={"=TYPE(TRUE)"}
  grid={{}}
  expected={"4"}
/>

<FunctionExample
  title={"Text type code"}
  formula={"=TYPE(\"abc\")"}
  grid={{}}
  expected={"2"}
/>

### How are errors handled by TYPE?
