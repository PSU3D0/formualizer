Returns text when input is text, otherwise returns empty text.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=T(value)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `value` | any | Required | — |

## Return type

Text

## Remarks
 - Text values pass through unchanged.
 - Errors propagate unchanged.
 - Numbers, booleans, and blanks return an empty string.

## Examples

<FunctionExample
  title={"Return a text value unchanged."}
  formula={"=T(\"sample\")"}
  grid={{}}
  expected={"sample"}
/>

<FunctionExample
  title={"Return an empty string for a number."}
  formula={"=T(123)"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"Preserve an already empty string."}
  formula={"=T(\"\")"}
  grid={{}}
  expected={""}
/>

<FunctionExample
  title={"Propagate the error instead of returning empty text."}
  formula={"=T(1/0)"}
  grid={{}}
  expected={"#DIV/0!"}
/>

<FunctionExample
  title={"Text passthrough"}
  formula={"=T(\"report\")"}
  grid={{}}
  expected={"report"}
/>

<FunctionExample
  title={"Number becomes empty text"}
  formula={"=T(99)"}
  grid={{}}
  expected={""}
/>

## FAQ

### Does T hide non-text values?
Yes. Non-text inputs become an empty string, but errors are still propagated.
