Returns the formula text stored in the referenced cell.

Retrieves formula source text for a single referenced cell without evaluating
 that cell's value.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=FORMULATEXT(reference)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `reference` | any | Required | — |

## Return type

Text

## Differences from Excel

Formualizer returns normalized formula text and can add spaces. Excel preserves the text as entered.

## Remarks
 - Staged formula text is preferred when present; otherwise canonical formula text is returned.





Returns the formula text stored in the referenced cell.

## Error cases

 - Returns `#N/A` if the reference does not point at a formula cell.

## Examples

<FunctionExample
  title={"Read an arithmetic formula as text without returning the calculated sum."}
  formula={"=FORMULATEXT(A1)"}
  grid={{"A1":"=1+2"}}
  expected={"=1 + 2"}
/>

<FunctionExample
  title={"Retrieve a formula that contains a function call."}
  formula={"=FORMULATEXT(B1)"}
  grid={{"B1":"=SUM(1,2)"}}
  expected={"=SUM(1, 2)"}
/>

<FunctionExample
  title={"A formula consisting of a single literal still has formula text."}
  formula={"=FORMULATEXT(A2)"}
  grid={{"A2":"=42"}}
  expected={"=42"}
/>

<FunctionExample
  title={"A value stored directly in a cell has no formula text to return."}
  formula={"=FORMULATEXT(A3)"}
  grid={{"A3":"42"}}
  expected={"#N/A"}
/>

## FAQ

### Does FORMULATEXT evaluate the referenced formula?
No. It retrieves formula provenance/source text only.
