Extracts the month number (`1` to `12`) from a date serial.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MONTH(serial_number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `serial_number` | number | Required | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - Fractional time is ignored; only the date portion contributes.
 - Serials are interpreted with the workbook's date system (Excel 1900 or Excel 1904).
 - The result always uses January=`1` through December=`12`.

## Examples

<FunctionExample
  title={"Extract the date component from a leap-day date."}
  formula={"=MONTH(DATE(2024,2,29))"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"Read the date component from a serial that also contains a time fraction."}
  formula={"=MONTH(DATE(2024,12,31)+0.75)"}
  grid={{}}
  expected={"12"}
/>

<FunctionExample
  title={"Read the component of the first day of the 1900 date system."}
  formula={"=MONTH(1)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"An unrecognized date string cannot be interpreted as a serial."}
  formula={"=MONTH(\"not a date\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Extract month from January date"}
  formula={"=MONTH(44927)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"Extract month from leap-day serial"}
  formula={"=MONTH(45351)"}
  grid={{}}
  expected={"2"}
/>

## FAQ

### Can MONTH return values outside 1 through 12?
No. MONTH always returns an integer from 1 to 12 after serial-to-date conversion.
