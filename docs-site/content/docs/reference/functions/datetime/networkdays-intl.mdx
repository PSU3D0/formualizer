Returns the number of working days between two dates with configurable weekends.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NETWORKDAYS.INTL(start_date, end_date, [weekend], [holidays])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `start_date` | number | Required | — |
| `end_date` | number | Required | — |
| `weekend` | any | Optional | — |
| `holidays` | any | Optional | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - The `weekend` argument can be a number code (1-7, 11-17) or a 7-character string
   of `0`s and `1`s (Mon-Sun, `1` = weekend day). Default is `1` (Sat/Sun).
 - The optional `holidays` argument accepts a range or array of date values, serials, or date
   text to exclude.
 - If `start_date &gt; end_date`, the result is negative.

## Error cases

 - A weekend string of all `1`s (no workdays) returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Count working days using the default weekend."}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,1),DATE(2024,1,7))"}
  grid={{}}
  expected={"5"}
/>

<FunctionExample
  title={"Select the Saturday–Sunday weekend and exclude Wednesday’s holiday."}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,1),DATE(2024,1,7),1,A1)"}
  grid={{"A1":"45294"}}
  expected={"4"}
/>

<FunctionExample
  title={"A single Sunday contributes no working days with the selected weekend."}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,7),DATE(2024,1,7),11)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"Weekend code 99 is outside the supported settings."}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,1),DATE(2024,1,7),99)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Default weekends (same as NETWORKDAYS)"}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,1), DATE(2024,1,31))"}
  grid={{}}
  expected={"23"}
/>

<FunctionExample
  title={"Friday-only weekend"}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,1), DATE(2024,1,7), 16)"}
  grid={{}}
  expected={"6"}
/>

<FunctionExample
  title={"Custom weekend string (Mon+Fri off)"}
  formula={"=NETWORKDAYS.INTL(DATE(2024,1,1), DATE(2024,1,7), \"1000100\")"}
  grid={{}}
  expected={"5"}
/>

## FAQ

### What happens if the weekend string is all 1s?
NETWORKDAYS.INTL returns #VALUE! because there would be no workdays.
