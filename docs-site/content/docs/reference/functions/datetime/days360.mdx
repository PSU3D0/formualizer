Returns the day count between two dates using a 30/360 convention.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=DAYS360(start_date, end_date, [method])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `start_date` | number | Required | — |
| `end_date` | number | Required | — |
| `method` | any | Optional | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - `method` omitted or `FALSE` uses U.S. (NASD) rules; `TRUE` uses the European 30E/360 method.
 - U.S. rules as Excel applies them: a start date on the last day of its month becomes the
   30th; an end date on the 31st becomes the 1st of the next month when the start day is
   before the 30th, otherwise the 30th. An end date on the 30th or on the last day of
   February is not adjusted (`DAYS360(DATE(2001,11,24),DATE(2001,11,30))` is 6).
 - Inputs are coerced to dates by truncating serials to integer days.
 - Serials are interpreted with the workbook's date system (Excel 1900 or Excel 1904).

## Examples

<FunctionExample
  title={"Measure two full months on the 360-day financial calendar."}
  formula={"=DAYS360(DATE(2024,1,1),DATE(2024,3,1))"}
  grid={{}}
  expected={"60"}
/>

<FunctionExample
  title={"Select the European convention for the month-end adjustment."}
  formula={"=DAYS360(DATE(2024,2,29),DATE(2024,3,31),TRUE)"}
  grid={{}}
  expected={"31"}
/>

<FunctionExample
  title={"A zero-length interval at the start of a month counts as zero."}
  formula={"=DAYS360(DATE(2024,1,1),DATE(2024,1,1))"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The start date must be a valid serial or supported date string."}
  formula={"=DAYS360(\"invalid\",45000)"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"U.S. 30/360 method"}
  formula={"=DAYS360(40574, 40602)"}
  grid={{}}
  expected={"28"}
/>

<FunctionExample
  title={"European 30E/360 method"}
  formula={"=DAYS360(40574, 40602, TRUE)"}
  grid={{}}
  expected={"28"}
/>

## FAQ

### Why does DAYS360 differ from actual day counts?
DAYS360 applies 30/360 financial conventions, so month-end dates are adjusted by rule instead of using calendar day totals.
