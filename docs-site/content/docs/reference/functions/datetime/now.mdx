Returns the current date and time as a volatile datetime serial.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NOW()`

## Remarks
 - `NOW` is volatile and may produce a different value at each recalculation.
 - The integer part is the current date serial; the fractional part is time of day.
 - Serial output respects the active workbook date system (`1900` or `1904`).

## Examples

<FunctionExample
  title={"Read the current date and time as a spreadsheet serial."}
  formula={"=NOW()"}
  grid={{}}
  expected={"Date and time serial number"}
/>

<FunctionExample
  title={"Combine today's date with the fractional time returned by NOW."}
  formula={"=TODAY()+MOD(NOW(),1)"}
  grid={{}}
  expected={"Date and time"}
/>

<FunctionExample
  title={"Strip the fractional time and inspect the whole-day portion of the serial."}
  formula={"=INT(NOW())"}
  grid={{}}
  expected={"Number"}
/>

<FunctionExample
  title={"NOW includes today's date"}
  formula={"=INT(NOW())=TODAY()"}
  grid={{}}
  expected={"Logical value"}
/>

<FunctionExample
  title={"NOW is at or after TODAY"}
  formula={"=NOW()>=TODAY()"}
  grid={{}}
  expected={"Logical value"}
/>

## FAQ

### How do I isolate only the time portion from NOW?
Use NOW()-INT(NOW()); the integer part is date serial and the fractional part is time-of-day.
