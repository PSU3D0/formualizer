Extracts the second component (`0` to `59`) from a time or datetime serial.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=SECOND(serial_number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `serial_number` | number | Required | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - The integer date portion is ignored for second extraction.
 - The date portion, when present, is resolved with the workbook's date system.
 - Time is computed from the serial fraction and rounded to whole seconds.

## Examples

<FunctionExample
  title={"Extract the component from a time with nonzero hours, minutes and seconds."}
  formula={"=SECOND(TIME(14,35,27))"}
  grid={{}}
  expected={"27"}
/>

<FunctionExample
  title={"Read the time component from a serial that also includes a date."}
  formula={"=SECOND(DATE(2024,2,29)+TIME(14,35,27))"}
  grid={{}}
  expected={"27"}
/>

<FunctionExample
  title={"Read the component at midnight."}
  formula={"=SECOND(0)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"An unrecognized time string cannot be converted to a serial."}
  formula={"=SECOND(\"not a time\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Extract second from 15:30:45"}
  formula={"=SECOND(0.6463541667)"}
  grid={{}}
  expected={"45"}
/>

<FunctionExample
  title={"Extract second from exact noon"}
  formula={"=SECOND(0.5)"}
  grid={{}}
  expected={"0"}
/>

## FAQ

### Can SECOND return 60 for leap seconds?
No. SECOND returns values from 0 to 59 based on spreadsheet serial-time interpretation.
