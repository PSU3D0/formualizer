Returns the date serial that is a given number of weekdays from a start date.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=WORKDAY(start_date, days, [holidays])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `start_date` | number | Required | — |
| `days` | number | Required | — |
| `holidays` | any | Optional | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - Positive `days` moves forward; negative `days` moves backward.
 - Weekends are fixed to Saturday and Sunday.
 - Optional `holidays` arguments are excluded and may be provided as scalars, inline arrays,
   or ranges of date values, serials, or date text.
 - Input and output serials use the workbook's date system (Excel 1900 or Excel 1904).

## Examples

<FunctionExample
  title={"Advance one working day from a Friday across the weekend."}
  formula={"=WORKDAY(DATE(2024,1,5),1)"}
  grid={{}}
  expected={"45299"}
/>

<FunctionExample
  title={"Skip Monday as a holiday as well as skipping the weekend."}
  formula={"=WORKDAY(DATE(2024,1,5),1,A1)"}
  grid={{"A1":"45299"}}
  expected={"45300"}
/>

<FunctionExample
  title={"A zero-day offset preserves the working start date."}
  formula={"=WORKDAY(DATE(2024,1,5),0)"}
  grid={{}}
  expected={"45296"}
/>

<FunctionExample
  title={"The offset must be a number of working days."}
  formula={"=WORKDAY(DATE(2024,1,5),\"tomorrow\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Move forward by five workdays"}
  formula={"=WORKDAY(45292, 5)"}
  grid={{}}
  expected={"45299"}
/>

<FunctionExample
  title={"Holiday exclusions push the target date out"}
  formula={"=WORKDAY(45292, 5, 45293)"}
  grid={{}}
  expected={"45300"}
/>

## FAQ

### Does WORKDAY include the start date when days=0?
Yes. With zero offset, WORKDAY returns the start date serial unchanged; nonzero offsets skip weekend days while stepping.
