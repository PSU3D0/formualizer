Extracts the minute component (`0` to `59`) from a time or datetime serial.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=MINUTE(serial_number)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `serial_number` | number | Required | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - The integer date portion is ignored for minute extraction.
 - The date portion, when present, is resolved with the workbook's date system.
 - Time is derived from the fractional serial component.

## Examples

<FunctionExample
  title={"Extract the component from a time with nonzero hours, minutes and seconds."}
  formula={"=MINUTE(TIME(14,35,27))"}
  grid={{}}
  expected={"35"}
/>

<FunctionExample
  title={"Read the time component from a serial that also includes a date."}
  formula={"=MINUTE(DATE(2024,2,29)+TIME(14,35,27))"}
  grid={{}}
  expected={"35"}
/>

<FunctionExample
  title={"Read the component at midnight."}
  formula={"=MINUTE(0)"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"An unrecognized time string cannot be converted to a serial."}
  formula={"=MINUTE(\"not a time\")"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Extract minute from 15:30:45"}
  formula={"=MINUTE(0.6463541667)"}
  grid={{}}
  expected={"30"}
/>

<FunctionExample
  title={"Extract minute from exact noon"}
  formula={"=MINUTE(0.5)"}
  grid={{}}
  expected={"0"}
/>

## FAQ

### Does MINUTE round to nearest minute?
No. MINUTE extracts the minute component from the interpreted time value; it does not independently round to minute precision.
