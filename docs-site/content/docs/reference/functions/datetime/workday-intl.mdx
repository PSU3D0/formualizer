Returns the date serial that is a given number of workdays from a start date, with configurable weekends.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=WORKDAY.INTL(start_date, days, [weekend], [holidays])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `start_date` | number | Required | — |
| `days` | number | Required | — |
| `weekend` | any | Optional | — |
| `holidays` | any | Optional | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - Positive `days` moves forward; negative `days` moves backward.
 - The `weekend` argument can be a number code (1-7, 11-17) or a 7-character string
   of `0`s and `1`s (Mon-Sun, `1` = weekend day). Default is `1` (Sat/Sun).
 - The optional `holidays` argument accepts a range or array of date values, serials, or date
   text to exclude.

## Error cases

 - A weekend string of all `1`s (no workdays) returns `#VALUE!`.

## Examples

<FunctionExample
  title={"Advance one workday from Friday with the default weekend."}
  formula={"=WORKDAY.INTL(DATE(2024,1,5),1)"}
  grid={{}}
  expected={"45299"}
/>

<FunctionExample
  title={"Count Saturday as the first workday and skip the Sunday weekend and Monday holiday to reach Tuesday."}
  formula={"=WORKDAY.INTL(DATE(2024,1,5),2,11,A1)"}
  grid={{"A1":"45299"}}
  expected={"45300"}
/>

<FunctionExample
  title={"A zero-day offset returns the start date."}
  formula={"=WORKDAY.INTL(DATE(2024,1,5),0,11)"}
  grid={{}}
  expected={"45296"}
/>

<FunctionExample
  title={"A weekend code outside the supported range cannot define a working week."}
  formula={"=WORKDAY.INTL(DATE(2024,1,5),1,99)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Default weekends (same as WORKDAY)"}
  formula={"=WORKDAY.INTL(DATE(2024,1,1), 5)"}
  grid={{}}
  expected={"45299"}
/>

<FunctionExample
  title={"Sunday-only weekend"}
  formula={"=WORKDAY.INTL(DATE(2024,1,1), 5, 11)"}
  grid={{}}
  expected={"45297"}
/>

## FAQ

### What is the difference between WORKDAY and WORKDAY.INTL?
WORKDAY.INTL adds a weekend parameter that lets you define which days are non-working, instead of always using Saturday/Sunday.
