Returns the serial date offset by a whole number of months from a start date.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=EDATE(start_date, months)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `start_date` | number | Required | — |
| `months` | number | Required | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - `months` is truncated to an integer before calculation.
 - If the target month has fewer days, the day is clamped to that month's last valid day.
 - Serials are interpreted and emitted with the workbook's date system (Excel 1900 or Excel 1904).

## Examples

<FunctionExample
  title={"Move forward one month from January 31 into leap-year February."}
  formula={"=EDATE(DATE(2024,1,31),1)"}

  expected={"45351"}

<FunctionExample
  title={"Use a negative month offset to go backward."}
  formula={"=EDATE(DATE(2024,3,15),-1)"}

  expected={"45337"}

<FunctionExample
  title={"Apply a zero-month offset in the middle of February."}
  formula={"=EDATE(DATE(2024,2,15),0)"}

<FunctionExample
  title={"The month offset must be numeric."}

## FAQ

### What happens when the start day does not exist in the target month?
EDATE clamps to the last valid day of the target month (for example Jan 31 + 1 month becomes Feb month-end).
