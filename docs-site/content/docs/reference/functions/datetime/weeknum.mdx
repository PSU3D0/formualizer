Returns the week number of the year for a date serial.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=WEEKNUM(serial_number, [return_type])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `serial_number` | number | Required | — |
| `return_type` | number | Optional | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - Default `return_type` is `1` (week starts on Sunday).
 - Supported `return_type` values are `1`, `2`, `11`-`17`, and `21` (ISO week numbering).
 - Input serials are interpreted using the workbook's date system (Excel 1900 or Excel 1904);
   week boundaries differ between the systems because their epochs are 1462 days apart.

## Error cases

 - Unsupported `return_type` values return `#NUM!`.

## Examples

<FunctionExample
  title={"The first Sunday starts week two with the default Sunday start."}
  formula={"=WEEKNUM(DATE(2024,1,7))"}
  grid={{}}
  expected={"2"}
/>

<FunctionExample
  title={"With Monday starts, the same Sunday is still in week one."}
  formula={"=WEEKNUM(DATE(2024,1,7),2)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"January 1 belongs to the first week in this numbering mode."}
  formula={"=WEEKNUM(DATE(2024,1,1),2)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"An unsupported return type cannot define a week numbering rule."}
  formula={"=WEEKNUM(DATE(2024,1,1),99)"}
  grid={{}}
  expected={"#NUM!"}
/>

<FunctionExample
  title={"Default week numbering"}
  formula={"=WEEKNUM(45292)"}
  grid={{}}
  expected={"1"}
/>

<FunctionExample
  title={"ISO week numbering"}
  formula={"=WEEKNUM(42370, 21)"}
  grid={{}}
  expected={"53"}
/>

## FAQ

### What is special about return_type 21 in WEEKNUM?
return_type=21 switches to ISO week numbering, matching ISOWEEKNUM behavior.
