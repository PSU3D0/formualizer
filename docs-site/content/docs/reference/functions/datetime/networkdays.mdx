Returns the number of weekday business days between two dates, inclusive.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NETWORKDAYS(start_date, end_date, [holidays])`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `start_date` | number | Required | — |
| `end_date` | number | Required | — |
| `holidays` | any | Optional | — |

## Remarks
 - A date argument may be text holding a date or time (`"10/26/1999"`, `"1999-10-26 14:05"`),
   read as its serial; text that is neither a number nor a date returns `#VALUE!`.
 - Weekends are fixed to Saturday and Sunday.
 - If `start_date &gt; end_date`, the result is negative.
 - Optional `holidays` arguments are excluded from the count and may be provided as scalars,
   inline arrays, or ranges of date values, serials, or date text.
 - Serials are interpreted with the workbook's date system (Excel 1900 or Excel 1904); the
   weekend days depend on the calendar dates the serials denote, which differ per system.

## Examples

<FunctionExample
  title={"Count working days across a full Monday-to-Sunday week."}
  formula={"=NETWORKDAYS(DATE(2024,1,1),DATE(2024,1,7))"}
  grid={{}}
  expected={"5"}
/>

<FunctionExample
  title={"Remove the Wednesday holiday from the weekday count."}
  formula={"=NETWORKDAYS(DATE(2024,1,1),DATE(2024,1,7),A1)"}
  grid={{"A1":"45294"}}
  expected={"4"}
/>

<FunctionExample
  title={"A single Saturday contributes no working days."}
  formula={"=NETWORKDAYS(DATE(2024,1,6),DATE(2024,1,6))"}
  grid={{}}
  expected={"0"}
/>

<FunctionExample
  title={"The start of the interval must be a date."}
  formula={"=NETWORKDAYS(\"invalid\",DATE(2024,1,7))"}
  grid={{}}
  expected={"#VALUE!"}
/>

<FunctionExample
  title={"Count weekdays in a range"}
  formula={"=NETWORKDAYS(45292, 45299)"}
  grid={{}}
  expected={"6"}
/>

<FunctionExample
  title={"Holiday exclusions reduce the count"}
  formula={"=NETWORKDAYS(45292, 45299, 45293)"}
  grid={{}}
  expected={"5"}
/>

## FAQ

### Can I exclude custom holidays in NETWORKDAYS?
Yes. Additional arguments can provide holiday serials or date text, as scalars, arrays, or ranges, to exclude from the weekday count.
