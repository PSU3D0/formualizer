Reverses the logical value of its argument.

`NOT` converts the input to a logical value, then flips it.

The Formualizer engine in this repository at 0.15.0 plus unreleased changes computes the example results. Known differences from Excel are listed on this page.

## Syntax

`=NOT(logical)`

## Arguments

| Argument | Type | Required | Default |
| --- | --- | --- | --- |
| `logical` | any | Required | — |

## Return type

Can return a logical value (TRUE or FALSE).

## Remarks
 - Numbers are coerced (`0` -&gt; TRUE after inversion, non-zero -&gt; FALSE after inversion).
 - Blank values are treated as FALSE, so `NOT(blank)` returns TRUE.
 - Errors are propagated unchanged.

## Error cases

 - Text and other non-coercible values return `#VALUE!`.

## Examples

## FAQ

### How does NOT treat blanks?
Blank is treated as FALSE first, so NOT(blank) returns TRUE.
