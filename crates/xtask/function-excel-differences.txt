# Space-separated function names | verified implementation difference
SUM COUNT | Formualizer accepts a call with no arguments and returns zero. Excel requires the first argument.
CEILING FLOOR | Formualizer defaults the significance to 1 if it is omitted. Excel requires it.
SUMIF AVERAGEIF | Excel requires a reference for the optional result range, where Formualizer can evaluate a non-reference expression and propagate its error. Formualizer also accepts array constants as the criteria range, which Excel requires to be a reference.
SUMIFS AVERAGEIFS | Formualizer accepts array constants as ranges. Excel requires references. An invalid INDIRECT result in the result range can raise `#NAME?` in Formualizer, where Excel returns `#REF!`.
COUNTIF | Formualizer accepts an array constant as the range. Excel requires a reference.
COUNTIFS | Formualizer accepts array constants as criteria ranges. Excel requires references. An invalid INDIRECT result in a criteria range can raise `#NAME?` in Formualizer, where Excel returns `#REF!`.
ROW COLUMN | Excel requires a reference when the argument is supplied. Formualizer can also evaluate expressions in that position and propagate their errors.
COUNTBLANK | Formualizer accepts multiple arguments and can count scalar values. Excel takes a single range reference.
ISFORMULA | Formualizer accepts scalar expressions and returns FALSE for them. Excel requires a reference.
MAX MIN | Unparseable text supplied directly, such as `"x"`, is ignored by Formualizer. Excel returns `#VALUE!`.
AVERAGE | Formualizer ignores unparseable text supplied directly. Excel returns `#VALUE!`. If there are no numbers to average, Formualizer returns `#DIV/0!`.
AVERAGEA MAXA MINA STDEVA STDEVPA VARA VARPA | Formualizer accepts calls such as `(TRUE,2,"x")`. Excel returns `#VALUE!` for the unparseable text supplied directly.
LOG | A base of 1 returns `#NUM!` in Formualizer and `#DIV/0!` in Excel.
NPV | A rate of −1 returns `#NUM!` in Formualizer and `#DIV/0!` in Excel.
CHISQ.TEST | An expected count of zero returns `#NUM!` in Formualizer and `#DIV/0!` in Excel.
SEC | At `PI()/2`, Formualizer reports `#DIV/0!` and Excel returns a finite approximation of about 1.63312E+16.
FORMULATEXT | Formualizer returns normalized formula text and can add spaces. Excel preserves the text as entered.
COMPLEX IMCONJUGATE IMCOS IMCOSH IMCOT IMCSC IMCSCH IMDIV IMEXP IMLN IMLOG10 IMLOG2 IMPOWER IMPRODUCT IMSEC IMSECH IMSIN IMSINH IMSQRT IMSUB IMSUM IMTAN | The raw Formualizer text can contain more significant digits than Excel’s complex-number text. The examples round each coefficient to 15 significant digits for display.
GCD LCM | Formualizer accepts at most two arguments. Excel accepts up to 255.
TEXTAFTER TEXTBEFORE | Formualizer supports the arguments through `instance_num`. Excel also accepts `match_mode`, `match_end` and `if_not_found`.
INDEX | Formualizer does not accept the `area_num` argument from Excel’s reference form.
GROUPBY | Formualizer accepts a text aggregation name. Excel’s aggregation function argument is unsupported. A filter array also returns `#VALUE!` in Formualizer. Formualizer defaults `total_depth` to 0 (no totals). Excel automatically adds a grand total and, where possible, subtotals.
PIVOTBY | A supplied filter array returns `#VALUE!` in Formualizer. Omitted `row_total_depth` and `col_total_depth` default to 0 (no totals) in Formualizer. Excel chooses grand totals and, where possible, subtotals automatically for both axes.
