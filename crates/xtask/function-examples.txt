# Authored examples are added in function groups.

# Grid values use JSON types. A leading "=" in a grid string marks a formula.
# <FUNCTION> expands to each name in a group. Cases never store a result.

DAVERAGE:
grid {"A1":"Team","B1":"Score","A2":"East","B2":8,"A3":"West","B3":3,"A4":"East","B4":10,"D1":"Team","D2":"East","E1":"Team","E2":"West"}
ordinary | =<FUNCTION>(A1:B4,"Score",D1:D2) | Average the Score column for the two East records.
expected-equal | =<FUNCTION>(A1:B4,2,D1:D2) | Use field number 2 to get the same average for East.
boundary | =IFERROR(<FUNCTION>(A1:B4,"Score",E1:E2),"Insufficient data") | With the West filter, only the score of 3 contributes to the average.
error | =<FUNCTION>(A1:B4,"Missing",D1:D2) | The missing field header prevents calculating the average for East.
